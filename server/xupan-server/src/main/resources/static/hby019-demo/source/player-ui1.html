玩法说明 ✕
——玩法规则——
上分示例：“上100”
下分示例：“下100”
查分示例：“查”
【番】
玩法：投注单一号码，开出为赢，其余为输。
如：1番，开1为赢，2、3、4为输。
下注格式：“1番100”
【角】
玩法：投注两个号码，开出为赢，其余为输。
如：12角，开1、2为赢，3、4为输。
下注格式：“12角100” “12/100”
【车】
玩法：投注三个号码，如果开出的结果是三个号码之一，则中奖；其他则输。
下注格式：“1车100” “124/100”
【严】
玩法：投注两个号码，一个为赢，一个为和，另外两个为输。
如：1念2，开1为赢，开2为和，3、4为输。
下注格式：“12严100” “1严2/100”
【加】
玩法：投注三个号码，一个为赢，另外两个为和，其他则输。
如：1加23，开1为赢，开23为和，4为输。
下注格式：“1加23/100”
【正】
玩法：1正 为开1番为赢，2、4为和，3为输，2正、3正、4正 规则类似。
下注格式：“1正100”
【通】
玩法：投注两个号码，开出为赢，其余两个号码一输一和。
如：3通12，则开1、2为赢，3为输，4为和。
下注格式：“3通12/100” “12无3/100”
【单、双】
玩法：1、3为单，2、4为双。
下注格式：“单100” “双100”
【大、小】
玩法：第八位开奖结果，大于等于11为大，小于等于10为小。
下注格式：“大100” “小100”
【特码】
玩法：开奖结果对应结果。
下注格式：“01特100” “02/03/04特100”
