# 玩家前台资源清单

## 构建基线

- UI4 基线为 `手动下载资料/汇博盈1.html`，生成 `player.html` 与 `official-player-runtime.js`。UI1 基线为 `手动下载资料/view-source_...大家好_ui=1.html` 保存的 DevTools view-source 文档；构建用 `parse5` 按源码行还原原始 HTML，再生成 `player-ui1.html` 与 `official-player-runtime-ui1.js`。`汇博盈2.html`、`汇博盈3.html` 不是当前构建输入。
- 两个构建目标都保留各自捕获的 DOM、内联 CSS 和交互脚本，并将原有 HTML/CSS/脚本资源映射到本地。访问标识和账号 id 会清除；用户指定的显示昵称“大家好”保留在本地页面，动态聊天快照由本地合成 fixture 替代；UI 菜单在两个本地页面间切换。
- 构建器会删除下载器插入的 `saved from url` 归档注释，避免生成的玩家页保留参考主机名；自动测试要求 UI1/UI4 产物均不含参考主机字符串。
- 这不是服务端源码或完整站点源码的副本；动态接口、服务端业务、未捕获资源不在本地包内。

## 手动下载并用于构建的资源

以下文件由 `手动下载资料/汇博盈1_files` 进入 `static/reference-player/vendor/`。测试会逐个比较源文件与运行文件字节，确保没有改写：

| 手动下载文件 | 本地运行路径 | 用途 |
|---|---|---|
| `jquery.js.下载` | `vendor/jquery.js` | 捕获客户端依赖 |
| `layui.js.下载` | `vendor/layui.js` | Layui 核心 |
| `cdn.min.js.下载` | `vendor/cdn.min.js` | 捕获客户端脚本（Alpine） |
| `bulma.min.css` | `vendor/bulma.min.css` | 页面样式 |
| `layui.css` | `vendor/layui.css` | Layui 样式 |
| `layer.css` | `vendor/css/modules/layer/default/layer.css` | Layer 样式 |

UI1 DevTools `view-source` 文档中的 `/static/xz/lib/jquery.js`、`/static/xz/layui/layui.js`、Bulma 与 Layui CSS 都映射到上述本地文件；已对比其与 UI1 手动资源包字节一致。UI1 使用的头像也取自随 UI4 下载的相同手动头像目录。

页面中的 UniIcons 图标字体由已捕获 `uniicons.b6d3756e.ttf` 提供，浏览器画面确认图标可渲染。原 CSS 仍包含不存在的 `webfont.svg` 末级回退地址，但前面的本地 TTF 可用，不需要伪造该回退文件。正文采用对应页面 CSS 中的系统字体栈。手动下载内容没有独立中文正文 Web 字体；系统字体栈已保留，但具体字形会由本机 Windows/浏览器决定。因此可对齐 CSS 字体声明，不能声称已下载正文中文字库或跨系统字形绝对一致。

本机 Windows 存在 `Microsoft YaHei` 字体文件，且捕获 CSS 的候选字体栈中包含 `Microsoft Yahei`；这只能证明本机有可用候选字体且 CSS 声明已保留，不等同于浏览器已报告实际命中的字体或跨设备像素级一致。

## 已观察并保存在本地的其他资源

- `static/reference-player/avatars/`：本地聊天头像，包括机器人头像及 `u__chat_img*.jpg`。页面 fixture 只引用本地头像，不依赖线上图片服务。
- `inline-svg-1.svg`：此前页面状态中导出的内联 SVG。
- `vendor/css/modules/layer/default/` 中的 `loading-0.gif`、`loading-1.gif`、`loading-2.gif`、`icon-ext.png`：按已捕获 `layer.css` 的原始相对引用，从参考站正常 GET 获取；响应为 GIF/PNG，已存于 CSS 同目录供本地弹层使用。
- `vendor/modules/layer.js`、Layer 的图标等补件：来自本地已有的 Layui 副本，不属于 `汇博盈1_files` 手动下载包。
- `vendor/modules/layer.js` 用来满足捕获页面调用的 `layer` API；由于手动下载包缺少完整模块目录，直接沿用官方最外层 `layui.use(['layer','form','table'])` 会令回调一直等待。构建只展开该包装并绑定本地 Layer、form、table 对象，内部捕获事件处理器保持不变。`form` 没有完整官方模块，本地适配只实现捕获代码用到的 `submit(formDemo)`：同源 fixture 接收五个快捷金额并更新前端控件；`table` 仅是初始化占位。它们不等同于完整 Layui 官方模块或服务端业务。
- UI1/4 的快捷游戏入口和“界面1/界面2”切换均留在本地页面；保留 `uid=local-demo` 与 `gid` 等本地状态，不复用下载源里的上游访问链接。
- UI4 快照的开奖结果 DOM 使用 `.blueQiu`，运行脚本还包含面向另一版页面的 `.numblueHead` 更新逻辑。构建仅在旧类节点不存在时将开奖更新目标回退到快照里的 `.blueQiu`，不改写捕获 HTML，也不替换开奖展示结构。

## 未捕获与本地化边界

- 手动下载目录不包含 `layer.js`、`form.js`、`table.js`、`laytpl.js`、`laypage.js` 等完整模块文件；其中 Layer 使用本机已有副本，其他能力不可据此声称完整复刻。
- 手动下载 HTML/CSS 还引用走势弹窗精灵图 `/static/play/ball_hk6.png`；本地所有资料目录均无该文件，对页面观察到的原始静态路径执行普通 HTTPS GET 返回 `404 text/html`（此前 HEAD 检查也为 404）。该图只用于 `.zoushitu` 走势弹窗，不替换成手工绘制图案，也不影响初始聊天/快捷/流水面板；没有尝试猜测其他路径或绕过访问限制。
- Layer 样式引用的加载动画与图片导航图标已按 CSS 原路径下载到本地；走势球图 `/static/play/ball_hk6.png` 的普通 HTTPS GET 返回 `404 text/html`，走势弹窗仍缺该官方图资源，不伪造替代图。
- 页面运行时的真实接口响应、账号、会话、余额及聊天数据未作为静态资源保存；`player-local-bridge.js` 拦截本地请求并返回合成数据，所有业务操作仅为本地展示，不会连接线上接口。
- 本地构建仅移除页面快照数据、访问标识和必要的远端初始化包装；视觉和交互依据已下载客户端 HTML/CSS/脚本。无法覆盖原服务端逻辑以及未观察到的页面状态。
