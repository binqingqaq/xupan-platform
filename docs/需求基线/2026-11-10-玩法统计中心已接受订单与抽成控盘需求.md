# 玩法统计中心已接受订单与抽成控盘需求

> 状态：业务口径已由使用者于 2026-11-10 确认；尚未实施。本文作为玩法统计改造的需求依据，代码状态和验证结果以开发计划及后续验收记录为准。
>
> 范围：调整超级管理后台“玩法统计”的普通玩家订单统计口径，增加虚拟积分抽成比例设置，并依据中心已接受订单计算开奖结果后直接写入当前期七个球位预设。本文不改变中心上报、接单、额度或结算规则。

## 1. 业务目标

玩法统计要用于查看已进入中心上游的普通玩家订单风险，并按管理员设置的抽成比例计算一组当前期七球开奖结果预设，使该期中心结算净赢至少达到目标积分。计算成功后直接写入页面现有七个球位卡片的开奖结果预设；开奖仍由既有轮期流程按原时间触发。

所有金额均为虚拟积分。此功能不得引入现实资金、真实外部上游或可兑换资产语义。

## 2. 已确认规则

| 项目 | 业务规则 |
| --- | --- |
| 统计范围 | 玩法统计只统计当前期中心已接受的普通玩家订单。订单须有对应的上报记录，且该注单最新一次上报尝试为中心已接受状态；只配置网盘账号、未发起上报、上报拒绝或状态待核的订单不计入。 |
| 托单与托开关 | 托单一律不进入玩法统计、抽成基数或开奖结果计算。移除现有页面上的“托开关”，不再提供包含托单的统计模式。 |
| 抽成比例 | 新增抽成下拉选项，并允许管理员手动输入百分比数值。比例作用于当前期中心已接受普通玩家订单的下注总积分。 |
| 目标中心净赢 | 目标积分 = 中心已接受普通玩家订单下注总积分 × 抽成比例。例如下注总积分 10,000、比例 20%，目标中心净赢为 2,000。 |
| 中心结算净输赢 | 按现有中心结算规则计算：玩家输，中心收取该订单本金；玩家赢，中心赔付该订单净赢额；作和或退款的订单按既有规则处理。不可只按玩家输赢笔数或下注本金简单估算。 |
| 号码计算 | 结合本期中心已接受普通玩家订单的球位、玩法参数、下注积分和下单时赔率快照，计算一组可用的七球开奖结果，使该期中心净赢达到或超过目标。 |
| 计算结果写入 | 计算成功后，直接将七个号码写入当前页面已有的七个球位卡片预设。不是仅展示建议，也不另建一套号码输入区域。写入后仍通过既有开奖流程开奖和结算，不立即开奖或结算。 |
| 操作截止 | 距离本期开奖时间不足或等于 10 秒时，不允许执行控盘计算或保存预设。该校验必须由服务端执行，不能只依赖页面倒计时禁用按钮。 |
| 无可行结果 | 若合法开奖结果中没有任何组合能使中心净赢达到目标，不得写入部分球位或静默降低目标；应明确提示没有满足目标的可行结果，保留现有预设不变。 |

## 3. 计算与选择约束

1. 玩法排行、订单数、下注总积分、抽成目标及结果计算均只使用中心已接受的普通玩家订单；托单、未上报、拒绝、待核订单不得显示或影响目标及选出的开奖结果。
2. 按当前彩种及当前期的开奖规则校验结果号码。AU8 当前规则要求七个号码在 1～40 范围内且互不重复；其他彩种按各自已确认规则处理。
3. 结果应满足“中心净赢不少于目标”。多个结果均满足时的优选/平局策略属于实施设计，须按玩法空间和计算方案确定，不改变“不低于目标”的业务条件。
4. 计算必须使用持久化注单、赔率快照和中心订单状态，服务端完成；不得将注单明细下载到浏览器后计算。
5. 写入七个预设值应作为一个完整操作处理：期号已变化、订单集合或状态不满足快照条件、开奖已确认、进入最后 10 秒或任一号码校验失败时，整次拒绝，不得留下部分球位更新。
6. 操作应记录操作者、期号、抽成比例、目标积分、参与订单口径摘要、计算出的七球结果、计算净赢和写入时间；日志不得包含敏感凭据或不必要的玩家身份明细。

## 4. 页面与权限

- 在现有玩法统计页面增加抽成比例选择控件，并提供手动输入百分比的方式。
- 删除现有“托开关”控件及其前端状态/请求参数；玩法统计页面不提供托单统计入口。
- 页面继续使用已有七个球位卡片和逐球预设状态；计算成功后更新这七个卡片的预设号码。
- 计算前应展示或确认当前期、中心已接受普通玩家订单下注总积分、抽成比例和目标中心净赢，避免用户对计算基数产生误解。
- 复用当前玩法统计查看权限和开奖结果预设管理权限的职责边界；控盘计算及写入必须要求预设管理权限。
- 保存成功后明确反馈抽成比例、目标中心净赢、计算结果及按现有结算规则估算的中心净赢。

## 5. 明确不在本需求内

- 不改变网盘账号配置、自动上报开关、中心账号绑定、订单受理或中心额度规则。
- 不把“已填写网盘账号”当作订单已上报或已接受的证据。
- 不改变托单的生成、上报隔离或本地结算行为；本需求只要求托单不进入玩法统计，并移除玩法统计页的托开关。
- 不提前开奖、不手工改写开奖结果确认状态、不跳过当前期的原定开奖时间。
- 不新增真实资金、支付、提现、外部上游连接或现实代理分成能力。
