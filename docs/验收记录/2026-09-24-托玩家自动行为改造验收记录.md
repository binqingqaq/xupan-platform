# 2026-09-24 托玩家自动行为改造验收记录

> 验收对象：托的自动行为（链接前提、期内随机时间、玩法与金额约束、活跃比例、全局风控、随机上分）
>
> 证据等级：本机后端 H2/Flyway、本机前端构建与类型检查、本机 MySQL 运行态；不是服务器或生产验收。

## 1. 验收范围

- 链接是托的工作前提：拉黑/过期/停用/删除后不产生动作，已有动作按原因码收尾。
- 期内随机时间下注：计划持久化、到期才执行、封盘与跨期收尾。
- 自动模式不发送闲聊消息；下注反馈保留。
- 下注范围档位、金额整十（整数）、指定玩法集合与玩法弹窗。
- 活跃比例 A+B 口径；每期注单数量控制。
- 所有托每期总注单/总积分上限；深夜活跃比例覆盖。
- 余额不足降额下注；随机上分申请进入后台审批队列。
