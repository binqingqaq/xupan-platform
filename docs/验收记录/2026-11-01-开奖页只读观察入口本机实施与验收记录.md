## 1. 已实施范围

- V105 建立单例 `display_observer_binding` 和追加式 `display_observer_binding_audit`，保存固定机器/展示托、状态、地址标识、版本和操作审计。机器/玩家物理删除时外键解除绑定对象，公开入口无法解析，不自动换绑。
- V106 增加 `DISPLAY_OBSERVER` 会话模式、`DRO:<publicId>` 范围和独立入口标识；原有 `PLAYER_FULL` 会话范围继续保留。
- 超级后台 `/platform-admin/settings` 增加独立的开奖页只读入口设置。机器和展示托候选受有效状态、同机归属和手动行为约束；支持单次绑定、启停、复制、换链及禁用后的紧急重绑。普通设置保存不覆盖绑定；绑定中的展示托不能切换为自动行为。
- 公开开奖页通过同源只读接口获取入口状态，只有 AU8/快乐8的期号文本在绑定有效时变为可点击链接；保留原卡片数据和样式。旧公开链接在停用、换链和对象失效后不能继续兑换观察会话。
- 观察会话只读取绑定机器的 `main` 聊天室、AU8 信息和固定展示托的账户数据；聊天发送、已读游标、下注、设置及其他写操作受服务端拒绝。WebSocket 仅允许同机只读订阅，连接上限独立于机器托的正常会话。
- 新增前端 `/display/observe/:publicId` 和玩家观察模式，保留聊天、快捷和账户阅读视图，移除可发送/下注/修改的控件。

## 4. 待使用者人工验收

本地开发入口：`http://127.0.0.1:8080/display/mobile`。现在没有有效绑定，所以期号标题不会跳转；按下列步骤操作后再验收完整体验：

1. 使用超级管理员登录 `/platform-admin/settings`，选择专用机器和该机器下已关闭自动行为的展示托，绑定并启用入口。
2. 检查管理页身份、绑定状态、复制地址；另开浏览器窗口验证外发链接打开的是只读观察身份。
3. 从 `/display/mobile` 点击快乐8期号，检查原有号码颜色、间距、七球数据及期号末三位显示没有变化，并进入同一观察地址。
4. 检查展示托账户/个人注单/虚拟积分流水和同机聊天室消息；检查快捷面板可读但无下注键盘，聊天区无输入发送控件。
5. 观察期间检查展示托没有自动新单；同机其他自动托照常运行。若页面行为与该结果不符，先停用入口并记录时间/账号供排查。
6. 停用或换链后重开旧地址，确认旧会话失效；确认绑定托的自动模式仍被禁止。

以下项不能由本轮未绑定数据证明：管理员真实操作、展示托真实账单、跨机器私有消息隔离、带鉴权 WebSocket 实时消息及重连、多个访客刷新不写业务事实、桌面/手机视觉、外部设备打开、专用托自动任务和其他托不回归。服务器/生产迁移、部署和安全现场检查未执行。

## 5. 数据与权限边界

- 展示对象继续归属其原子账号和机器；本功能只提供独立公开只读身份，不复用或撤销 `PLAYER_FULL` 玩家链接。
- 展示账户、下注、结算和盈亏仍是虚拟积分，不新增现实资金能力。
- 公开地址持有者可读取绑定范围内的数据；地址标识不写入普通请求日志，错误消息不回显地址。
- 没有提交、服务器发布或生产操作。隔离构建输出留在被忽略的本机 `tmp/` 目录。
