# BY220 超级管理后台子账号过期、机器权限与安全删除验收记录

> 验收日期：2026-10-02
> 对应范围：BY220 `Login.php`、`Sub.php`、`Users.php::add/userDel`、`Rb.php::GetUserList/UpdatePanStatus`
> 当前结论：H2 与前端全量通过；本机 MySQL 8.4.11 迁移与关键运行态通过；服务器和生产未验证。

## 1. 已实现

- 子账号密码校验通过后检查 `agent_group.expires_at`；过期返回 `AUTH_SUB_ACCOUNT_EXPIRED`，延长失效时间后立即可以重新登录。
- 已有 access token 在每次请求重载用户时再次检查子账号分组状态、软删除状态和失效时间；过期或删除后立即失效。
- `agent_group.machine_manage=false` 时动态移除有效 `MACHINE_MANAGE`，机器菜单和机器 API 同步关闭；开启后恢复。
- 平台后台登录页接受具有 `PLATFORM_HOME_READ` 的子账号，平台后台会话过期跳转固定回 `/platform-admin/login`。
- 子账号和机器新增 BY220 对应“删除”按钮；内部采用软删除、会话撤销和操作审计，不物理删除历史钱包、注单和审计事实。
- 子账号仍有机器时删除返回 `SUB_ACCOUNT_HAS_MACHINES`；机器仍有玩家或托时删除返回 `MACHINE_HAS_PLAYERS`，不级联删除业务数据。
- 失效时间超过 MySQL `TIMESTAMP` 可用范围时，服务端在写库前返回 `PLATFORM_ADMIN_EXPIRY_OUT_OF_RANGE`，前端 `datetime-local` 同样限制最大值。
- Flyway `V50` 为 `agent_group` 和 `agent` 增加 `deleted_at`、`deleted_by` 及存活索引。

## 2. 已执行验证

- 后端全量 H2/Flyway：`315` 个测试通过（`mvnw test`）。
- 前端 Vitest：`30` 个测试文件、`118/118` 通过。
- 前端 `typecheck` 和 `vite build` 通过。
- 本机 MySQL `8.4.11` 从 V49 迁移至 V50；Flyway 成功应用迁移，服务在 `18080` 健康启动。
- 运行态验证：过期子账号登录 `401/AUTH_SUB_ACCOUNT_EXPIRED`；延长后登录 `200`；`machine_manage=false` 时 `MACHINE_MANAGE` 不存在且机器 API 返回 `403`；开启后恢复且机器 API 返回 `200`。
- 删除运行态验证：2099 失效时间返回 `400/PLATFORM_ADMIN_EXPIRY_OUT_OF_RANGE`；有机器时子账号删除返回 `409/SUB_ACCOUNT_HAS_MACHINES`；空机器删除返回 `204`；空子账号随后删除返回 `204`；删除后机器和子账号登录均返回 `401`。
- 验证创建的临时子账号、机器、会话、登录日志和操作审计已清理。
