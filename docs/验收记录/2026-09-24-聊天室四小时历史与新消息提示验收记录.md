# 2026-09-24 聊天室四小时历史与新消息提示验收记录

> 验收对象：玩家聊天室历史消息窗口和新消息提示
>
> 证据等级：前端单元测试、构建和本机浏览器；不是服务器或生产验收。

## 1. 验收范围

- 最近4小时历史消息。
- 向上滚动自动加载更早消息。
- 加载后阅读位置保持。
- 4小时边界状态。
- 右下角新消息气泡。
- 点击气泡返回最新聊天节点。

## 2. 已执行检查

- 前端 Vitest：18 个文件、`94/94` 通过。
- `vue-tsc --noEmit`：通过。
- Vite 生产构建：通过。
- `chatHistory.test.ts` 覆盖4小时边界、滚动位置恢复和消息标签。
- 浏览器实测：
  - 初始加载后可以持续向上浏览。
  - 自动加载后消息数量增加，当前可见位置未跳到顶部或底部。
  - 达到4小时边界后显示`已显示最近4小时消息`。
  - 第二个玩家会话发送消息后，历史视图右下角出现`▼ 1条新消息`。
  - 点击提示后回到消息底部，提示消失。

## 3. 未执行检查

- 服务器和生产环境。
- 超大消息量、长期运行和弱网连续分页。
- 多实例连接和消息保留清理策略。

## 4. 已知边界

- 4小时窗口按服务端时间计算。
- 历史分页复用现有聊天接口，不新增数据库表。
- 4小时之前的消息仍保留在数据库中，只是当前玩家大厅不继续向上展示。

## 5. 结论

本机环境下，最近4小时历史、自动向上分页和新消息浮动提示已形成可重复证据；服务器和生产验收仍待后续执行。
