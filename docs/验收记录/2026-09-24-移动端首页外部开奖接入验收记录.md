# 移动端首页外部开奖接入验收记录

## 验收范围

- 唯一展示入口：`http://localhost:8080/display/mobile`
- 旧桌面入口：`/display` 自动跳转到 `/display/mobile`，不再展示桌面首页
- 数据范围：移动端首页 15 张开奖卡片、期号、号码、生肖、五行、大小、单双、冠亚和、总分和倒计时
- 不包含：登录、投注、新闻、彩票大厅、更多菜单和其他子页面

## 已实现

| 项目 | 结果 |
| --- | --- |
| 桌面页面移除 | 已删除桌面页面、桌面专用样式和资源映射 |
| 移动端入口 | 保留 `/display/mobile` |
| 旧入口处理 | `/display` 跳转到 `/display/mobile` |
| PC 入口按钮 | 移动端头部桌面版按钮已移除 |
| 外部开奖请求 | Spring Boot 服务端直接请求外部热门彩种接口 |
| 当前项目接口 | 新增公开只读 `GET /api/display/mobile/home` |
| 数据映射 | 15 个彩种按首页顺序映射 |
| 快照持久化 | Flyway V29 新增移动端展示开奖快照表 |
| 失败恢复 | 外部接口失败时返回最近一次成功快照 |
| 前端刷新 | 每 5 秒刷新数据，倒计时每秒本地更新 |
| 首页轮播 | 4 张宣传图每 5 秒自动循环，支持左右滑动和指示器手动切换 |

```text
npm run build
```

结果：类型检查通过，18 个测试文件共 95 个测试通过，生产构建通过。

### 后端

```text
.\mvnw.cmd -q test
```

结果：完整后端测试退出码为 `0`，Flyway 迁移版本更新为 V29。

### 本机 MySQL 8.4

结果：

- 服务成功启动在 `8080`
- Flyway 校验 29 个迁移
- 本机 MySQL 8.4 schema 版本为 `29`
- 外部开奖接口匿名请求成功
- 当前项目接口返回 HTTP `200`
- 返回 `stale=false`，15 张卡片均为实时数据
