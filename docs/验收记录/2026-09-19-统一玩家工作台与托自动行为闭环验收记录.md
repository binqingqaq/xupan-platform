# 统一玩家工作台与托自动行为闭环验收记录

## 1. 验收范围

本次验收覆盖统一玩家分类、后台左右工作台、普通玩家复用创建、托创建、虚拟积分操作、托行为配置、动作持久化、聊天/下注正式服务入口和前端构建产物。

所有积分均为虚拟积分。未新增充值、支付、提现、转账、代理分成或现实资金能力。

## 2. 已实现内容

- 路由 `/admin/test-players` 保留，页面改为“玩家工作台”；普通玩家与托集中在同一左列表、右详情布局。
- 总积分、普通玩家数量、托数量由后端聚合查询返回，不由分页结果或前端数组计算。
- 普通玩家创建调用 `UserAdminService.createUser`；托创建调用既有测试玩家创建服务并标记 `player_kind=BOT`。
- Flyway V16 增加 `player_kind`、`test_player_behavior`、`test_player_action`，历史 `TEST` 身份回填为 `BOT`，普通账号默认 `NORMAL`。
- 托自动动作和工作台手工消息先写动作表，再调用 `ChatMessageService.sendUserMessageWithOutcome`，沿用正式下注、钱包扣款、幂等和反馈链路。
- 动作执行包含 `PENDING/PROCESSING/SUCCEEDED/SKIPPED/FAILED`、唯一幂等键、条件认领、租约过期恢复和错误记录。
