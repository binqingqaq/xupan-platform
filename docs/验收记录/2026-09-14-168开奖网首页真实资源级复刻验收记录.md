## 5. 仍存在的差异和边界

- 主横幅仍使用第一阶段自制静态 SVG，因为参考首页横幅内容由动态焦点图接口提供，本轮没有下载动态广告或运行时接口响应。
- 右侧浮动工具仍使用页面专用 CSS 图形，没有复制参考站点的完整 Sprite 和客服接口。
- 彩种期号、号码、新闻和倒计时仍为静态演示值，不代表真实开奖数据。
- 资源清单中的参考图片均为 B 类，公开可访问不等于获得版权或商用许可；正式部署前必须取得授权或替换为项目自有素材。
- 当前 8080 服务是修改前启动的旧进程，仍返回 401；新配置已编译通过，但由于本机默认 MySQL 凭据缺失，无法启动第二个 Spring Boot 实例进行端到端 HTTP 验证。重启正式服务后应再次验证 `/display` 和 `/display/reference/brand/logo.svg` 为 200。
- 移动端未纳入本轮验收。

## 6. 结论

本轮已完成“真实资源级桌面静态复刻”代码和资源接入，满足本地评审条件；不应将其视为已获得正式资源授权，也不应将静态展示数据视为后端业务闭环。下一阶段应先由用户确认视觉效果和素材授权，再决定是否替换主横幅、清理未使用占位资源或进入移动端/后端数据开发。
