# 后台界面复古运营台重构验收记录

## 1. 验收范围

本次改造覆盖后台前端壳层和视觉层：

- `/console` 主控制台。
- 玩家工作台。
- 欢迎控制、赔率控制、报网控制、下注榜、上下分确认、最近上下分记录、线路域名、底部控制等已嵌入面板。

- 后台主题类、共享 CSS 和构建产物更新。

- Flyway、数据库表结构、钱包、积分、下注、开奖和结算规则。
- 玩家、托、服务端机器人的身份和业务语义。
- 所有现有测试依赖的接口调用、事件、表单字段、校验和业务文案。
- 未新增充值、支付、提现、转账、代理分成或现实资金能力。

## 4. 页面上线关注项

- 后台继续采用 1000px 桌面设计宽度，手机端由浏览器整页缩放查看；该模式保证同构，但输入、表格和按钮的触控尺寸可能偏小。
- 长列表和宽表格应在自身容器内滚动，避免撑宽后台页面。
- 构建后的 `index.html` 必须与新增的哈希 JS/CSS 资源一起提交或部署，不能只提交 `index.html`。
- `AdminDomainFooterPanel.vue` 中的线路域名和登录链接是既有静态占位内容，本次未新增、未扩展实际外部跳转能力。
