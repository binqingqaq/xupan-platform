>

>
> 结论：H2/Flyway、前端测试与构建、本机 MySQL V47→V48 和真实 API 运行态已验证；服务器和生产未验证。

## 1. BY220 依据

- 页面控制器：`application/admin/controller/Tongji.php::GetYingKui`
- 计算函数：`application/common.php::getRecordData`、`getShuang`、`getShuangs`
- 模板：`application/admin/view/tongji/index.html`

BY220 口径：

- 总流水为已结算注单的投注额合计。
- 单边流水获胜时累计 `yingScore`；当前结构化模型映射为普通玩法净收益、特殊玩法返还额。
- 双边流水获胜时按玩法折算，失败时累计有效投注额；通类按一半，车类失败按投注额。
- 反水按 `fanshui / 100` 计算；普通获胜玩法以净收益为基数，特殊玩法以投注额为基数并使用 `teFanshui`。
- DRAW 不计双边流水和反水。

## 2. 已完成
