# BY220 超级管理后台游戏设置验收记录

> 验收日期：2026-10-02
>
> 范围：BY220 `admin.php` - 游戏设置第一版。
>
> 结论：H2/Flyway、前端测试与构建、本机 MySQL V42→V43 和页面/API 运行态已验证；当前仅支持主彩种 AU8，服务器和生产未验证。

## 1. BY220 依据

- 页面控制器：`application/admin/controller/Game.php`
- 列表模板：`application/admin/view/game/index.html`
- 表单模板：`application/admin/view/game/form.html`、`form1.html`
- 数据表：`x_rbgame`
- 隐藏赔率表：`x_rbwppl`

BY220 实际开放字段：

- 彩种名称、彩种键名、开奖球号、采集链接、排序。
- 算法：相拼/相加。
- 玩法前缀、是否切换、显示特、特模型、显示键盘、状态。

BY220 操作：添加、刷新、编辑、删除和状态开关。

## 2. 已完成

- Flyway V43 新增 `game_definition` 和主彩种记录 `AU8`。
- 新增权限 `GAME_SETTINGS_READ`、`GAME_SETTINGS_WRITE`。
- 新增 `/platform-admin/games`，菜单名称保持“游戏设置”。
- 页面列、编辑字段和操作位置按 BY220 模板实现。
- 当前单彩种引擎只真实支持 AU8 编辑；添加和删除按钮保留位置但明确禁用。
- `x_rbwppl` 的 A-D 盘隐藏赔率字段不开放。
- 采集链接只做 `http/https` 保存和校验，不主动请求外部地址。
- 关闭状态后会由服务端拒绝新下注。
- 算法、球号、玩法前缀、是否切换、特模型等真实持久化；当前引擎尚未消费的多彩种能力在页面明确提示。
- 更新使用版本号并发保护并写操作审计。

## 3. 接口
