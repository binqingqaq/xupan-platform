> 文档效力：本文是验收当时的证据快照，不是当前状态入口。文中的测试计数、Flyway 版本、默认行为、未完成项和页面结论只代表该次验收时点；当前基线以 [文档索引](../文档索引.md)、[模块状态矩阵](../模块状态矩阵.md) 和 [BY220 平移 DeepSeek 桌面端 Agent 交接](../交接/2026-10-02-BY220平移-DeepSeek桌面端Agent交接.md) 为准。

> 范围：BY220 admin.php 的“子账号”和“机器管理”独立页面、API、数据库字段与权限。
>
> 结论：H2、前端构建和本机 MySQL 8.4 已验证；服务器和生产未验证。

## 1. 已完成

- 新增 Flyway V35，扩展子账号和机器账号字段。
- 新增权限：SUB_ACCOUNT_MANAGE、MACHINE_MANAGE。
- 子账号和机器管理从原来的合并页拆成独立路由。
- 平台管理顶部菜单中“子账号”和“机器管理”分别进入独立页面。
- 子账号支持列表、新增、编辑、启停、权限、积分、失效时间、网盘和盘口字段。
- 机器账号支持列表、新增、编辑、启停、所属子账号、积分、开盘、托数量、封盘、取消、返水、赔率和限额字段。
- 机器账号支持查看所属玩家列表。
- 机器账号继续作为代理登录 /agent 的实际身份。

## 2. 页面

- /platform-admin/sub-accounts
- /platform-admin/machines

## 3. 接口

- GET/POST /api/admin/sub-accounts
- PUT /api/admin/sub-accounts/{id}
- PATCH /api/admin/sub-accounts/{id}/status
- GET/POST /api/admin/machines
- PUT /api/admin/machines/{id}
- PATCH /api/admin/machines/{id}/status
- GET /api/admin/machines/{id}/players
