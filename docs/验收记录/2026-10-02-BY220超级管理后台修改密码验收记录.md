## 1. BY220 依据

- 页面控制器：`application/admin/controller/Pwd.php`
- 模板：`application/admin/view/pwd/setting_list.html`
- 保存接口：`Pwd.php::ModifyPwd`

BY220 页面字段和操作：

- 旧密码、新密码、确认密码。
- 登录账号：仅用户 ID 为 1 的超级管理员可修改。
- 提交成功后提示“修改成功, 请重新登录!”并退出到登录页。

## 2. 已完成

- Flyway V44 新增权限 `PLATFORM_PASSWORD_MANAGE` 并授予 ADMIN 角色。
- 新增 `/platform-admin/password`，菜单名称保持“修改密码”。
- 页面按 BY220 三密码字段和超级管理员登录账号修改规则实现。
- 修改密码校验旧密码，新密码和确认密码必须一致。
- 新密码遵守当前正式密码安全策略。
- 只有超级管理员 ID 1 可以修改登录账号；其他管理员只能修改自己的密码。
- 修改成功后提升 `security_version`，旧会话全部失效并回到登录页。
- 操作审计只记录是否修改账号和密码，不记录密码内容。

## 3. 接口

- `GET /api/admin/password`
- `PUT /api/admin/password`
