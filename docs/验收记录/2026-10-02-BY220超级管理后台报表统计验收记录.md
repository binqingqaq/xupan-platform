# BY220 超级管理后台报表统计验收记录

> 验收日期：2026-10-02
>
> 范围：BY220 admin.php - 报表统计的积分流水和盈亏报表第一版。
>
> 结论：H2、前端构建和本机 MySQL 8.4 已验证；双边流水、反水、服务器和生产未完成。

## 1. 已完成

- 新增权限 REPORT_READ。
- 新增 /platform-admin/reports 页面。
- 支持日期开始/结束、子账号筛选、今天/昨天/本周/上周快捷查询。
- 积分流水读取 demo_balance_ledger。
- 盈亏报表按机器账号汇总：
  - 昨余 = 机器积分 + 当前玩家余额。
  - 流水 = 区间内注单 stake 合计。
  - 单边流水 = 赢单按 stake × odds 快照、输单按 stake 的合计。
  - 盈亏 = 区间内玩家净盈亏的反向值。
  - 上分/下分/上下 = 管理员积分流水汇总。
- 飞单记录页明确标记为未接入，不展示模拟数据。

## 2. 接口

- GET /api/admin/reports/score-flow
- GET /api/admin/reports/profit
