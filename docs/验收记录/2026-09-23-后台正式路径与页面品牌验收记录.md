# 后台正式路径与页面品牌验收记录

## 1. 验收范围

- 后台管理正式前端入口从 `/admin` 调整为 `/console`。
- 旧 `/admin/*` 地址保留自动跳转兼容。
- 后台页面标题统一为“AI模型房间管理”。
- 玩家下注页和玩家链接入口标题统一为“奥巴AI”。
- 全站 favicon 使用 `web/public/display/picture/favicon.ico`。

## 2. 实现结果

| 路径 | 页面 | 标题 |
| --- | --- | --- |
| `/console` | 统一管理后台 | AI模型房间管理 |
| `/console/operations` | 旧运营兼容页 | AI模型房间管理 |
| `/console/users` | 用户管理 | AI模型房间管理 |
| `/console/players` | 玩家工作台 | AI模型房间管理 |
| `/console/robots` | 服务端机器人管理 | AI模型房间管理 |
| `/room` | 玩家完整前台 | 奥巴AI |
| `/player-login`、`/33/**` | 玩家链接登录和前台 | 奥巴AI |

旧路径兼容：

```text
/admin                 -> /console
/admin/operations      -> /console/operations
/admin/users           -> /console/users
/admin/test-players    -> /console/players
/admin/robots          -> /console/robots
```

## 3. favicon

`web/index.html` 已声明：

```html
<link rel="icon" type="image/x-icon" href="/display/picture/favicon.ico" />
```

构建后 Spring Boot 静态资源返回：

- `/display/picture/favicon.ico`：HTTP 200，15406 bytes。

- 登录页标题为“AI模型房间管理”。
- `/console` 和旧 `/admin` 的 Spring Boot SPA 入口均返回 HTTP 200。
- favicon 请求返回 HTTP 200。
