## 验收范围

本次收尾覆盖中心订单对账、未知结果恢复、代理对中心撤单/退款的本地注单人工结论、对账运行指标、前端视图、本机数据库兼容和本地服务重启。依据[需求基线](../2026-10-23项目二次改进/2026-10-23-中心上游报网闭环需求基线.md)和[开发计划](../plans/2026-10-24-中心上游报网闭环重整开发计划.md)执行。金额仍仅表示虚拟积分；中心由同进程内部逻辑承接，不接真实外部上游。

## 本次完成

- 对账键使用中心账号与 `BET-<betId>`，避免不同中心账号的相同本地注单号串单；同一中心账号内按注单取最新上报尝试。
- 管理端对账可按中心账号和期号筛选；差异行显示账号、期号，并按中心账号识别处置记录。
- 对账汇总呈现风险预留、中心/机器冻结、双层结算金额、单边结算、中心账本净额及应有值、退款/撤单金额和不一致数量。`balanced` 同时检查逐笔差异、未解决项、中心/机器账本链、订单引用的冻结/释放/结算分录和结算方向。
- 运行指标新增中心待核实/超时订单、单边结算、中心账本不一致层数和机器积分账本不一致数量。
- 主库只读核对曾发现一笔旧风险版本退款单：`risk_amount=0`、冻结快照 400、退款处置 400。旧终态单缺少 V92 风险版本快照，因此对账按冻结额加机器补足快照计算旧风险；新增用例后验证不再误报。
- 用户确认中心撤单/退款后的代理处理规则，并落地到机器报网订单面板：`KEEP_LOCAL` 保留本地注单和玩家余额，继续本地结算；`REFUND_CANCEL_LOCAL` 按下注本金退款并取消本地注单。两种结论都必填原因，持久记录操作者、时间、中心结果和选择，并写操作审计。退款用独立幂等键，同一请求重放不重复退款；已选结论不能改成另一种。该代理操作只影响本机玩家本地注单，不修改中心订单或中心额度。
- V97 增加 `report_local_disposition`，并在报网订单列表区分中心结果与本地处理结论；接口校验机器归属、中心终态和本地未结状态。代理机器只能处理本机数据。

### P6 V95 迁移权限门禁

- 在本机新建隔离 schema `xupan_v95_gate_20261027172642_52c71d3d`，由 DBA 账号通过 Flyway 从 V94 完成迁移，history 为 `94/1`。本机 MySQL 为 `8.4.11`，只读观察到 `log_bin=1`、`log_bin_trust_function_creators=0`，未修改全局变量。
- 对该 schema 的临时 app-like 账号有 schema 范围 DDL 权限、无全局 `SUPER` 权限。该账号运行 Flyway V95 失败，MySQL 返回 `SQL State HY000`、错误码 `1419`：`You do not have the SUPER privilege and binary logging is enabled (you might want to use the less safe log_bin_trust_function_creators variable)`。Flyway history 记录 `95/0`，没有留下部分触发器。
- DBA 在该临时 schema 对 V95 失败记录执行 Flyway repair，再完成 V95、V96；history 分别为 `95/1`、`96/1`，两个 V95 触发器均存在。随后撤销临时账号原有权限，仅授予 `flyway_schema_history` 的 `SELECT`；该低权限账号成功读取 V95/V96 成功状态并执行只读 `SELECT 1`。
- Flyway 11.14.1 对 MySQL 8.4 输出“最高验证到 8.1”的兼容性警告，但上述迁移和版本读取均实际成功。测试结束后删除本轮临时 schema 和账号，余量均为 0。
- 结论仅证明本机隔离库可采用受控 DBA 前置迁移并由应用式低权限账号读取迁移状态；不证明服务器/生产 DBA 流程或生产部署已验收。

测试使用本轮新建的隔离数据库和只获该库权限的临时账号。测试完成后已删除该数据库与账号；持久化本机 `xupan_platform` 未用于本次集成测试。

JOIN` 语法兼容错误，测试方法及断言没有执行；这是 H2 无法执行 MySQL 专用迁移语法，不是对账断言失败。最终代码随后已在隔离 MySQL 8.4.11 新库迁移至 V97，并实际运行 `CenterReconciliationControllerTest` 23/23、`ReportConsoleTest` 11/11 和 `ReportProcessRestartRecoveryTest` 1/1，均 0 skipped。Maven `test-compile` 另编译成功 259 个主源码和 115 个测试源码。

新增回归覆盖未解决项、中心/机器余额公式及相邻流水连续性、受理冻结、退款/撤单释放、机器风险预留/释放、结算分桶以及玩家/中心结算方向。结算错桶用例保持汇总净额和各桶余额链自洽，但将扣减记入错误桶，验证逐订单分录核对仍会阻止 `balanced=true`。
