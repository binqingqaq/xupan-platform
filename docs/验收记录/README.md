# 验收记录目录规则

验收记录只记录已经执行过的证据，不把计划、推断、模拟数据或未执行环境写成事实。

> 所有验收记录都是**执行当时的证据快照**，不是当前实现状态的总入口。记录中的测试计数、Flyway 版本、默认行为、未完成项和页面状态不能被后续读者当作当前结论；当前状态先看 [文档索引](../文档索引.md)、[模块状态矩阵](../模块状态矩阵.md) 和 [DeepSeek 桌面端 Agent 交接](../交接/2026-10-02-BY220平移-DeepSeek桌面端Agent交接.md)。

## 证据等级

| 等级 | 可以证明 | 不能替代 |
| --- | --- | --- |
| 静态检查 | 文件、配置、差异和文档格式 | 运行时行为 |
| H2/单元集成测试 | 领域逻辑、迁移和测试上下文 | MySQL、网络、服务器和生产 |
| 本机 MySQL 8.4 | 本机真实数据库迁移和接口链路 | 服务器和生产 |
| 服务器现场 | 目标服务器部署和运行态 | 正式生产长期稳定性 |
| 生产验证 | 正式环境操作和运维结果 | 未覆盖的容量、灾备和长期观察 |

每份记录必须包含：验收范围、执行命令或入口、结果、环境、未执行项和不能推出的结论。
