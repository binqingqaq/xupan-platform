# 运维可观测性与日志体系验收记录

## 1. 验收范围

本轮依据 [运维可观测性与日志体系开发计划](../plans/2026-09-14-运维可观测性与日志体系开发计划.md) 实现单服务器、单 Spring Boot 实例的基础日志、请求关联、异常记录、健康检查、指标和部署模板。

## 2. 已实现内容

- 请求观测过滤器统一生成或透传 X-Request-Id，并写入响应头、MDC 和访问日志。
- 认证异常和未预期异常记录 HTTP 方法、路径、requestId、异常类型和堆栈。
- 生产 profile 使用控制台加滚动文件日志，默认单文件 50MB、历史 30 天、总容量 2GB。
- 日志 pattern 对 password、access_token、refresh_token、authorization、cookie、ticket 等字段做脱敏。
- 暴露 health、info、metrics；health 可用于存活检查，info 和 metrics 受 SYSTEM_MONITOR_READ 权限保护。
- 新增机器人调度、聊天室连接、outbox 和 dispatch pending/failed 指标。
- 新增 systemd、healthcheck、journald 配置示例和故障排查手册。

## 4. 尚未执行的现场验证

以下事项没有在本轮自动化测试中冒充已完成：

- 真实服务器上的 systemd 单元安装、enable 和 timer 启用。
- 真实服务器上的应用日志滚动、journald 持久化和磁盘空间验证。
- 真实服务 kill/restart、JVM 崩溃文件和重启恢复演练。
- 外部监控平台、短信、邮件或企业 IM 告警联动。
- HTTPS、反向代理和公网环境下的完整观测链路。

这些事项需要在确认维护窗口和服务器变更授权后单独执行。

## 5. 结论

代码、配置、测试和排障文档已形成可维护的基础观测闭环；当前可以支持本机或后续单服务器部署的健康检查、日志检索、requestId 关联和核心业务指标查看。服务器级安装、故障演练和外部告警仍是后续运维验收项。
