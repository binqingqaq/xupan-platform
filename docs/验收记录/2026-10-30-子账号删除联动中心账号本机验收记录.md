# 子账号删除联动中心账号本机验收记录

> 日期：2026-10-30；范围：本机源码、独立 MySQL 测试库与前端自动化。未操作本机业务库中的真实子账号或中心账号，未部署服务器或生产。

## 需求与实现

- 用户确认：删除子账号时，连同其专属中心账号、中心订单、额度流水、会话、风控/处置和上报数据全部物理删除；机器、玩家/托、注单和积分流水按原有子账号删除语义清理。独立删除中心账号继续保留本地机器及玩家数据。
- BY220 静态对照：`application/admin/controller/Users.php:231-245` 的 `userDel` 删除子账号和机器、玩家相关数据；`application/admin/view/sub/list.html:107-114` 有二次确认。BY220 没有 Xupan 中心承接侧。尝试访问本机 `http://127.0.0.1/admin.php` 得到 404，未执行 BY220 实际删除操作，不将源码对照写成运行态验证。
- `CenterUpstreamAccountService` 抽取共用中心清理核心；独立删除继续拒绝无法归属的旧报网尝试并保留本地账务，子账号联动删除跳过该阻断并清除整组下属数据。`AccountPurgeService` 锁组、双向检查跨组引用，按中心账号 → 会话/机器 → 玩家/注单 → 子账号的外键顺序删除。任何后段异常由事务整体回滚；单机器与删除全量账号入口同步调整清理顺序。
- 子账号删除确认提示列出中心账号、上报数据、机器和玩家；越组归属冲突显示中文错误。没有新增数据库结构或 Flyway 迁移，复用 V89、V94、V97 的外键与现有索引。
