## 实施结果

- `/platform-admin/**` 共用导航在 767px 以下显示菜单按钮、当前页名、安全退出；抽屉菜单复用 `visibleItems` 权限过滤、原顺序和原路由跳转。桌面仍使用现有横向菜单。
- 子账号在窄屏使用信息卡片，显示用户名、状态、积分、失效日期、机器数量、子账号权限、机器人权限及编辑/启停/解锁/删除操作。新增/编辑表单窄屏单列，桌面表格保留。
- 机器管理在窄屏显示账号、子账号、积分、失效日期、下注开关、玩家/托数量；展开配置可查看桌面机器表格全部字段。编辑、玩家、复制登录链接、启停/解锁、删除沿用既有 handler。玩家列表窄屏显示昵称、编号、类型、余额、状态。
- 平台管理对话框在手机变为全屏并保留内部滚动，固定动作区考虑安全区。开奖信息球号允许换行；开奖历史、报表、订单、在线玩家、设置等表格限制在各自容器滚动。
- 正式 `/platform-admin/**` viewport 仍为 `width=device-width, initial-scale=1.0`，浏览器缩放没有被禁用。旧 `/admin/**` 兼容地址原有 viewport 行为未修改。
- 未修复开奖数据 `null`；该数据问题不属于页面布局。

## 本机访问与边界

- 后端 `/actuator/health` 返回 `UP`。
- 局域网 Vite `http://192.168.43.59:5175` 下 15 个 `/platform-admin/**` 与登录 SPA 路由均返回 HTTP 200。该地址要求手机与开发机处于同一 Wi-Fi/可互通局域网；HTTP 200 只证明 SPA 路由可加载，不证明登录后的页面交互通过。
- 本机尚无自动化浏览器驱动；本次未执行 Android Chrome / 内置浏览器 / iOS Safari 登录后截图、点击/软键盘/缩放验收。预览登录后的列表视图需使用者在手机完成认证后查看。
- BY220 源码已核对；本机 BY220 未登录请求重定向到登录页，因此不记录登录后运行操作通过。
- 未执行服务器或生产部署与验证；本机测试不构成服务器/生产验收。

## 手机反馈后的二次整改

使用者对首轮部署版本实测发现顶部导航双显叠字、开奖历史固定操作列遮挡字段。当前源代码核对到的直接原因是：手机媒体查询此前没有隐藏桌面导航容器；开奖历史在窄屏仍保留固定右侧操作列。首轮测试数字只对应首轮代码，不能覆盖此次重做。

已在本机源码完成二次实现：

- 手机断点显式隐藏桌面导航，桌面/手机导航不再同时显示；侧栏弹层改为 Teleport 到 body。
- `usePlatformAdminMobile` 统一管理 767px 断点及窗口尺寸变化；所有已适配页面通过条件渲染保证手机卡片和桌面表格只挂载一套。
- `PlatformAdminMobileRecordList` 作为 Sub2API DataTable 卡片模式的 Vue/Element Plus 对应实现，提供加载态、空态、字段标签和值、详情和行内动作。
- 开奖历史/投注记录、未结订单、订单改单、在线玩家、网盘设置、游戏设置、报表三页签、中心账号/会话/实时订单/处置记录/流水均有手机记录卡；路字图保留独立横向滚动区，玩法统计球位改手机两列。
- 页面使用原有 API 数据和业务 handler。桌面 `el-table` 保留，但在手机视口不挂载，不存在固定操作列覆盖卡片字段的问题。

二次验证：`npm run typecheck` 通过；`vite build --outDir <系统临时目录>` 通过且没有覆盖工作区 Spring 静态资源；LAN Vite 下 15 个后台/登录 SPA 路由 HTTP 200。自动化测试、真机登录后截图/触控以及服务器/生产部署没有执行。生产服务器仍是现有已发布版本，除非另行发布，不会自动包含当前工作区二次改造。
