# 上下分审批与最近记录验收记录

## 1. 验收范围

- 统一后台 `/admin` 的“上下分确认”和“最近上下分记录”两个区域。
- 聊天上下分申请待处理列表、昵称展示、同意、取消和失败刷新。
- 声音1、声音2、测试提示音和浏览器本地选择。
- 最近上下分只读接口、玩家/托切换、当天记录、方向颜色和分页。
- 玩家工作台手动上下分后的最近记录刷新。

## 2. 代码与数据边界

- 待审批事实继续使用 `player_point_request`。
- 实际积分变化继续使用 `demo_balance_ledger`。
- 最近记录只读取 `ADMIN_GRANT` 和 `ADMIN_ADJUST`。
- 未新增第二套余额、申请或统计表。
- 所有继续为虚拟积分，不涉及充值、支付、提现或现实资金。

## 6. 未执行项

- 待审批队列在服务重启期间的真实浏览器恢复未单独复验。
- 平板尺寸未单独截图，仅使用同一响应式断点规则检查。
- 服务器部署、生产数据库、正式 HTTPS 和生产现场验收未执行。

## 7. 不能推出的结论

- H2 和本机 MySQL 通过不能替代服务器和生产验收。
- 当前单实例 3 秒轮询不承诺多实例实时提醒。
- 浏览器无前端错误不等于所有终端均允许自动播放声音。
