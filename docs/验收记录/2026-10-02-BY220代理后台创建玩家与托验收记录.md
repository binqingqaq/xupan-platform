# BY220 代理后台创建玩家与托验收记录

> 验收日期：2026-10-02
> 对应范围：BY220 `robot.php`、`application/rbt/controller/Index.php::AddMember`
> 当前结论：代理后台已支持创建普通玩家和托、签发玩家链接、托数量上限校验和代理范围隔离；H2、前端和本机 MySQL V54 运行态已验证，服务器和生产未验证。

## 1. BY220 依据

- `application/rbt/controller/Index.php::AddMember` 接收 `type`。
- `type=0` 创建普通玩家，复用 `addReal`/`user_inf` 生成玩家和链接。
- `type` 为托时创建托，并检查当前代理 `tuoNum` 是否大于已有托数量；超限返回“托数量已达到最大值! 创建失败！”。
- 代理后台只能操作 `USER_ID` 所属机器下的玩家和托。
- 创建成功后更新代理统计并返回昵称。

## 2. xupan 实现

- Flyway V54 新增 `AGENT_PLAYER_MANAGE` 权限，并授予 ADMIN、AGENT 角色。
- `POST /api/agent/players/normal` 创建普通玩家，自动加入当前代理并签发 `PLAYER_FULL` 链接。
- `POST /api/agent/players/bot` 创建托，使用 `agent.bot_count` 作为数量上限，建立托行为并签发玩家链接。
- 创建事务内锁定 `demo_user_account.agent_id`，确认玩家归属当前代理；代理停用、资料缺失或越权时拒绝。
- `GET /api/agent/players` 继续只返回当前代理名下的普通玩家和托。
- `/agent` 页面新增“添加玩家”“添加托”和昵称/内部编码表单，不把平台管理菜单混入代理后台。
