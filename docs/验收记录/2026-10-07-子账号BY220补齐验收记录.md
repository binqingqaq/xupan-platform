## 2. 关键实现点

- 迁移 `V72__子账号上下分与在线状态.sql`：`agent_group.online`、`agent_group.logtime`。
- `AgentLedgerService#changeGroupScore`：子账号积分的唯一增量写入点（`SELECT ... FOR UPDATE` → 算差额 → 写余额 → 写流水；余额不足 409；delta 为 0 不写流水）。
- `PlatformAdminService#createSubAccount`：批量拆分 + 同一事务 + 唯一名冲突 409；`updateSubAccount`：`up`/`down`/`online`/飞单密码（AES 加密，`PlayerLinkTokenCipher`）/开启飞单重置机器上游状态。
- `AuthenticationService`：登录/退出维护子账号 `online`/`logtime`；`CurrentUser.subAccountScore` 供顶部「可用积分」。
- `ReportConfigRepository#findConfig`：统一飞单**只读回退**（条件：机器 `report_username` 为空 + 子账号未软删 + `unified_report_enabled=1` + 子账号 `report_username` 非空）；`ReportService#saveConfig` 的"保持原值"基准改为机器自身列，避免把子账号凭据复制进 `agent` 行（否则会撞 `uk_agent_report_username` 并破坏「一台机器一个上游账号」）。
- 安全防线（比 BY220 更严）：子账号操作者若被授予 `SUB_ACCOUNT_MANAGE`，列表按 BY220 收窄到自身，且编辑/删除/停用增加归属校验 `SUB_ACCOUNT_SCOPE_FORBIDDEN`。

### 4.2 复核指出、经确认后登记为「有意偏离/已知行为」（不修改代码）

### 8.1 报网类型由统一飞单决定

BY220 依据：子账号表单**没有**类型字段；机器的 `x_robot.flyers_type`（= 本项目 `agent.report_type`，取值 `K28/ls8899/wns` 等驱动类型）是在机器账号侧由**所选网盘的 `code`** 写进去的（`application/rbt/controller/Index.php:745`），`application/console/Websocket.php:161-165` 用它选择上游驱动；`x_rbwp`（网盘）本身没有类型列。本项目把「网盘编码」与「报网类型」拆成两列，因此在子账号侧显式保存统一飞单的类型：

- 迁移 `V73__子账号统一飞单报网类型.sql`：`agent_group.report_type`（取值集合与 `agent.report_type` 一致，`ck_agent_group_report_type`）。
- 继承规则：机器处于统一飞单继承态时，`reportType` 取**子账号**的值；子账号类型为空则回退取机器自身；非继承态仍取机器自身。只读回退，**不写回** `agent.report_type`。
- 子账号表单增加「报网类型」下拉（与机器端同一组选项）；**列表不加类型列**（BY220 `sub/list.html` 只有 网盘/盘口 列）。

### 8.2 同类收敛：调用方错误不再返回 500
`AuthenticationExceptionHandler` 原来用兜底 `Exception` 分支把 Spring MVC 标准异常吞成 500。现按类型收敛：

| 异常 | 现在返回 |
| --- | --- |
| `HttpMessageNotReadableException` / `HttpMediaTypeNotSupportedException` | 400 `REQUEST_BODY_INVALID`（请求体缺失或格式不正确） |
| `NoResourceFoundException` / `NoHandlerFoundException` | 404 `REQUEST_PATH_NOT_FOUND`（旧缓存前端请求已下线接口不再显示成服务端故障） |
| `HttpRequestMethodNotSupportedException` | 405 `REQUEST_METHOD_NOT_ALLOWED` |
| `MissingServletRequestParameterException` / `MethodArgumentTypeMismatchException` / `MissingServletRequestPartException` / `MultipartException` | 400 `REQUEST_INVALID` |
| `HttpMediaTypeNotAcceptableException` | 406 `REQUEST_NOT_ACCEPTABLE` |
