## 澳门四分彩数据同步

- 使用者明确要求同步本机澳门四分彩开奖记录/预设。只同步 `macau_four_minute_draw` 与 `macau_four_minute_draw_ball` 两张表的数据，不复制本机整库、玩家、注单或控盘审计表。
- 本机快照：第 100 期 `DRAWN`，号码 `7,19,18,2,21,32,13`，开奖时间为 2026-11-10 20:30（北京时间）；第 101 期 `PENDING`，计划开奖时间为 2026-11-11 20:30（北京时间），球位均为空。本机待开奖期没有非空预设需要复制。
- 迁移后检测到应用初始化生成的空白第 100 期待开奖占位记录；停服后确认仅有该记录且 7 个球位全空，删除该占位并在事务中导入本机两期数据。导入后重启服务，公开 API 返回最新第 100 期和下一期第 101 期。
- 公网 API 读取第 100 期开奖号码与本机一致；服务器 DB 有两期、14 个球位，100 期 7 个号码、101 期 0 个号码。澳门四分彩后台权限已由 V113 授予 ADMIN。
- 后续服务器调度独立运行并生成新的随机开奖；本次同步只建立截至第 101 期的历史/待开奖状态，不复制本机后续调度运行环境。
