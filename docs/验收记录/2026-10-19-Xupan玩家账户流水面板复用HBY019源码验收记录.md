# 2026-10-19 Xupan 玩家账户流水面板复用 HBY019 源码验收记录

## 验收范围

- 依据：[实施计划](../plans/2026-10-19-Xupan玩家账户流水面板复用HBY019源码实施计划.md)
- 范围：Xupan 玩家页面点击账户流水后，以 HBY019 UI1 来源 DOM/CSS 展示账户面板；数据与交互由 Xupan 页面/API 持有。
- 环境：本机工作区，前端 Vite 与本机 Spring Boot 8080；不是服务器或生产验收。
- 验收日期：2026-10-19 至 2026-10-20（Asia/Shanghai）。

## 实施结果

- 从 HBY019 UI1 页面生成独立的同源 `account-panel.html`，保留账户弹层原始 DOM、原页面样式和相关属性；移除了生成文档中与面板无关的主页面结构。
- 对照来源 `official-player-runtime-ui1.js` 检查动态记录行模板；桥接脚本按其四列顺序、作用域属性、行高/弹性宽度、背景色、退单样式和展开行为创建 DOM。这里使用 DOM API 写入纯文本，数据字段来自 Xupan，不执行 HBY019 的 AJAX 运行时代码。
- Xupan 玩家页用透明全屏 iframe 承载来源面板，数据和 UI 操作通过双方校验 `origin`、窗口来源及消息类型的 `postMessage` 传递。认证状态和 access token 保留在 Xupan 父页面。
- iframe 堆叠顺序对齐来源：面板层级 `999`，Xupan 顶部工具栏 `1001`；iframe 根画布透明，遮罩下的聊天室背景保持可见。来源字体 CSS 完整保留，未覆盖成另一套字体。
- Xupan 父页面继续请求当前用户账户摘要 API。面板显示用户资料、今日流水/盈亏、未结算/已结算注单，并桥接页签、字号、加粗、展开、关闭等操作。
- Spring Security 仅允许精确账户面板静态文档被同源页面嵌入；其余页面的 `X-Frame-Options` 仍为 `DENY`。
- 移除了未被引用的旧 Vue 重画面板组件，避免两个实现并存。
