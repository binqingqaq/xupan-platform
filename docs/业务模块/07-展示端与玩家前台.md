# 业务模块 07：展示端与玩家前台

> 当前状态：展示端复刻和玩家前台链路并行存在；玩家前台已接入参考式快捷下注与玩家级快捷金额偏好。

## 1. 页面边界

| 页面/路由 | 主要作用 | 数据边界 |
| --- | --- | --- |
| `/display` | PC 展示端首页 | 公开只读展示，不能写业务事实 |
| `/display/mobile` | 移动展示端首页 | 公开只读展示，不能写业务事实 |
| `/room` | 普通玩家完整前台 | 依赖玩家会话、游戏、钱包和聊天权限 |
| `/33/{token}` | 玩家链接进入入口 | 只用于一次链接兑换，Token 不进入持久化前端状态 |
| `/console` | 管理控制台 | 与玩家前台权限和事实写入隔离；旧 `/admin` 自动跳转 |

## 2. 数据规则

- 展示端可以读取公开的期号、开奖结果和展示资源，但不能自己生成最终开奖事实。
- 玩家前台余额、下注结果、结算和消息以服务端返回为准。
- 页面本地状态只能做缓存、输入和视图切换。
- 参考网站只决定视觉、结构和资源参考，不决定当前项目的玩法、赔率、支付、接口或开奖规则。

## 3. 玩家前台联动

```text
玩家链接兑换
  -> /room 会话
  -> 当前期号和倒计时
  -> 余额和流水
  -> 聊天输入
  -> 服务端解析下注
  -> 反馈消息、钱包和注单刷新
  -> 开奖后的结算反馈
```

链接失效、拉黑、玩家停用或软删除后，页面需要显示明确状态并回到重新获取链接的路径，不能显示看似可操作但必然失败的按钮。

### 3.1 快捷下注面板

玩家页右上角“快捷”打开完整赔率面板，不再展示旧快捷下拉。面板包含 74 个参考式赔率项、主赔率拼图、下方赔率网格和底部快捷下注栏。

- 赔率读取当前服务端 `game_odds`，不硬编码参考站数字。
- 赔率项支持多选和再次点击取消。
- 数字键追加金额，快捷金额替换金额，底部 `X` 回退一位。
- `重置`清空赔率选择但不清空金额。
- `设置`保存五个玩家级快捷金额；同一玩家的不同链接读取同一偏好；弹窗内提供`默认`按钮一键恢复默认值后保存，已移除头像设置和快捷金额文字提示。
- `快速下注`按固定顺序生成组合文本，交由聊天室下注链路处理。
- 底部快捷金额按钮与设置保持一致，数字键盘不受设置影响。

### 3.2 消息、流水与刷新行为

- 聊天室只展示最近 4 小时消息，向上滚动分页加载；不在底部时新消息只累计未读并在右下角显示 `▼ N条新消息`，点击回到最新节点。
- 机器人文本消息气泡按正文长度自适应，不再固定宽度。
- 账户流水只展示当天已结算流水，历史日期不在「今日」列表中出现；账户流水按钮悬停不显示文字提示。
- 点击`说明`只把`说明`写入输入框，点击`发送`后才在本机弹出玩法说明；这条消息对所有人可见，但弹窗只在发送者界面出现。
- 刷新浏览器后停留在刷新前的界面（快捷、账户流水、历史或普通下注），不再回到下注室首页。
