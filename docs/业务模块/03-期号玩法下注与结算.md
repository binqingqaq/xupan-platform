## 1. 模块职责

负责当前游戏的期号推进、下注窗口、封盘、开奖、玩法文本解析、赔率快照、注单和 WIN/DRAW/LOSE 结算。

## 2. 当前基础规则

- 当前方案是一个游戏类型和一个期号流。
- 每期默认 240 秒：前 180 秒 `BETTING`，后 60 秒进入 `DRAWING`；到期后结算并立即创建下一期。已创建期次使用保存的结束时间快照，不随代码配置变化。
- 下单接口在锁定当前期号后直接校验 `now < betting_ends_at`；自动轮期的每秒阶段切换负责状态推进，不作为截止时间的唯一保护。机器封盘秒数为 `0` 时仍受本期 `betting_ends_at` 限制。
- 期号从 `3000000` 起步，服务端每秒推进。
- AU8 当前已确认目标规则：每期 7 个 01～40 的不重复号码；实现状态及数据迁移边界见上方 2026-11-10 新决定和专项计划。非 AU8 彩种继续使用各自规则。
- 当前文本下注固定落到第 1 球，服务端拒绝其他球位。
- 下注保存赔率快照，结算不能读取开奖后的当前赔率。
- `LOSE` 为负投注额；`WIN` 按快照赔率计算净盈亏；`DRAW` 使用配置的和局策略。

### 2.1 机器赔率、封盘与取消（BY220 平移，2026-10-02）

> **2026-10-28 最新决定：恢复机器级手动开盘/封盘控制，取代同日先前移除该控制的决定。** 本机已由 V99 恢复独立下注许可，并接入下注与托自动下注；与彩种、期次阶段/截止时间、机器封盘秒数和账号有效状态叠加判断。H2 集成上下文受既有 V83 迁移阻断，浏览器和服务器/生产未验收。实现及边界见[恢复开发计划](../plans/2026-10-28-机器手动封盘开盘控制恢复开发计划.md)。

- 赔率快照按玩家所属机器（BY220 `x_robot`）计算：普通玩法 `1 + num × PeiLv/100`（`FanShui` 与权重 `num` 见 [代理赔率返水封盘取消结算映射实施计划](../plans/2026-10-02-代理赔率返水封盘取消结算映射实施计划.md) 第 3 节），特码直接使用 `tePeilv`。
- 历史实现（已被2026-10-23改进取代）：机器未配置赔率（`0/NULL`）时回退全局 `game_odds`。当前实现不再用全局赔率替代机器配置；缺配置会明确拒绝报价或接单。
- 实施目标：机器手动封盘时拒绝新的普通下注，使用独立拒绝原因 `GAME_MACHINE_MANUALLY_CLOSED`；不能与 `close_seconds` 到点的 `GAME_MACHINE_CLOSED` 混淆。手动开盘不覆盖期次阶段、下注截止时间、机器封盘秒数、机器停用或过期状态。
- 对手动封盘不撤销已受理注单；开奖结算不检查机器手动开关。取消按 BY220 顺序独立处理：机器手动封盘不禁止取消，但机器封盘时间、期次截止和取消秒数仍可禁止取消。
- 手动封盘仅限制机器下注，不拒绝玩家进入前台，不自动踢出玩家，不撤销链接；查询、聊天和非下注命令继续各自授权和状态规则。BY220 前台入口的 `isOpen` 拒绝分支处于禁用状态（`application/common.php:1274-1301`）。
- 并发强化目标：下注和手动状态变更锁定同一机器数据库行并持锁至提交；关盘成功响应前，已经先取得锁的下注事务必须提交。新状态先提交时，后续下注拒绝。托自动动作执行前复检，封盘时跳过的期号动作在重开后不补跑。
- 机器 `close_seconds`（BY220 `fengpan`）表示距开奖前多少秒封盘；进入封盘窗口后既不能下注也不能取消，原因是 `GAME_MACHINE_CLOSED`。`0` 表示不额外提前，仍受期号阶段约束。
- 机器 `cancel_seconds`（BY220 `cancel`）表示注单生成后多少秒内可撤单；`0` 表示关闭取消。
- **撤单按 BY220 物理删除注单行**（用户 2026-10-02 确认）：事务内先删除注单作为原子占用，再写幂等退款流水，最后写操作审计。取消能力关闭或窗口内没有待处理注单时，反馈文案与 BY220 保持一致（`禁止取消！`、`N 秒内无有效指令！`）。
- 进入结算的注单不再保留 `CANCELED` 状态；该状态只用于历史存量数据。

### 4.2 玩家快捷下注

AU8 玩家快捷面板当前包含 94 个赔率项，其中 01～40 特都是可提交选项并共用统一特码赔率。选中一项或多项并输入金额后，按固定顺序生成逗号分隔的组合文本，交由统一批次下注链路在同一事务中创建全部注单；任一注单失败时整批不生效。其他玩法与额度规则保持原样。

当前新增文本规则：

- `1车` 到 `4车` 表示车覆盖另外三个番值。
- `2无3` 表示 `2` 中、`3` 输、剩余番值和。
- 原有 `12无3` 等三位`无`格式继续有效。

快捷金额偏好不属于游戏结算事实，保存在玩家偏好表中，由玩家前台读取和保存。

### 4.3 限额与下注校验

后台顶部状态赔率栏的`限额`按钮打开 13 项配置，机器赔率、返水和额度持久化在 `agent` 配置及其版本字段中，由机器表单和代理配置入口维护；不再用全局 `game_betting_config` 或 `game_odds` 作为机器报价回退。具体字段含义见2026-10-23业务基线第9节。

校验口径：

- `agent` 的13项机器限额按所属机器读取，机器0值或缺项不能静默回退全局值。
- `单场总限额`按玩家、机器、游戏、期号统计所有有效注额；普通玩法按BY220号码/文本匹配规则归并额度组，特码按每个号码累计，组合特码以每号单价计额。
- BY220限额查询不含球位条件，故同一期不同球共享额度；游戏、玩家、机器和期号分别隔离；托单依 `player_kind_snapshot` 排除，不计入普通玩家额度。
- `玩家最小注额`与`玩家最高注额`按每条用户指令的总金额检查，不把历史累计注额误作单笔最高额；组合特码先保留指令总额，再按每号单价检查号码限额。
- 同一批次全部指令在额度预占、扣分及注单写入上保持原子性；任一指令超限时整批拒绝、不扣分、不占额、不生成成功注单。撤单物理删除有效注单后额度随之释放，退款流水保持幂等。
