# 业务模块 10：BY220 式超级管理后台

> 当前状态：独立超级管理后台入口和“开奖信息”首屏已实现。**强约束：后续菜单必须严格按 BY220 `admin.php` 平移；“子账号”和“机器管理”必须拆成独立页面，不能继续共用一个代理组织管理页。** 服务器与生产未验收。

## 1. 页面定位

超级管理后台是平台最高管理端，独立于代理后台：

| 入口 | 使用者 | 作用 |
| --- | --- | --- |
| `/platform-admin/login` | 平台超级管理员 | 独立密码登录 |
| `/platform-admin` | 平台超级管理员 | BY220 式开奖信息首页 |
| `/agent` | 代理 | 代理自己的玩家/托后台 |
| `/console` | 平台运营管理员 | 现有详细运营工作台 |

超级管理后台不是代理后台，不复用代理账号身份作为登录入口。

## 2. 当前首屏

“开奖信息”首屏按参考图实现：

- 深色顶部管理菜单。
- “澳8番摊”游戏选择区域。
- 上期开奖结果。
- 八个开奖号码。
- 特码番值。
- 最近 12 期开奖历史。
- 平台管理员身份和安全退出。

开奖信息和历史数据来自现有游戏服务，不使用前端伪造数据。

## 3. 菜单现状

已接入：

- 开奖信息：`/platform-admin`
- 子账号/机器管理：跳转现有代理组织管理 `/console/agents`
- 报表统计/在线玩家：跳转现有玩家管理 `/console/players`
- 游戏设置：跳转现有运营台
- 修改密码：跳转现有用户管理
- 安全退出：使用现有认证退出

暂未实现具体页面或只做视觉占位：

- 开奖历史独立菜单页。
- 未结订单。
- 订单改单。
- 设置。
- 网盘设置。
- 完整 BY220 子账号和机器管理专用页面。

占位菜单不会伪造订单、余额或网盘数据。

## 4. 权限

- `/platform-admin` 要求 `USER_MANAGE`。
- 代理账号只有 `AGENT_CONSOLE_READ`，不能进入超级管理后台。
- 登录页使用现有密码认证，但入口和页面独立。
