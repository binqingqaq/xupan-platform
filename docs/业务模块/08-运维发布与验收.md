# 业务模块 08：运维、发布与验收

> 当前状态：提交 `caf4677` 已完成单服务器发布、数据库备份、V14-V32 前向迁移和公网 HTTP 冒烟；HTTPS、Secure Cookie 刷新恢复、恢复演练和有鉴权浏览器验收尚未完成。

## 1. 当前部署基线

- Java 21。
- Spring Boot 单体服务。
- MySQL 8.4 LTS。
- 单服务器、单实例。
- 配置和密钥分离，生产凭据不入库。
- Flyway 负责数据库迁移。
- Redis、MQ、多实例协调和跨节点广播不属于当前前置条件。

## 2. 发布必须覆盖

```text
构建
  -> 数据库备份
  -> Flyway 前向迁移
  -> 启动/健康检查
  -> 接口和页面冒烟
  -> 日志和指标检查
  -> 失败时回滚或前向修复
```

正式业务发布还需要记录：版本、迁移版本、备份位置和哈希、环境变量、启动停止方式、健康结果、错误日志、回滚/修复结果。

## 3. 验收等级

| 等级 | 能证明什么 | 不能证明什么 |
| --- | --- | --- |
| 静态检查 | 文件、配置和差异基本正确 | 运行时可用 |
| H2 测试 | 领域逻辑、迁移和集成测试通过 | MySQL、网络、生产配置 |
| 本机 MySQL | MySQL 8.4 迁移和本机接口链路 | 服务器和公网 |
| 服务器现场 | 目标服务器部署和运行态 | 正式生产业务稳定性 |
| 生产验证 | 正式环境可用和运维证据 | 未覆盖的长期容量和灾备能力 |
