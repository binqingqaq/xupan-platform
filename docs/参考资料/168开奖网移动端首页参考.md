# 168开奖网移动端首页参考

> 类型：外部网页只读观察记录。参考资源仅用于当前项目本地展示评审，不代表官方业务、接口契约或正式素材授权。

## 观察结论

- 移动端使用独立的 `m.` 子域名，页面结构不是桌面首页的简单缩放。
- 页面从上到下由 APP 宣传条、移动头部、公告条、宣传图、开奖卡片列表和固定底部菜单组成。
- 开奖卡片采用单列纵向滚动；不同彩种的号码数量和摘要信息不同。
- 本项目入口为 `/display/mobile`，桌面入口 `/display` 保持不变。

## 本阶段复刻范围

| 区域 | 当前实现 | 说明 |
| --- | --- | --- |
| APP 宣传条 | 静态展示 | 下载按钮无外链、无下载动作 |
| 移动头部 | 静态展示 | 汉堡菜单和桌面版按钮无跳转 |
| 公告条 | 静态展示 | 公告文本固定，不保留外部导航地址 |
| 宣传图 | 本地图片 | 复用当前项目已核验的本地宣传素材 |
| 开奖卡片 | 15 张固定数据 | 只展示静态期号、号码、摘要和倒计时 |
| 底部菜单 | 固定视觉展示 | 点击不跳转、不请求、不打开其他页面 |

## 明确排除

- 登录、注册、APP 真实下载和外部广告。
- 底部菜单对应的其他页面。
- 真实开奖接口、新闻接口、倒计时接口和 WebSocket。
- 下注、支付、会员、预测和后台功能。
