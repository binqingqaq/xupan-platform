# 168开奖网移动端首页接口与字段映射

> 状态：只读观察与单接口抽验记录，不是正式接口契约。用户已明确确认外部接口合法合规，并允许当前项目请求这些开奖接口用于首页展示。
>
> 观察日期：2026-09-24
>
> 范围：仅限移动端首页 `home.html`，不包含登录、投注、后台和其他子页面。

## 1. 结论

- 首页开奖卡片不是纯静态数据，页面运行时会发起多个匿名可访问的 XHR 请求。
- 大部分开奖接口与首页同域，返回统一 JSON 包装结构；至少一个六合彩接口位于其他域名。
- 可以观察并整理字段，但当前接口没有公开文档、版本号、授权说明、稳定性承诺或服务等级约定。
- 当前项目可以请求这些接口。生产实现应由 Spring Boot 服务端请求，不默认让浏览器跨域直连。
- 外部接口作为开奖数据上游，当前项目应保存归一化快照和来源信息，避免把浏览器内存状态当作事实源。
- 接入仍需处理超时、限流、重试、字段变化、缓存和故障降级，但不因授权问题阻断实现。

## 3. 统一响应包装

已抽验接口使用以下外层结构：

```json
{
  "errorCode": 0,
  "message": "操作成功",
  "result": {
    "businessCode": 0,
    "message": "操作成功",
    "data": {}
  }
}
```

适配器必须同时校验 `errorCode`、`result.businessCode` 和 `result.data`，不能只判断 HTTP 状态码。

## 5. 通用字段映射

| 外部字段 | 含义 | 当前项目建议字段 | 说明 |
| --- | --- | --- | --- |
| `serverTime` | 数据服务时间 | `source_server_time` | 用于计算时钟偏差，不能直接当业务日 |
| `lotCode` | 外部彩种编号 | `source_lot_code` | 必须与来源类型一起唯一 |
| `lotName` | 外部彩种名称 | `source_lot_name` | 展示名使用当前项目自身配置 |
| `frequency` | 开奖频率描述 | `draw_interval_desc` | 仅作展示，调度周期必须另行配置 |
| `lotteryStatus` | 彩种状态 | `source_status` | 需转换为当前项目枚举 |
| `preDrawIssue` | 已开奖期号 | `issue_no` | 与 `lot_code` 组合唯一 |
| `drawIssue` | 下期期号 | `next_issue_no` | 允许暂时为空 |
| `preDrawTime` | 已开奖时间 | `drawn_at` | 统一转为数据库时区 |
| `drawTime` | 下期开奖时间 | `next_draw_at` | 倒计时唯一基准 |
| `preDrawCode` | 号码字符串 | `number_list` | 按逗号拆分并校验数量、范围和重复规则 |
| `sumFS` | 冠亚和 | `champion_runner_sum` | 常见于赛车、飞艇 |
| `sumNum` | 号码总和 | `number_sum` | 常见于时时彩、PC28、快3 |
| `sumTotal` | 六合彩总分 | `total_score` | 与 `sumNum` 语义不同 |
| `sumBigSamll` | 大小，外部拼写错误 | `size_result` | 兼容旧字段，不照搬拼写 |

| `sumSingleDouble` | 单双 | `parity_result` | 转换为当前项目枚举 |
| `dragonTiger`、`firstDT` 等 | 龙虎 | `dragon_tiger_list` | 不同玩法长度不同 |

## 6. 特殊字段边界

运动会类返回中包含区块链交易哈希、地址和交易金额等字段。它们涉及外部资产与可验证性叙事，当前项目不得因为字段存在就复制、展示或纳入规则。若未来确需使用，必须单独完成合规、安全和数据真实性评审。

外部接口还可能返回真实金额、代理、充值或投注相关信息。此类字段不得进入当前项目的虚拟积分模型、接口、数据库、日志或页面。

## 8. 生产接入前置条件

1. 保留用户关于合法合规和数据请求范围的确认记录。
2. 为每个玩法建立独立 `LotteryResultProvider` 适配器。
3. 后端按来源配置轮询，不在前端直接调用外部接口。
4. 以 `source_code + source_lot_code + issue_no` 建立唯一约束，保证幂等。
5. 保存来源、抓取时间、响应哈希、解析状态和失败原因，禁止保存凭据和敏感请求头。
6. 增加超时、重试上限、熔断、限流、健康检查和告警。
7. 区分静态检查、H2 测试、本机 MySQL、服务器现场和生产验证证据。
8. 正式发布前替换未授权图片、Logo、广告素材和文案。

## 9. 当前结论

用户已明确确认外部接口合法合规并允许请求。当前项目可以按服务端接入方案实现移动端首页数据联动，范围仍严格限制为 `home.html` 对应的移动端首页，不进入登录、投注、新闻、彩票大厅或其他子页面。前端只调用当前项目自己的接口，外部接口请求、字段转换、缓存和失败恢复放在 Spring Boot 服务端。
