当文档与实现或不同文档之间出现冲突时，按以下顺序判断：

1. 当前源代码、配置、Flyway 迁移和测试结果。
2. 本索引列出的当前需求基线和项目方案。
3. 用户在当前会话明确确认的业务规则。
4. 实施计划、验收记录和参考资料。

“计划”“建议”“待确认”和“未执行”不能当作已实现事实；参考网页观察不能直接当作当前项目业务规则。
