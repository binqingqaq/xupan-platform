## 1. 目标与范围

- 正式机器账号登录入口 `/login` 使用 `D:\codes\liuhecai\hby019-local-rebuild\index.html` 的界面结构、样式、字体和按钮布局；沿用 Xupan 已复制的 `web/public/hby019-demo/source/index.html` 及资源，不重画近似页面。

- 收件人打开专属地址时，用户名已填好且只读，密码为空；输入密码后复用现有 `CONSOLE` 认证，成功进入机器账号的 `/console`，所有机器隔离与权限继续由后端决定。
- 保持普通 `/login` 可手填用户名。平台超管 `/platform-admin/login`、玩家链接入口及玩家前台不在本次界面调整范围。

## 3. 路由与链接契约

1. `/login`：正式机器账号通用登录页，HBY019 外观，用户名可编辑。既有登录过期、退出和权限不足提示继续走现有入口规则。
2. `/console/login/:username`：公开的机器专属登录页，末段是 URL 编码后的 `accountUsername`；新建机器目前要求 3–64 位字母、数字、下划线、短横线，但链接读取不得据此误拒绝已有历史账号。前端只拒绝空值、非法编码、控制字符和不合理长度，最终账号有效性由现有登录接口判断；无效链接显示可理解的状态与通用登录入口，不调用账号查询接口。
3. `/console`：认证后机器后台的唯一正式语义入口，仍跳转当前 `/hby019-demo/console` 承载页；新链接不改变后台实际路由或机器范围。
4. `web/src/main.ts` 注册专属公开路由；`consoleScope.ts` 将普通与专属机器登录入口都归入 `CONSOLE`，修正现有 `/login` 被归为 `PLATFORM` 而实际以 `CONSOLE` 登录的口径不一致；`SpaController` 增加带用户名路径的 SPA 回退，以保证复制地址直接打开、刷新和新标签访问均返回前端入口。核对 Spring Security 的 `/console/**` 公开页面规则；认证 API 仍受原有规则保护。
5. 链接只包含用户名，不包含密码、Token、会话标识或可免密访问的随机码。它不创建数据库链接记录，也不单独设置有效期；账号状态和有效期仍由现有登录接口实时判定。

## 4. 完整业务流程

1. 有 `MACHINE_MANAGE` 权限的超管或授权子账号进入 `/platform-admin/machines`；列表以接口返回的 `accountUsername` 作为唯一复制来源，不用机器编码 `code`、展示名或前端暂存编辑值。
2. 点击该行“复制”，以当前部署站点的可访问 origin 组装 `/console/login/{用户名}`，调用浏览器剪贴板 API；成功后显示共享 `adminNotice.success` 顶部 toast。复制失败应给出错误提示和可手动选中的完整地址，不能误报成功。按钮需与“编辑/玩家/启停/删除”同时可见并保持窄屏表格可操作。
3. 收件人打开地址：父 Vue 路由提取并校验用户名，把它传给同源 HBY019 登录 iframe；页面显示对应用户名并设为只读，密码保持空白。普通 `/login` 不绑定机器用户名，允许手填。iframe 向父页发登录请求时，专属路由只接受与路径用户名一致的账号，避免页面脚本或 DOM 改值造成链接语义漂移。
4. 用户点击“登录”或按回车，页面只提交一次 `api.login(username, password, 'CONSOLE')`。Xupan 后端继续验证密码、账号停用/锁定、机器及所属子账号有效期和 `AGENT` 角色，并写登录审计；成功签发该入口的访问令牌与 `xupan_console_refresh` Cookie，进入 `/console`，由现有机器范围策略决定可见数据。
5. 失败时保留用户名、清空密码、解除按钮忙碌状态，通过已实施的全局顶部 `ElMessage` 显示错误；不泄露账号是否存在。打开链接本身不触发认证、不改变积分、机器配置或现有平台会话。

## 5. 边界与异常处理

| 场景 | 预期 |
| --- | --- |
| 已有另一机器的 `CONSOLE` 会话后打开专属链接 | 仍展示链接指向的用户名和空密码，不自动进入旧机器；只有明确输入目标机器密码并登录后才切换当前标签的代理身份。平台后台的独立会话不受影响。 |
| 已有同机器会话后打开专属链接 | 专属页仍以密码登录为入口，不因自动恢复会话跳过用户名确认；普通 `/login` 继续沿用现有会话恢复行为。 |
| 密码错误、账号停用/锁定/过期、所属子账号到期或机器被删除 | 由现有后端拒绝；页面不跳后台，继续显示链接用户名和安全的错误提示。复制地址不绕过任何状态。 |
| 旧链接的用户名已不存在或曾删除后重建同名账号 | 登录只认当时数据库中的现有账号与密码；链接本身不绑定旧机器 ID，不能作为账号所有权凭证。需要不可复用链接时须另立带有效期的令牌需求。 |
| 地址末段含非法字符、编码错误、空值或过长 | 前端安全拒绝或进入通用登录页；不拼接到 API 路径，不发账号探测请求，不造成白屏。 |
| 复制时站点地址是 `127.0.0.1` / `localhost` | 链接只可在本机打开；提示当前为本机地址。正式分享应通过收件人可访问的 HTTPS 域名访问后台后复制，不复用玩家线路域名或硬编码测试域名。 |
| 浏览器剪贴板权限或非安全上下文导致写入失败 | 显示失败提示及可选中的完整地址供手动复制；不声称已复制。 |
| 登录成功、退出或失效后返回 | 登录成功进入现有机器后台；退出/失效仍回正式机器登录入口，若需再次打开原机器专属页可使用原链接，不在浏览器持久保存密码。 |

## 6. 实施顺序与文件边界

1. **视觉基线**：读取 HBY019 `index.html` 与本仓库副本，确认两者只存在已知路径和登录适配差异；在相同浏览器与视口保存桌面/窄屏对照。保留登录表单、按钮、字体、留白和现有“查”入口的视觉与既有导航。
2. **路由与宿主**：调整 `web/src/main.ts`、`consoleScope.ts`、`Hby019SourcePage.vue`，让普通和专属路由复用同一来源页；扩展来源校验、账号预填和登录请求绑定，处理路由参数变更、iframe 加载先后及已有会话误跳转。
3. **机器管理复制**：调整 `web/src/views/PlatformAdminMachines.vue` 操作栏与复制行为，使用已有共享 `adminNotice`；依据 `Machine.accountUsername` 生成标准化 URL，处理剪贴板异常和本机 origin 提示。
4. **直达支持与静态资源**：调整 `server/xupan-server/.../SpaController.java` 的精确动态路由；确认 `SecurityConfig` 无须扩大接口权限。按仓库规则同步 `web/public/hby019-demo/source` 与 Spring Boot `static` 中实际使用的登录脚本，使用安全构建流程保留工作区已有静态资源。
5. **专项验收**：更新登录入口、机器管理复制、路由/回退和 iframe 消息测试；随后做类型检查、生产构建、本机服务和浏览器人工验证。除页面路由外预期无需新 API、Flyway 迁移或业务表结构变更；若实现时发现缺口，先记录证据再扩展范围。

- 普通 `/login`、专属 `/console/login/ahy005` 与 HBY019 来源登录页在相同桌面/窄屏视口下关键结构和样式一致；用户名预填/只读、密码留空、登录/回车和“查”按钮均按各自路径工作。视觉对照不得仅以 HTTP 200 或构建通过代替。
