# 移动开奖首页接入 AU8 七球开奖开发计划

> 状态：2026-10-31 接口/历史分页实现及本机 API 冒烟已完成；按使用者反馈恢复原展示样式、期号末三位的最后修改已重新编译并通过两份脚本语法检查。浏览器视觉复核、自动化测试和生产验收未做。

## 目标

在 `/display/mobile` 点击“快乐8”时，将原卡片数据替换为 Xupan 当前 AU8 七球业务真实期次及开奖结果；保留原有球位、颜色、间距和信息行，只替换期号、号码、番值与本地期次时间。期号显示末三位，当前下注/开奖阶段倒计时与最近已开奖期分别展示。

## 页面与数据映射

| 当前页面/数据 | Xupan 实现位置 | 规则 |
| --- | --- | --- |
| 移动展示页顶栏“快乐8”页签 | `web/public/display/mobile-replica/official/page.js` | 接本地 AU8；外部 `happy-eight-six` 快乐8六合彩不再驱动此页签。香港彩保持现有外部映射。 |
| 顶栏七个号码框及下方标签 | 新增公开 AU8 只读 DTO | 读取 `game_code=AU8`、`ball_count=7`、`phase=SETTLED`；原位显示号码及逐球番值，保留参考页样式。 |
| 快乐8卡片期号和七球号码 | `game_issue` + `BallResult` | 只使用已确认结果，不从当前期动画预览生成开奖结果；期号仅显示末三位。 |
| 当前期号和截止下注时间 | `GameDataRepository.findCurrentIssue("AU8")` | 从当前七球 `BETTING`/`DRAWING` 期读取 `bettingEndsAt`，与最近已开奖期分别展示。 |
| “历史记录”入口 | `GET /api/display/mobile/au8/history?page=1&pageSize=10` | 按已结算七球期分页展示全部本地开奖记录；每条显示末三位期号、开奖时间、七个号码及番值。 |
| “最新开奖”与刷新按钮 | 当前 AU8 只读接口 | 本地重新读取最新结果；外部直播/开奖时间不用于该卡片。 |
| 外部开奖首页数据接口 | `GET /api/display/mobile/au8` | 仅公开开奖结果及期次时间；不得返回账户、赔率、注单或投注数据。 |

## 实施约束

- 开发前已核对 BY220 严格平移基线、本机移动展示页结构、既有外部开奖映射计划、AU8 七球方案和当前数据访问代码。
- BY220 `application/common.php` 的 `getCum`/`getFan` 区分所选位置合计与取 4 余数；Xupan `BallResult` 定义每个号码的番值、单双和大小。本卡片只替换原球位标签为逐球番值，不追加合计摘要行。
- 公共展示不复用需认证且包含玩家账户信息的 `/api/demo/game/current`。
- 无开奖结果或请求失败时不得保留外部快乐8六合彩或八球历史内容并冒充本地 AU8 数据。
- 页面源与 Spring Boot 静态副本需保持同步；不得覆盖工作区已有静态资源改动。
