# 超级管理后台手机适配开发计划

> 状态：本机代码与自动化验收完成；手机登录后的手工浏览器验收待确认（2026-11-08）。
> 需求来源：[超级管理后台手机适配方案](2026-11-08-超级管理后台手机适配方案.md)，使用者已审核通过。
> 业务边界：仅调整 `/platform-admin/**` 窄屏呈现；桌面版、BY220 菜单/字段/业务流程、接口、权限和数据口径保持不变。

## 1. 目标

让平台超级管理后台在手机上可读、可操作：不需要先把桌面页面整体缩小或左右拖动，便能找到菜单、查看子账号/机器关键数据并访问原有操作；手机表单适配全屏滚动；平板过渡自然；桌面布局保持原样。

## 2. 现状与映射

| BY220 菜单/页面/操作 | Xupan 页面与组件 | 本计划的适配 |
| --- | --- | --- |
| 顶部菜单、账号欢迎、安全退出：`application/admin/view/public/head.html` | 所有路由共享 `web/src/components/platform-admin/PlatformAdminNav.vue` | 桌面仍横向菜单；手机改为明确的菜单抽屉，保留现有顺序、权限过滤、当前项和退出 |
| 开奖信息 | `/platform-admin`、`PlatformAdminHome.vue` | 结果球换行、摘要纵排；历史宽表自身滚动 |
| 子账号列表、新增/编辑、启停、解锁、删除：`application/admin/view/sub/list.html`、`sub/form.html` | `/platform-admin/sub-accounts`、`PlatformAdminSubAccounts.vue` | 手机改账号信息块，字段和操作完整可见；弹窗全屏 |
| 机器列表、新增/编辑、玩家、启停、复制、删除：`application/admin/view/rb/list.html`、`rb/form.html` | `/platform-admin/machines`、`PlatformAdminMachines.vue` | 手机改机器摘要卡片及可展开详情；所有现有字段和操作保留；表单全屏 |
| 报表统计、开奖历史、未结订单、订单改单、在线玩家、设置、网盘设置、游戏设置、修改密码 | `web/src/main.ts` 中现有 `/platform-admin/**` 路由组件 | 筛选/表单单列；宽表只在表格容器中滚动，适合逐条查看的列表用摘要信息块 |
| Xupan 中心上游扩展 | `/platform-admin/center`、`PlatformAdminCenter.vue` | 保留现有 Xupan 扩展边界；按子页面适配筛选、表格、抽屉/弹窗，不映射为 BY220 功能 |

BY220 静态源码已核对：子账号列表包含用户名、失效、积分、权限、状态及超管可见的飞单字段；机器列表含账号、密码掩码、失效、子账号、积分、状态、开盘、托数、飞单信息、赔率/返水/限额和操作。机器新增/编辑字段有角色与新增/编辑态差异，移动版须保留 Xupan 当前实现的真实字段、权限和表单行为，不直接照搬旧默认密码或凭据。BY220 `admin.php`、子账号页未登录访问返回重定向；本次没有执行 BY220 登录态业务写操作，业务映射依据是上述源码和当前已确认规则。

当前 Xupan 根页面 viewport 为 `width=device-width, initial-scale=1.0`；`main.ts` 对正式 `/platform-admin/**` 也设置设备宽度，对旧 `/admin/**` 兼容地址设置 `width=1000, user-scalable=yes`。本次不改路由 viewport 与浏览器缩放策略，保持正式超级后台的窄屏媒体查询有效，并不添加禁用缩放属性。

## 3. 实施范围

### 3.1 公共导航与布局

- 修改 `PlatformAdminNav.vue`：`>=768px` 保留当前横向菜单；`<768px` 显示菜单按钮、当前菜单名和账号操作入口，菜单抽屉只渲染现有权限允许的入口。
- 移动抽屉中的菜单顺序、路由、当前选中态和安全退出沿用现有数据与函数；不新增导航项，不改变权限判断。
- 在平台后台专属样式中增加窄屏内容宽度、标题/按钮/筛选布局规则；样式限定在 `.platform-admin-page` 及后台弹层，不能污染代理后台或玩家端。
- 设备旋转、浏览器缩放和安全区下菜单/弹层不得被裁切；触控目标尽量达到 44px。

### 3.2 子账号

- 保留桌面 `el-table`；手机以同一 `accounts` 数据生成逐条信息块，用户名、状态、积分、失效时间、机器数量、子账号权限、机器人权限均有可见位置。
- 手机保留添加入口和每行编辑、启用/停用、锁定解锁、删除操作；危险操作仍有既有二次确认。
- 新增/编辑手机弹层满屏显示，字段单列、内容可滚动、底部确认/取消可达；新增批量用户名规则、编辑时积分只读、上/下分及权限含义不变。
- 卡片视图与桌面表格共用加载数据、同一操作函数和相同 API，不做第二套状态或权限。

### 3.3 机器管理

- 保留桌面 `el-table`；手机卡片摘要显示账号、状态、下注开关、所属子账号、积分和失效时间；展开区呈现表格中其余字段，包括赔率/返水/限额和玩家/托统计。
- 每台机器的编辑、玩家、复制登录链接、启用/停用、锁定解锁、删除操作保持可达；删除仍保留确认。
- 添加/编辑机器表单手机全屏、单列、独立滚动和固定底部动作；保留新增/编辑字段差异、子账号归属、AU8 球位模式、配置精度、校验和请求 payload。
- 玩家列表弹层在窄屏也能查阅昵称、编号、类型、余额、状态。

### 3.4 其他平台后台页

- 覆盖 `/platform-admin` 菜单可进入的全部页面：开奖信息、子账号、机器管理、开奖历史、玩法统计、报表、未结订单、订单改单、在线玩家、设置、中心上游、网盘设置、游戏设置和修改密码；登录页沿用现有窄屏呈现，核对其不受全局样式影响。
- 公共样式负责标题、筛选、统计区、表单及表格容器的窄屏约束；页面自有结构用局部规则适配，避免以 `min-width`、`zoom` 或 `transform: scale()` 缩小整页。
- 宽数据表在各自容器内横向滚动，不能让整页水平溢出；具备操作按钮的记录需保证账号/订单识别信息和操作仍容易触达。
- 开奖 `null` 展示属于数据问题，不在本计划内改数据口径或填造占位数据；若页面布局暴露该问题，单独记录。

### 行为验收

- 导航：超管与子账号已有权限菜单集合不变；菜单顺序/目标地址不变；退出行为不变；直接访问权限拦截不变。
- 子账号：创建/批量创建、编辑、上下分、权限开关、启停、解锁、删除确认和反馈不变。
- 机器：创建、编辑、所属子账号、AU8 球位配置、各限额/返水/赔率字段、玩家列表、复制登录链接、启停、解锁、删除确认和反馈不变。
- 其余页：主要筛选、分页、原有行操作、弹层确认、刷新和错误状态仍可用。
- viewport 不禁用缩放；缩放后菜单、卡片、表格、日期选择器和弹层不重叠。
- 不触发任何线上/本机真实账号写操作作为视觉验收；若需验证业务写路径，按对应功能的独立授权与验收边界执行。

### 自动化与运行验证

- 定向运行导航、子账号和机器管理相关 Vitest；新增响应式标记/视图测试，覆盖断点下桌面与移动内容切换及字段/动作映射。
- `npm run typecheck` 与 `npm run build`。
- 通过本机 Vite/应用静态资源分别访问实际平台管理路由；视觉检查使用无真实写入的已登录只读页面或安全空态，记录账号/接口约束。
- 检查 `/console`、`/room`、`/display/mobile` 的样式隔离；服务器和生产不属于本计划的本机实施验收。

## 6. 风险与边界

| 风险 | 控制 |
| --- | --- |
| 卡片视图漏字段或操作 | 以桌面 `el-table-column` 与操作栏为逐项清单；每项映射到卡片摘要/详情/操作并由测试覆盖 |
| 重复渲染导致状态分叉 | 卡片与桌面表共享同一 refs、handler 和 API；不复制数据请求与领域逻辑 |
| 固定操作列与横向滚动继续挡住账号 | 手机视图不使用桌面固定列；桌面表仅在桌面断点显示 |
| 弹层被移动导航/软键盘/安全区遮挡 | 移动断点全屏表单与内部滚动；真机/浏览器验证日期弹层和底部动作 |
| 全局样式污染其他入口 | 所有规则限定 `.platform-admin-page` 或平台后台弹层，完成非后台路由回归 |
| BY220 运行态无法登入验证 | 本机 BY220 GET 目前重定向到登录；本次只做源码映射和只读页面可用性检查，验收如未取得认证态不得写成 BY220 运行操作通过 |

## 7. 本次不做

- 不修改 Java/API/数据库/Flyway、认证授权、权限码、菜单顺序和业务逻辑。
- 不移动代理业务到超级后台，不改 `/console` 或玩家端。
- 不因手机布局隐藏或移除现有表单字段、表格数据和业务操作。
- 不处理开奖结果数据 `null` 的来源。
- 不部署服务器或生产，不把本机浏览器验证描述成生产验收。
