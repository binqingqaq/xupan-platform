# 积分记录 0 点/6 点业务日切换修复计划

> 制定日期：2026-11-04
> 状态：本机实施完成；机器账号浏览器现场验收待补，结果记录在 §5。

## 1. 目标

让 `/console` 积分记录中的“0点一天”和“6点一天”都切换实际统计窗口；日期标签只来自服务端可查询日期，不再回退到演示 HTML 中的固定 2026-10-07 至 2026-10-14。

## 2. BY220 与当前实现映射

| BY220 | Xupan | 规则/差异 |
| --- | --- | --- |
| `application/rbt/view/index/record.html` 的 `timeType` 与日期选择 | `web/public/hby019-demo/source/console.html`、`local-api-bridge.js` | BY220 默认 `timeType=1`，按钮在 0/1 间切换；日期按钮保留所选日期索引 |
| `application/rbt/controller/Index.php::GetScoreHis`、`GetScoreHisDetail` | `Hby019SourcePage.vue` → `GET /api/admin/player-desk/points-records` | 前端已发送 `timeType`，当前桥接只传日期并丢弃模式 |
| `application/common.php::get_time_arr` | `PlayerPointsReportService.resolveBusinessDay` | 0 点：`[day 00:00, day+1 00:00)`；6 点：`[day 06:00, day+1 06:00)`。当前 Xupan 固定 6 点 |
| `getTimeList*`/日期选择器 | `availableDates`、`local-api-bridge.updateReportDates` | 当前 HTML 隐藏数组仍是 2026-10-07 至 10-14，桥只更新可见标签，切换时读到静态旧值 |

BY220 语义来源（静态源码）：`_github-by220-cp/application/common.php` 中 `get_time_arr`（约 4030 行）、`get_score_his`（约 4660 行）；运行态未在本任务中启动 BY220。

## 3. 修复内容

1. 后端报表 API 接受 `cutoffHour=0|6`，默认 6；按 Asia/Shanghai 计算业务窗口，并返回当前模式及两种模式的可用日期。
2. HBY019 桥接将 `timeType` 映射为 `cutoffHour`，积分汇总、托汇总、会员详情和上下分记录统一使用该窗口。
3. 服务端日期响应动态填充 `day0_*`、`day1_*`，切换时保持相同日期；若该日期在目标模式尚未发生，则选目标模式最近可用日。
4. 删除前端对 2026-10-07 至 10-14 静态日期的运行时依赖，保留 06:00 默认行为供非 HBY019 玩家工作台调用。

## 4. 验收

- 06:00 模式窗口为 06:00 到次日 06:00，00:00 模式窗口为当日 00:00 到次日 00:00，均按半开区间计算。
- 按钮切换后 API 的 `cutoffHour` 与窗口发生变化，所选日期有效时保留，不再请求 HTML 中的静态旧日期。
- 跨 00:00 和 06:00 边界验证两个模式的业务日归属；日期标签、汇总和明细使用同一模式/日期。
- 旧 API 调用不传 `cutoffHour` 时仍按 06:00 统计。

## 5. 实施记录

- BY220 `get_time_arr` 的业务语义已复核：`timeType=0` 使用自然日 00:00 至次日 00:00；`timeType=1` 使用 06:00 至次日 06:00。BY220 仅静态源码核对，未启动其运行环境。
- Xupan 报表 API 已接受 `cutoffHour=0|6`（缺省仍为 6），按 Asia/Shanghai 半开区间查询，并返回两种截点各自的动态日期列表。HBY019 桥已将 `timeType` 映射为 `cutoffHour`；汇总、托汇总、会员详情及 Way2/Way3 记录查询均传递该模式。
- HBY019 日期桥接现用服务端日期更新 `day0_*`、`day1_*` 隐藏数组；日期切换保留当前日期，若目标模式还未到该日期则选目标模式的最新可用日。旧静态 2026-10-07 至 10-14 日期已清空；`showdetails` 展开页链接带上当前截点，且未选中的短日期通过 `data-full` 请求 ISO 日期。
