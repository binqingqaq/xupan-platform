# 下注榜实施计划

## 1. 计划状态

- 状态：本机实现和验证完成；服务器、生产现场和撤单能力未纳入本阶段。
- 日期：2026-09-23
- 所属模块：[运营后台与报表](../业务模块/06-运营后台与报表.md)、[期号玩法下注与结算](../业务模块/03-期号玩法下注与结算.md)
- 关联模块：身份与权限、虚拟积分、玩家分类、游戏期号和开奖。
- 目标：在 `/console` 左侧功能导航下方增加只读“下注榜”，让管理员按当前期查看普通玩家和托的下注情况，并查看最近 18 期开奖和当前倒数。

## 2. 用户已确认规则

- 下注榜包含四个页签：`普`、`托`、`上期`、`开奖`。
- `普` 和 `托` 展示当前期下注情况，按钮括号内显示对应下注单数量。
- 下注榜标题右侧显示当前期普通玩家和托的下注总积分。
- 当前期下注项展示昵称、重建后的玩法文本、单笔积分和右侧 `×`。
- 当前阶段 `×` 必须保留显示，但禁用，不实现管理员撤单。
- `上期` 当前保持空白，不伪造数据。
- `开奖` 展示最近 18 个已结算期号，每期显示 8 个位置的番值和状态。
- 开奖页倒计时与当前期服务端阶段截止时间同步，不依赖浏览器本地时钟单独计算。
- 下注榜放在后台左侧功能导航下方，原有“模块预留”和“兼容入口”继续向下排列。

## 3. 实施边界

### 本次纳入

- 只读查询当前期、普通玩家/托聚合数量、总积分和下注明细。
- 只读查询最近 18 个已结算期号和 8 个位置番值。
- `USER_MANAGE` 权限校验。
- 前端 3 秒轮询、服务端时间校准和阶段倒计时。
- 桌面端和 375px 基础布局验证。
- `×` 的禁用保留和组件级测试。

### 本次不纳入

- 管理员撤单、退款、注单状态改变和相关审计。
- `上期` 榜单规则和交互。
- 导出、搜索、分页历史榜、图表和多游戏支持。
- 服务器、生产数据库和正式运营验收。

`×` 后续接入撤单时，必须另立计划，至少补齐权限、二次确认、幂等、事务、虚拟积分退回、流水、审计、开奖竞态和失败恢复，不能直接解除当前禁用属性。

## 4. 数据与接口设计

### 4.1 数据来源

- 当前期：`game_issue`。
- 下注单：`game_bet`。
- 玩家分类：`demo_user_account.player_kind` 的 `NORMAL` 或 `BOT`。
- 开奖历史：`game_issue` 已结算记录。
- 本次不新增表、字段或 Flyway 迁移；下注榜是已有事实的只读装配，不建立第二套统计事实源。

### 4.2 统计口径

- `普`：`player_kind = NORMAL`。
- `托`：`player_kind = BOT`。
- 数量和总积分均排除 `CANCELED` 注单。
- 当前期下注项按下注时间倒序、注单 ID 倒序返回。
- 单次最多返回 500 条当前期明细。
- 开奖历史固定最多 18 期，展示 8 个位置的番值；番值按号码计算结果映射为 1 到 4。

### 4.3 接口

```text
GET /api/admin/player-desk/bet-board?kind=NORMAL|BOT&limit=500
```

权限：

- 必须已认证。
- 必须具备 `USER_MANAGE`。
- 普通玩家返回 403。

响应主要字段：

```text
issueNumber / phase / serverNow / phaseEndsAt
normalCount / botCount / normalStake / botStake
items[] / history[]
```

## 5. 前端行为

- `BetBoardPanel.vue` 挂载在 `/console` 左侧导航下方。
- `普` 和 `托` 切换时重新请求对应分类。
- `上期` 只显示空白面板。
- `开奖` 显示标题、倒计时和 18 期表格。
- 倒计时使用服务端响应中的 `serverNow` 与本机时间计算偏移，再基于 `phaseEndsAt` 递减。
- 当前期列表中的 `×` 使用真实禁用按钮保留视觉位置，并提供“管理员撤单功能暂未开放”的提示。
