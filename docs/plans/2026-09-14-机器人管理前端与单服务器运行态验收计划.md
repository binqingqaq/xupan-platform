**目标：** 在已经完成的服务端常驻机器人基础能力之上，增加可受权限控制的机器人管理前端，并完成单服务器、单 Spring Boot 实例下的配置、消息发布、重启恢复和数据边界验收。

**架构：** 前端新增受保护的 `/admin/robots` 页面，直接调用现有 `/api/admin/robots` 后台 API，不新增机器人业务表或第二套管理接口。机器人运行仍由现有 `RobotDispatchScheduler` 每秒扫描已提交的 `game_issue_event`，通过 `chat_message`、`chat_outbox` 和提交后 WebSocket 广播链路发布消息。运行态验收以独立 MySQL 8.4.11 验收库为基础，单实例重启恢复和数据库幂等为本阶段边界。

**技术栈：** Vue 3、TypeScript、Vite、现有 `api.ts` 会话封装、Spring Boot 4.0.8、Java 21、Spring JDBC、Flyway、MySQL 8.4 LTS、H2 测试配置、现有 Spring Security/JWT、单实例 WebSocket 和 `chat_outbox`。

## 全局约束

- 当前只支持一台服务器、一个 Spring Boot 实例；不得在本计划中引入 Redis、MQ、多实例任务协调、分布式锁或跨节点 WebSocket 广播。
- 必须复用现有 `RobotAdminController`、`RobotAdminService`、`ChatMessageService`、`RobotDispatchScheduler` 和认证刷新机制；不复制一套机器人接口或前端身份体系。
- 前端不能接受客户端自报的机器人身份、发送者名称、头像、`senderId`、消息类型或投递状态；这些字段只能来自服务端响应。
- 机器人不是 `sys_user`，不创建用户、不进入 `demo_user_account`、`demo_balance_ledger` 或 `game_bet`。
- 当前余额仍是管理员分配的虚拟演示余额，不接入充值、提现、第三方支付、真实资金或代理分成。
- 机器人消息必须继续经过 `chat_message`、`chat_outbox` 和事务提交后的广播；前端不能通过 WebSocket 控制台或本地假消息伪造机器人消息。
- 所有配置写操作必须由服务端权限控制：查看使用 `ROBOT_READ`，机器人启停/新增/编辑和失败重试使用 `ROBOT_WRITE`，模板更新和预览使用 `ROBOT_TEMPLATE_WRITE`。
- 机器人代码字段必须遵守后端约束：小写字母、数字、下划线和连字符，长度不超过 32；权重范围为 1-100；延时范围为 0-300 秒。
- 模板文本必须遵守服务端纯文本、变量白名单、长度和事件变量约束；前端校验只用于减少无效提交，不能替代服务端校验。
- 页面必须支持加载中、空数据、提交中、成功、参数错误、401、403、404、409 和网络失败状态；不能让失败请求静默消失。
- 不在仓库、浏览器日志、截图、验收记录或命令输出中写入密码、Token、Cookie、ticket、完整会话 URL 或真实数据库凭据。
- 现有 `README.md` 和 `docs/项目记忆.md` 已同步到机器人后端完成状态；实施结束时只补充本阶段真实结果，不覆盖历史阶段记录。

## 后端 API 契约

前端实现必须以当前 `RobotAdminController` 和 `RobotAdminResponse` 为准，不能自行改变字段名或把服务层内部对象直接暴露给页面。

| 页面能力 | 方法和路径 | 权限 | 请求体/查询参数 | 响应 |
| --- | --- | --- | --- | --- |
| 机器人分页 | `GET /api/admin/robots?page=1&pageSize=20` | `ROBOT_READ` | `page`、`pageSize` | `RobotPage` |
| 机器人详情 | `GET /api/admin/robots/{robotId}` | `ROBOT_READ` | 路径 ID | `RobotDetail` |
| 创建机器人 | `POST /api/admin/robots` | `ROBOT_WRITE` | `CreateRobot` | `201 RobotDetail` |
| 编辑机器人 | `PUT /api/admin/robots/{robotId}` | `ROBOT_WRITE` | `UpdateRobot` | `RobotDetail` |
| 启停机器人 | `PATCH /api/admin/robots/{robotId}/status` | `ROBOT_WRITE` | `{ "status": "ENABLED" }` 或 `{ "status": "DISABLED" }` | `RobotDetail` |
| 模板列表 | `GET /api/admin/robots/{robotId}/templates` | `ROBOT_READ` | 路径 ID | `TemplateList` |
| 更新模板 | `PUT /api/admin/robots/{robotId}/templates/{eventType}` | `ROBOT_TEMPLATE_WRITE` | `{ "templateText": "..." }` | `TemplateSummary` |
| 模板预览 | `POST /api/admin/robots/{robotId}/templates/{eventType}/preview` | `ROBOT_TEMPLATE_WRITE` | `{ "templateText": "..." }` | `TemplatePreview` |
| 投递分页 | `GET /api/admin/robots/dispatches` | `ROBOT_READ` | `issueNumber`、`eventType`、`status`、`from`、`to`、`page`、`pageSize` | `DispatchPage` |
| 失败重试 | `POST /api/admin/robots/dispatches/{dispatchId}/retry` | `ROBOT_WRITE` | 无请求体 | `DispatchSummary` |

页面需要处理的响应结构：

```ts

  | 'ISSUE_STARTED'
  | 'BETTING_WARNING'
  | 'BETTING_CLOSED'
  | 'DRAW_RESULT'

type RobotStatus = 'ENABLED' | 'DISABLED'
type RobotDispatchStatus = 'PENDING' | 'PROCESSING' | 'FAILED' | 'PUBLISHED' | 'SKIPPED'

interface RobotSummary {
  id: number
  robotCode: string
  displayName: string
  avatarKey: string
  status: RobotStatus
  weight: number
  delaySeconds: number
  createdAt: string
  updatedAt: string
}

interface RobotDetail {
  robot: RobotSummary
  templates: TemplateSummary[]
  dispatchStatistics: {
    pending: number
    processing: number
    failed: number
    published: number
    skipped: number
  }
}

interface RobotPage {
  items: RobotSummary[]
  page: number
  pageSize: number
  total: number
}

interface TemplateList {
  items: TemplateSummary[]
}

interface TemplateSummary {
  id: number
  robotId: number
  eventType: RobotEventType
  templateCode: string
  templateText: string
  enabled: boolean
  version: number
  createdAt: string
  updatedAt: string
}

interface TemplatePreview {
  eventType: RobotEventType
  version: number
  templateText: string
  renderedText: string
  issueNumber: string
  eventMessage: string
}

interface DispatchSummary {
  id: number
  gameEventId: number
  robotId: number
  issueNumber: string
  eventType: RobotEventType
  status: RobotDispatchStatus
  attemptCount: number
  nextAttemptAt: string | null
  lockedUntil: string | null
  messageId: number | null
  lastError: string | null
  createdAt: string
  updatedAt: string
  publishedAt: string | null
}

interface DispatchPage {
  items: DispatchSummary[]
  page: number
  pageSize: number
  total: number
}
```

## 后续边界
