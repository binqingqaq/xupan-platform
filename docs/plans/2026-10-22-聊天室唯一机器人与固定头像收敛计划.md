# 聊天室唯一机器人与固定头像收敛计划

> 状态：代码与迁移已完成，未运行测试/构建，未部署服务器（2026-10-22）。

## 目标

- 玩家聊天室只存在普通玩家和一个服务端机器人两类发言身份。
- 唯一机器人固定显示名“机器人”，固定使用本机绿色 Android 头像；图片作为静态资源随应用发布，不依赖某个环境中的上传目录或数据库头像键。
- 保留唯一机器人内部记录，继续为开奖事件、模板、消息派发和审计提供稳定关联；不允许通过后台 API 新增机器人、修改机器人身份/头像或停用唯一机器人。
- 自动上下分、托下注、结算及失败退单等聊天室提示均以该机器人身份发出。
- 历史 `SYSTEM` 聊天消息在迁移中归并到唯一机器人，保留原消息内容、期号、时间、序号、机器可见范围和幂等键；不改后台审计、钱包流水及托动作记录。

## 实施步骤

1. 已将确认规则同步到项目方案和聊天室/机器人业务模块文档。
2. 已将绿色 Android PNG 固化为 Web 与 Spring 静态资源，机器人聊天头像解析固定返回该资源。
3. 已收敛机器人管理 API 和页面为单一固定身份；模板、开奖组件和投递记录仍可管理。
4. 已将机器范围内的聊天室运营通知改为唯一机器人消息；托自动上下分只发布一条完成反馈。
5. 已增加 V86 Flyway 迁移，固定机器人属性、停用历史额外机器人记录、归并历史聊天身份并同步 outbox 身份字段。
6. 已调整受影响的既有测试断言；本阶段未运行测试/构建，未部署服务器。

## 验收边界

- 静态代码与迁移检查：单机器人入口、固定头像资源、自动通知发送者、历史记录保留范围均与规则一致。
- 测试/构建仅在使用者要求验证时执行；服务器与生产部署和数据库迁移不属于本计划。
- 不删除机器人派发、模板、组件配置、钱包流水或操作审计能力。
