# 汇博盈页面复刻实施计划

## 1. 计划状态

- 状态：实施中
- 日期：2026-09-10
- 依据：[当前需求基线：汇博盈页面复刻](../需求基线/2026-09-10-汇博盈页面复刻.md)
- 参考证据：用户当前会话提供的可访问参考页，以及只读视觉审计记录
- 目标：先完成用户前台的视觉和可见交互复刻，再单独确认后端玩法、权限和生产逻辑

## 2. 实施边界

### 本次纳入

- Vue 3 用户前台的参考页布局、颜色、字体层级、固定区域和响应式行为。
- 顶部余额/用户/快捷/界面/菜单区域、期号和 8 球开奖条。
- 聊天消息流、下注输入、数字键盘、快捷入口、玩法说明和搓牌开奖入口。
- 已从参考页确认的界面切换、历史查看和设置等可见状态；数据先使用当前演示 API 或明确标注的演示数据。
- 桌面端和窄屏无横向溢出、控件可操作和构建验证。

### 本次不纳入

- 参考站点的源代码、静态资源、账号、真实数据、私有接口或随机访问标识。
- 未经用户确认的真实投注、资金、生产权限、生产级开奖源和生产部署逻辑；演示自动轮期按单独计划实现。
- 把演示数据或前端视觉行为当成后端玩法规则已经确认。

## 4. 验收证据

完成时至少保存以下事实到交接记录或最终报告：

1. `npm run typecheck` 通过。
2. `npm run build` 通过，构建产物能被 Spring Boot 静态资源目录使用。
3. 浏览器中默认视图无 `NaN`、消息区可滚动、输入可发送、键盘可展开、搓牌层可打开和关闭。
4. 界面 2、历史和设置入口能打开对应的可见状态；窄屏 `390px` 级别视口无页面级横向溢出仍待本地运行时截图复核。
5. 仍未实现或无法由参考证据确认的后端规则，在文档中明确标为“未确认/未执行”。
