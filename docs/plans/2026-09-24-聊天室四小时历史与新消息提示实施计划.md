# 聊天室四小时历史与新消息提示实施计划

## 1. 计划状态

- 状态：本机实现和浏览器验证完成；服务器与生产现场待验收。
- 日期：2026-09-24
- 所属模块：[聊天室与实时消息](../业务模块/04-聊天室与实时消息.md)、[展示端与玩家前台](../业务模块/07-展示端与玩家前台.md)
- 目标：玩家向上滚动时按游标加载最近4小时历史消息，并在查看历史时显示可点击的新消息提示。

## 2. 用户已确认规则

- 聊天室最多向上查看最近4小时消息。
- 一直向上滑动时自动加载更早消息，直到4小时边界或没有更多数据。
- 已达到4小时边界时，在消息区顶部显示明确状态。
- 用户不在消息底部时，新消息不强制拉回底部。
- 有新消息时，在右下角显示`▼ N条新消息`气泡。
- 点击新消息气泡后回到当前聊天底部，并清除提示。

## 3. 实施边界

### 本次纳入

- 复用现有`beforeSequence`历史分页接口。
- 前端按服务端时间和4小时窗口过滤。
- 向上滚动自动分页、保持当前阅读位置。
- 浮动新消息提示和点击回到最新位置。

### 本次不纳入

- 修改聊天室数据库结构。
- 删除或归档4小时之前的消息。
- 服务器、生产环境和超长运行容量验证。
