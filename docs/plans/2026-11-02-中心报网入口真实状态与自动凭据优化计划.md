## 实施与验收

1. 代理页不得再用浏览器本地模拟的 `50000`、在线状态或账号名充当中心报网事实；未分配额度显示 `0.00`，类型始终 `loc`。页面读取失败时显示错误，不回退为成功模拟。
2. 中心账号创建表单不再要求手填账号密码；服务端按 `loc<代理子账号ID>_<随机后缀>` 生成全局唯一账号，密码由安全随机数生成小写字母与数字，符合现有密码策略，仅在创建响应展示一次，库内只存哈希。保留旧手填 API 的兼容性供既有调用使用。
3. 新账号默认初始额度仍为 0；只有已有额度调整操作或现有账本规则可改变额度。机器积分风险补足保持原规则。
4. 定向测试覆盖创建、唯一性、密码格式、真实报网状态接线、开关和错误路径；本机浏览器与 MySQL 验证单独记录实际执行范围。

## 边界

- 不修改既有中心账号、额度、订单或历史数据，不运行迁移；不引入外部上游或真实凭据。
- 不改其他管理菜单、玩家下注解析、开奖、结算或机器人行为。
