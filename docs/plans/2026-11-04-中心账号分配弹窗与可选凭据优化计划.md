# 中心账号分配弹窗与可选凭据优化计划

> 日期：2026-11-04
> 范围：只调整超级管理后台“中心上游 → 中心账号”的分配界面和账号凭据输入；不改其它中心业务。
> 状态：代码已实施；测试、类型检查、构建和浏览器验收未执行。

## 目标

- “分配中心账号”改为与子账号、机器账号一致的二级弹窗。
- 弹窗保留代理子账号、初始额度和有效期设置，增加可选用户名与密码。
- 用户名留空时保留现有格式 `loc<代理子账号ID>_<10位小写字母数字>`，并继续处理唯一名冲突。
- 密码留空时使用 `test123456`；手动填写时使用填写值。两种情况都经过现有密码策略校验，数据库只保存 BCrypt 哈希，创建结果中的凭据仍只展示一次。
- 默认密码由所有未填写密码创建的账号共用，弹窗需明确提示。

## 页面、接口与数据映射

| 页面/操作 | 当前实现 | 本轮处理 |
| --- | --- | --- |
| `/platform-admin/center` → 中心账号 → 分配中心账号 | 内联选择代理子账号、额度、有效期；服务端自动生成账号和随机密码 | 二级弹窗收集同样字段及可选用户名/密码 |
| `POST /api/admin/center/accounts/generated` | 接收子账号、额度、有效期；账号和密码均随机生成 | 接口保留，新增可选用户名/密码，缺省采用本计划规则 |
| 账号归属、唯一约束、额度流水、密码哈希和一次性凭据返回 | 现有服务端能力 | 保持事务与数据规则不变 |

## 验收范围

- 前端：弹窗打开/关闭、可选用户名和密码、空值缺省、创建结果一次性展示。
- 后端：缺省用户名格式、缺省固定密码、显式凭据、用户名冲突、密码 BCrypt 哈希、密码不进入日志或账号列表。
- 不改订单、报网开关、风控、结算、账本、账号编辑/删除或数据库迁移。

## 安全说明

固定默认密码 `test123456` 可被所有未显式输入密码的新账号共用，弱于随机凭据。弹窗会提示这一点并建议正式使用时填写独立密码；后端仍只存哈希，明文只随创建响应返回一次。

## 实施与验证记录（2026-11-04）

- `/platform-admin/center` 的分配表单已改为二级弹窗；保留子账号、初始虚拟额度和有效期，增加可选用户名/密码。取消或关闭弹窗会清除密码输入。
- `/api/admin/center/accounts/generated` 接受可选用户名/密码。空用户名保留 `loc<groupId>_<10位小写字母数字>` 及冲突重试；空密码为 `test123456`；自定义密码和默认密码均经过现有 8–72 位且至少含字母/数字的策略，BCrypt 哈希后存储。账号密码仍只在创建响应显示一次，审计和 `toString()` 不含密码。
- 未改数据库结构、账号归属约束、额度账本、有效期规则、报网、订单、风险或结算逻辑。
- 前端和后端原有凭据用例已按新规则调整；本轮没有运行自动化测试、类型检查、构建、MySQL 或浏览器验收。
