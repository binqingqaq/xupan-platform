# 历史计划：聊天室前台与演示后台改造（已被当前需求替代）

> 状态：历史计划，不再作为当前用户前台的实施依据。
>
> 历史计划：本计划完成的是一个自定义的 Vue 聊天室式演示页面，不能证明已经复刻汇博盈页面。当前页面以 [汇博盈页面复刻实施计划](2026-09-10-汇博盈页面复刻实施.md) 为准。

> 本计划承接首期 8 球玩法演示，目标是完成可验证的用户前台与演示后台闭环。余额为虚拟演示余额，不代表真实资金能力。

## 1. 当前事实

- 当前首期前端原本是 Spring Boot 托管的原生 HTML/CSS/JavaScript 单页，本计划将其替换为 Vue 前端。
- 当前后端已有期号、赔率、下注、开奖和结算能力。
- 当前没有用户账户、余额流水、后台页面和用户与注单的关联。
- 汇博盈页面只作为界面组织和交互参考，不复制其代码、资源、账号、数据或接口。

## 2. 目标闭环

```text
后台修改赔率 -> 用户前台刷新赔率 -> 演示用户下注
后台调整演示余额 -> 用户前台显示余额
后台录入 8 个中奖号码 -> 前台消息流显示开奖和结算结果
```

## 3. 技术和目录

- 新增根目录 `web/`，使用 Vue 3、TypeScript、Vite。
- 用户前台路由：聊天室式下注页。
- 管理后台路由：赔率、账户、开奖、注单核对页。
- 公共层：API 客户端、类型、玩法标签、金额和状态展示工具。
- 后端暂时保留单体 Spring Boot；开发环境前后端独立运行，发布时构建到 Spring Boot 静态资源目录。
