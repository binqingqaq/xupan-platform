# 后台界面复古运营台重构计划

> **计划状态：** 本机实施完成（2026-09-28）；375px 真实设备/浏览器、MySQL 8.4、服务器和生产验收未执行。
>
> **目标：** 在不改变后台业务逻辑、接口、权限、数据库事实和操作语义的前提下，将后台前端重构为参考图所示的紧凑复古桌面运营台，并保留手机端整页缩放查看能力。

## 1. 范围

本次只修改后台前端布局、组件结构、视觉样式和测试：

- 统一后台壳层 `/console`。
- 玩家工作台及已嵌入面板。
- 兼容入口 `/console/operations`、`/console/users`、`/console/robots` 的后台主题。
- 后台路由进入时的全局主题类与共享样式变量。

## 2. 明确不变

- 不修改任何 REST API、WebSocket、权限编码、路由权限和认证逻辑。
- 不修改 Flyway、数据库结构、钱包、积分、下注、开奖、结算、玩家身份和机器人业务规则。
- 不新增充值、支付、提现、转账、代理分成或现实资金语义。
- 不新增假数据、演示接口或未实现按钮。
- 不删除兼容入口和现有功能。

## 3. 视觉方向

- 参考旧式 Windows 桌面运营软件，而不是现代卡片式 Web 后台。
- 以约 1000px 为后台固定设计宽度，手机端继续由视口缩放整页查看。
- 使用浅灰蓝背景、白色工作区、蓝色 1px 边框、淡蓝标题栏、紧凑状态条和小圆角。
- 保持“状态—列表—详情—操作”的高密度信息结构；功能不隐藏、不搬离同一页面。
- 页面只允许上下滚动；列表和长内容在容器内部滚动，不产生页面级横向滚动。

## 4. 分工

- 主协调：共享主题变量、路由主题挂载、文档、集成和验收。
- UI 壳层 agent：`UnifiedAdminPanel.vue`。
- 玩家工作台 agent：`PlayerWorkbenchModule.vue`。
- 面板 agent：欢迎栏、下注榜、报网控制、上下分确认、最近记录、底部控制、线路域名和占位组件。
- 兼容页面 agent：旧运营页、用户管理页和机器人管理页。
- 边界审查 agent：检查业务逻辑、接口调用、权限文案和测试契约未被改变。

## 5. 验收

- `npm run test:run`
- `npm run typecheck`
- `npm run build`
- 静态检查后台各页面无页面级横向溢出。
- 差异审查确认没有修改 `api.ts`、后端控制器、Flyway 和权限路由。
- 未执行的 375px 真实浏览器截图、MySQL 8.4、服务器和生产验收必须明确标注。
