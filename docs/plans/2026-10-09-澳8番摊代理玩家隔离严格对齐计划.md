## 1. 对齐目标

严格按 BY220 澳8番摊的可观察业务关系迁移到 Xupan：机器账号创建的普通玩家与托归该机器；玩家链接只进入对应玩家身份；机器玩家区的聊天、下注消息和机器内排行不能串到其他机器；同一澳8番摊的期号/开奖号码与公共开奖播报保持共享。玩家账户、机器后台汇总及流水继续按实际归属查询。

“每个机器一套独立前端部署”不是 BY220 的证据，也不是此计划的目标。BY220 使用同一页面实现；隔离边界来自链接解析出的玩家/机器身份、消息筛选条件和数据查询条件。前台仍可复用同一套 HTML/Vue 页面。

### BY220 隔离结论

- **代理玩家消息不是全平台互通**：普通聊天、玩家下注消息和机器相关反馈由 `rid=机器用户名` 分区；澳8的 `gameType` 再限定彩种。同一机器名下的普通玩家与托（托也是该机器的玩家账号）处于同一 feed，可见彼此公开发言、下注和托投注消息；跨机器不可见。
- **开奖公共消息是共享面**：同一游戏名的公共开奖、期号播报可进入各澳8玩家房间。
- **机器内部可见并非“每个玩家互相看不见”**：BY220 同一机器的普通玩家与托能在本机 feed 中看到彼此公开发言、下注和托投注消息；隔离边界是机器，不是单个玩家。
- **同页不同房间**：链接把玩家关联到机器数据上下文；`rbDomain` 可令链接 host 不同，但 host/页面模板本身不是数据隔离的充分条件。

## 5. 实施目标草案（严格按 BY220 可证口径）

1. 从已兑换玩家会话在服务端查 `demo_user_account.agent_id` 得到 tenant；不接受 URL、请求体或 WebSocket subscribe 中由客户端任意指定机器 ID。
2. 每个玩家链接进入同一套 `/room` UI；后端按该玩家机器读取机器私有聊天室 feed。玩家和托在同一机器范围内共享公开聊天/下注消息，跨机器不可见。
3. 同一 AU8 的全局期号、开奖结果和公共开奖主持播报，对所有 AU8 机器玩家共享；不复制 `game_issue`/结算事实。
4. 机器私有的普通玩家发言、下注消息、下注失败/成功反馈、托投注消息和机器获奖/核对摘要只发给该机器房间；同一机器内普通玩家与托共享这些公开消息。托账号按所属 `agent_id` 隔离，不是跨机器共享身份。
5. 玩家端“我的下注”当期列表按 BY220 `getRecord` 口径严格查询当前玩家本人、当前彩种的注单；账户页签、下注历史、余额与个人积分账本也只按当前玩家账号查询。玩家聊天室公开下注消息按当前机器共享；机器下注榜、待结算单、玩家注单明细、上下分/积分流水、流水统计按当前 `agent_id` 覆盖该机器的普通玩家与托，不得跨机器。保留每一笔下注和虚拟积分账本事实，不因聊天室隔离或清理旧消息而迁移/删除。
6. `/console` 继续只管理自己机器；链接 token 继续只绑定玩家身份。机器归属从玩家记录推导，使用同一个 URL 前端并不改变隔离边界。
7. `/display/mobile` 是单独的全局只读展示；是否继续全站可见不属于代理玩家房间隔离，不在本专项改变。

## 6. 已选数据模型

BY220 的逻辑读取集合是：

```text
当前机器 M、彩种 AU8 的 feed
  = machine-private (rid = M, gameType = AU8)
  + public-game (uid = AU8 游戏名, gameType = AU8)
```

采用**单物理 `main` 房间 + 消息可见范围快照**：`chat_message.visibility=PUBLIC|MACHINE`，`agent_id` 保存机器历史归属且不设外键；PUBLIC 消息所有有效 AU8 玩家可见，MACHINE 消息只对当前机器可见。用户/托和反馈按 MACHINE 写入；澳8公共开盘、封盘、开奖结果摘要按 PUBLIC 写一条；封盘核对列表和中奖名单按每台启用 AU8 机器单独幂等投递。

选择该模型保留单序号、单游标、现有 REST 补偿路径和公共消息单份存储；物理删除机器不会把旧私有消息改成公共消息。V78 不删除 room 和 sequence，也不删除机器人派发事件，只解除其旧 message 引用。

不采用“把 URL 加机器号后就算隔离”或“前端本地隐藏其他消息”。访问控制必须落在服务端读/写查询和 WS 广播边界。

## 8. 已确认口径与实施结果

1. **旧 `main` 聊天历史：使用者确认可以删除。** V78 清理旧 `main` 消息、对应 outbox/read cursor，并将托行为 `message_id` 置空；开奖 dispatch 保留状态和事件但解除旧 message 关联。该迁移在 H2 验证通过，未应用到本机 MySQL 或服务器数据库。AU8 期号/开奖结果、玩家账户、注单、钱包与机器账本不在删除范围。
2. **玩家与托隔离**：同一机器名下普通玩家与托属于同一代理玩家房间，可以看到彼此公开发言、下注、托投注和本机反馈；不同机器之间不可见。托是 `agent_id` 下的玩家账号，不是全局共享身份。
3. **开奖主持机器人**：同一 AU8 的公共开奖结果跨机器共享；机器内核对/中奖排行与玩家下注反馈只在本机显示。开奖主持机器人和代理创建的托账号是两类身份。
4. **玩家个人记录**：BY220 `getRecord` 按当前玩家 `wxid` 和彩种读取本人注单；同机公开下注消息和机器下注榜仍按机器共享。
5. **域名范围**：本专项不改线路域名、链接 host 或 TLS；隔离依赖服务端解析的玩家身份和机器归属。BY220 的 `rbDomain` 是链接 host 配置，不是数据隔离依据。
