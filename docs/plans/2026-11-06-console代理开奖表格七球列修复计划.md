# 代理后台 AU8 七球开奖表格修复计划

## 目标

修复 `/console` 代理后台开奖记录仍显示空白第八球框的问题。AU8 已按使用者决定固定七球；开奖区域应只有期号、1–7 球和状态。

## 代码映射与根因

| 环节 | 当前实现 | 修复 |
| --- | --- | --- |
| 后端/桥接数据 | `Hby019SourcePage.vue` 的 `loadHbyOpenResults()` 返回 7 个 `fans` | 不改数据契约 |
| HBY019 模板网格 | `console.html` 使用 `repeat(8, 1fr)` | 改为 `repeat(7, 1fr)` |
| 开奖列头 | 固定输出球号 1–8 | 仅输出 1–7 |
| 每期结果行 | 循环生成 8 个球位；第 8 位为空 | 循环仅生成 7 个球位 |
| 空数据标题 | 默认文案仍为“澳8番摊/8球” | 更正为“澳8番摊/7球” |

根因在 HBY019 代理后台 HTML 模板的固定 8 球呈现代码，后端开奖记录及 Xupan 桥接已经是 7 球。

## 范围

仅修改 `web/public/hby019-demo/source/console.html` 的开奖表格显示。不改开奖数据、状态、倒计时、历史筛选、其它页面、数据库和 API。

## 验收

- 表头显示球号 1–7，不显示 8。
- 每条开奖记录只生成 7 个球位，状态列紧随第七球，不留空白第八格。
- 空列表标题也使用七球文案。
- Vite 构建成功且构建后的 `/hby019-demo/source/console.html` 已更新。
- 只验证本机工作区；服务器和生产未操作。
