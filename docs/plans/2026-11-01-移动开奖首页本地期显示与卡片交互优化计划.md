# 移动开奖首页本地期显示与卡片交互优化计划

> 状态：2026-11-02 按使用者后续反馈屏蔽快乐8历史面板和点击项；Java 编译、两份脚本语法及 8080 页面/脚本/API 检查通过。浏览器视觉和点击仍待人工确认。
> 范围：仅调整 `/display/mobile` 快乐8卡片的 AU8 数据文案和“最新开奖/历史记录”操作；其余彩种卡片、号码颜色及布局不变。

## 目标

1. 屏蔽快乐8卡片上原有的“最新开奖/历史记录”点击项和分页历史面板；右侧只保留静态“历史记录”字样，不可点击。当前期开奖仍通过橙色刷新按钮更新。
2. 移除所有彩种卡片中的“直播开奖”字样。
3. 将“本地期 032 截止下注 20:59”改为图二格式，显示当前周期之后预期开始的下一期号和北京时间。下一期号为当前本地期号加一，下一期开启时刻取当前期 `drawEndsAt`；轮期服务根据当前期开始时刻和周期长度保存 `drawEndsAt`。
4. 顶部倒计时继续从当前期开始后的投注截止时刻倒数。倒计时归零/进入 DRAWING 后，顶部倒计时与下一期时间文案改为“开奖中”；开奖结果更新并进入新一期后，刷新为新下一期号及北京时间。

## 实施映射

| 位置 | 修改 |
| --- | --- |
| AU8 期次接口 / 轮期服务 | 当前期提供 `issueNumber`、`bettingEndsAt` 和 `drawEndsAt`；下一期开启时间等于当前期 `drawEndsAt` |
| 两份官方复刻 `page.js` | 快乐8显示预期下一期号/北京时间；投注截止后显示“开奖中”，轮期后刷新；移除所有“直播开奖”标签和快乐8历史面板；其他彩种卡片及其历史入口不变 |
| 卡片操作 | 快乐8静态展示“历史记录”但不提供历史操作；当前开奖由橙色刷新按钮调用 `/api/display/mobile/au8` |
