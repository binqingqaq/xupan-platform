# 移动开奖首页外部数据映射计划

## 目标

将本地 123 论坛首页快照作为 `/display/mobile` 的页面内容，保持页面 HTML/CSS 呈现不变；在快照已有开奖记录节点上，通过 Xupan 后端 `GET /api/display/mobile/home` 更新能明确对应的开奖数据。前端不直接请求参考站或外部开奖服务。

## 对照与决定

| 参考页栏目 | 后端返回 | 决定 | 依据 |
| --- | --- | --- | --- |
| 香港彩 | `hong-kong` / `香港彩` | 接入 | 栏目名称一致；本机接口期号 `112`、下期开奖时间与参考页一致。 |
| 快乐8 | `happy-eight-six` / `快乐8六合彩` | 接入并在展示层简写为“快乐8” | 本机接口期号 `280`、下期开奖时间与参考页一致。 |
| 新澳彩 | 无匹配类型 | 不替换 | 返回的 15 类中没有新澳彩，不能由相似号码结构推断。 |
| 老澳彩 | 无匹配类型 | 不替换 | 返回的 15 类中没有老澳彩，不能由相似号码结构推断。 |
| 其他六合彩 | `bingo-six` / `宾果六合彩` | 不展示为参考页栏目 | 名称、期号序列与开奖时间均不对应。 |

接口检查时响应为 `stale=false`。香港彩期号移除接口值中的年份前缀后展示；快乐8期号同样去掉年份前缀。号码、颜色、生肖、下期开奖时间和倒计时使用接口数据。首页默认选择已有接口映射的香港彩，避免首屏先展示无匹配数据的新澳彩快照。新澳彩和老澳彩保留页面快照的原始展示，不宣称为实时数据。接口不提供历史开奖明细及独立的下一期期号，因此这些内容不改写为实时数据；前端仅接受 `stale=false` 的响应，旧快照或请求失败时保留当前内容并按退避间隔重试。

## 实施与验证边界

- 复用独立本地复刻项目生成的 HTML、CSS 和静态资源，由 Spring Boot `/display/mobile` 直接提供；不要求页面使用 Vue，保留复刻 UI；静态资源只从 Xupan 同源路径加载。
- 后端接口与数据库不变；不复制参考站登录态、接口地址、凭据和外部脚本。
- 保持外部源由后端现有客户端请求；浏览器只调用本地 Xupan API。
- 验证数据桥接脚本语法、前端类型检查和生产构建。
- 已在浏览器打开 `/display/mobile`，确认首页渲染、香港彩第 112 期和快乐8第 280 期号码由本机页面显示；本机健康检查为 `UP`，页面 HTTP 200。此检查不代表服务器或生产可用性。
- 浏览器复核发现 API `stale=true` 回退被前端当作新数据接受，导致第 109 期快照覆盖页面；现改为忽略旧快照并退避重试。默认选择香港彩，并同步两类已匹配彩种的开奖时间和逐秒倒计时。
- 本机接口响应只证明本轮检查时的本机运行态，不代表服务器或生产可用性。
- 复刻快照下方保留了原站带现实金额投资和保证盈利含义的静态文案；本轮按要求保持 UI 不变。该文案不符合项目虚拟积分边界，正式对外使用前必须移除或改为合规内容。
