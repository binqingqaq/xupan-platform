# 玩家与托头像池替换为 HBY019 九十六张图片计划

## 目标与范围

按使用者 2026-11-06 的要求，将玩家和托的头像预设池完整替换为 HBY019 本地项目中 `static/xz/admin/avatars/avatar-001.jpg` 至 `avatar-096.jpg`，并为当前已有玩家和托随机分配新头像。超级后台用户头像、聊天室固定机器人头像、HBY019 演示静态目录及玩家上传头像不属于本次头像池替换范围。

## 对齐映射

| HBY019 素材 | Xupan 静态键 | Xupan 数据与行为 |
| --- | --- | --- |
| `avatar-001.jpg` 至 `avatar-096.jpg` | `preset-01.jpg` 至 `preset-96.jpg` | `web/public/avatars/presets/` 服务静态图片 |
| 玩家/托头像选择器 | 现有头像池接口与选择器 | `avatar_preset` 为可分配池，`sys_user.avatar_key` 保存当前头像 |

## 实施内容

1. 把 96 张用户指定的图片复制到 Xupan 头像池并按 `preset-NN.jpg` 命名，覆盖原有同名图片并补齐此前不存在的键。
2. 添加 Flyway V110：将现存头像池账号、所有未删除的 NORMAL/BOT 玩家账号统一收集；随机打乱 96 个头像键后重新分配，并重建 96 条可用预设记录。
3. 保留已有的头像分配唯一约束。若迁移涉及的账号超过 96，迁移显式失败，不会以重复头像继续运行。
4. 更新身份与玩家管理文档；旧 40 张 Pixabay/Pexels 素材清单降为历史记录。
