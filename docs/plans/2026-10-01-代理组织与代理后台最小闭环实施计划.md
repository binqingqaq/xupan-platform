# 代理组织与代理后台最小闭环实施计划

> 文档效力：本文是已结项的阶段性计划快照，不是当前开发输入。计划中的“只读后台”“不提供上下分/创建玩家”等早期范围已被后续实现取代；当前代理能力和下一步以 [09 代理组织与代理后台](../业务模块/09-代理组织与代理后台.md) 和 [BY220 平移 DeepSeek 桌面端 Agent 交接](../交接/2026-10-02-BY220平移-DeepSeek桌面端Agent交接.md) 为准。

> 计划状态：本机完成，服务器与生产未验证  
> 创建日期：2026-10-01  
> 关联需求：BY220 业务提炼与 Xupan 落地边界  
> 当前目标：先建立代理身份、归属和最小后台，不实现代理钱包、信用、报网、盘口、二层结算或外部上游。

## 1. 背景

当前 xupan 已有平台管理员、普通玩家、TEST/BOT、聊天室、虚拟积分、下注、开奖、结算和 `/console` 运营后台。BY220 的核心业务结构包含“平台 -> 子账号/渠道组 -> 机器账号/代理 -> 玩家/托”，当前 xupan 缺少代理组织和代理侧数据隔离。

用户已确认按推荐路线先实现代理，同时明确需要平台超级管理后台和代理后台两个层次。

## 2. 默认业务规则

本计划采用以下默认规则，后续可以调整：

1. 渠道组可选，第一版只做“平台 -> 可选渠道组 -> 代理”一层。
2. 代理是玩家和托的运营归属主体。
3. 渠道组只负责分组和管理，不拥有玩家，不建立钱包。
4. 存量玩家和托自动归入系统内置的“平台直属代理”。
5. 新玩家和托默认归入平台直属代理，平台管理员可以将其分配给一个普通代理。
6. 第一版不允许代理之间转移玩家；平台直属玩家只允许一次性分配。
7. 代理停用采用软停用，不删除玩家、订单、流水和历史数据。
8. 代理账号使用 `sys_user` 密码登录，具备 `AGENT` 角色和最小代理后台权限。
9. 第一版代理后台只提供自身资料、玩家/托列表和汇总，不提供上下分、创建玩家或下注操作。
10. 不实现代理积分、信用、冻结、报网、盘口、二层结算和外部上游。

## 3. 范围

### 3.1 包含

- `agent_group` 渠道组。
- `agent` 代理主体和代理账号绑定。
- `demo_user_account.agent_id` 当前归属。
- 平台直属代理初始化迁移。
- 超级管理端渠道组和代理列表、创建、停用/启用。
- 超级管理端查看代理玩家数量、托数量、虚拟积分合计。
- 平台管理员将平台直属玩家分配给代理。
- 代理登录后查看自己的资料、玩家和托。
- 代理状态、账号状态、权限和审计。

### 3.2 不包含

- 代理自有钱包、信用额度、冻结和结算。
- 代理创建玩家、上下分、改赔率或管理注单。
- 玩家转移到其他代理。
- 报网类型、盘口线路、上游账号和自动上报。
- 中心上游 API、对账和风控。
- 外部投注平台、现实资金、代理分成或可兑换资产。

## 4. 数据模型

### `agent_group`

- 渠道组编码、展示名、状态、创建人、创建时间、更新时间。
- 不允许物理删除，只允许启用/停用。
- 编码全局唯一。

### `agent`

- 代理编码、展示名、所属渠道组、绑定账号、系统内置标记、状态、创建人和时间。
- 系统内置“平台直属代理”不允许停用或绑定登录账号。
- 普通代理必须绑定一个 `sys_user`。
- 代理编码和绑定账号全局唯一。

### `demo_user_account.agent_id`

- 记录玩家或托当前所属代理。
- 存量数据默认指向平台直属代理。
- 第一版建立禁用的转移入口，只允许平台直属代理的玩家分配给普通代理。

## 5. 权限

新增：

- `AGENT_MANAGE`：平台管理员创建、启停渠道组和代理，分配平台直属玩家。
- `AGENT_CONSOLE_READ`：代理账号读取自己的代理后台。

角色：

- `ADMIN`：自动获得 `AGENT_MANAGE`。
- `AGENT`：只获得 `AGENT_CONSOLE_READ`，不能访问平台用户、玩家工作台、代理管理和其他后台接口。

## 6. 接口

平台超级管理端：

```text
GET    /api/admin/agent-groups
POST   /api/admin/agent-groups
PATCH  /api/admin/agent-groups/{groupId}/status

GET    /api/admin/agents
POST   /api/admin/agents
PATCH  /api/admin/agents/{agentId}/status

GET    /api/admin/agent-player-assignments
PUT    /api/admin/agent-player-assignments/{userId}
```

代理后台：

```text
GET /api/agent/me
GET /api/agent/players
```

## 7. 前端

- `/console/agents`：超级管理端代理管理。
- `/agent`：代理后台。
- 登录后根据权限自动进入平台管理端或代理后台。
- 代理无法进入 `/console/**`。
