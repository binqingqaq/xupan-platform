# HBY019 页面源码复用演示计划

## 目标与范围

在 Xupan 前端技术栈中增加独立可访问的 HBY019 本地演示入口。唯一界面来源为 `D:\codes\liuhecai\hby019-local-rebuild`；不得参考 BY220、BY220 衍生项目或其他站点。正式 Xupan 页面、后端、API、权限、数据库和业务流程不在本次范围。

以来源页面文件直接呈现为实现方式：Vue Router 只提供独立路径，由 `Hby019SourcePage.vue` 通过全屏 iframe 加载从 HBY019 工作区复制的页面。来源 HTML、CSS、字体、图片、页面脚本及版式由来源文件决定，不在 Vue 中重画。复制脚本只改写为本地演示所需的静态资源路径、站内导航和数据桥接。来源服务与 Xupan 后端均不作为演示数据服务。

## 必须保持的边界

- 视觉、布局和控件由 HBY019 来源 HTML/CSS/资源决定。遇到差异先检查来源文件、资源和运行环境，不用其他项目或截图重新设计。
- 所有演示请求只由本地 fixture/bridge 处理。不得访问 Xupan `/api`、`/ws`、数据库、HBY019 服务端或其他外站，不形成真实登录、投注、聊天、积分等业务写入。
- 不改变 Xupan 正式页面和后端逻辑。演示专用代码、路由和静态资源保持在独立 `/hby019-demo` 前缀。
- 缺失的来源资源按实际来源状态记录，不绘制替代图，也不宣称来源服务端行为已复刻。

## 验收

- 登录、代理后台、portal、玩家 UI4/UI1 和后台可达的明细页面均能打开、刷新，页面主体直接来自本地 HBY019 来源副本。
- 在同浏览器、同视口比较本地 HBY019 来源运行页与 Xupan 演示页的关键区域、弹窗位置/尺寸、标题、按钮样式和可见交互；验证登录导航、后台常用弹窗、玩家面板/格式切换等路径。

- HTTP 200 或构建通过只证明服务和编译正常，不单独作为视觉与交互一致的证据。未实际核验的页面/交互明确列为未验收。
