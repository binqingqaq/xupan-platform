# 子账号与机器账号表单仅保留用户名实施计划

> 日期：2026-10-09
> 状态：本地实现与定向验证完成（2026-10-09）。用户确认管理后台创建子账号和机器账号时只保留用户名，移除独立展示名及相关请求逻辑。
> 依据：BY220 `application/admin/view/sub/form.html` 与 `application/admin/view/rb/form.html` 均以 `UserName` 作为账号标识，没有独立展示名字段。

## 目标与边界

- 子账号、机器账号的新增/编辑表单只显示用户名，不再要求或提交独立展示名。
- 对应管理 API 不再接收/返回独立展示名；新建时将用户名复制到现有的 `sys_user.display_name`、`agent_group.display_name`、`agent.display_name` 内部字段，以满足共用模型和下游显示要求。
- 改子账号用户名时同步更新上述内部显示值；未改用户名时保留既有值。已有数据库字段和既有展示值不做批量清洗，不新增 Flyway 迁移。
- 本范围只覆盖 `/platform-admin/sub-accounts` 与 `/platform-admin/machines`。通用用户昵称、托/玩家昵称、彩种名称、渠道组名称等字段不改。

## BY220 → Xupan 映射

| BY220 | Xupan | 目标 |
| --- | --- | --- |
| 子账号表单仅 `UserName` | `/platform-admin/sub-accounts` 另有「子账号名称」 | 移除名称控件与 request DTO 字段；服务按用户名赋内部显示值 |
| 机器表单仅 `UserName` | `/platform-admin/machines` 另有「展示名」 | 移除名称控件与 request DTO 字段；创建服务按用户名赋内部显示值 |
