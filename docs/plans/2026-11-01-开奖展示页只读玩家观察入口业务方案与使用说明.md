## 1. 要达到的效果

1. 使用者在超级管理后台创建一个专用子账号，再创建归属于它的专用机器。该机器仍是普通机器账号：可以登录 `/console`，创建玩家与托，正常执行现有虚拟积分下注、开奖结算、内部模拟上报及代理运营流程。
2. 在专用机器下创建一个**固定展示托**，将它的自动行为设为“手动/关闭自动”；可以再创建其他启用自动的托。展示托的账户面板只显示它自己的虚拟积分、注单和流水；聊天室显示该机器范围内真实可见的消息，包括其他托实际产生的动作。关闭展示托的自动行为，不会关闭同机其他托。
3. 超级管理员在现有“设置”页新增的“开奖页只读入口”区域，**一次绑定**专用机器和该机器名下的固定展示托。浏览者没有机器或账户选择器。常规“保存设置”不改变此绑定。
4. `/display/mobile` 的快乐8期号文本保持现有样式并变为可点击链接；期号仍只显示末三位。点击进入玩家前台外观的**只读观察界面**。开奖页随 AU8 轮期更新文本，绑定与观察地址保持固定，不必每期复制新链接。
5. “设置”页可以复制同一个只读观察地址并单独外发。打开地址后直接看当前直播式房间状态；该地址不是机器账号登录地址，也不是任何托/玩家的 `PLAYER_FULL` 链接。
6. 观察者能看聊天室、打开“快捷”查看内容、打开“账户”查看固定展示托数据；不能打开下注键盘、提交下注、发送文字/指令，不能保存快捷金额或执行任何积分与账号操作。前端隐藏/禁用入口，服务端也拒绝直接调用写接口和 WebSocket 发言。

**使用示例**：专用机器中有展示托 A（手动）和托 B、C（自动）。观察者的“账户”始终是 A 的虚拟钱包与个人注单；聊天中能看到该机器里 B、C 实际产生且按规则可见的消息。A 不会因为有人打开观察页而自动下注，B、C 也不会因为 A 被设为手动而停下。

**期号语义**：开奖卡片标题显示最近已确认的开奖期号。点击它进入该机器的**当前实时房间**，不把旧期号当作历史聊天筛选条件；如需“点击第 xxx 期只看该期聊天”，属于另一个需求。观察地址单独外发时同样进入当前实时房间。

## 2. 已确认与设计口径

| 事项 | 口径 | 状态 |
| --- | --- | --- |
| 专用组织 | 一个子账号下创建一台专供公开观察的机器；机器保留当前全部正常业务能力 | 使用者确认 |
| 托配置 | 选定一个展示托并关闭它的自动行为；其他托可保持自动、正常下注和结算 | 使用者确认 |
| 唯一绑定 | 超级后台“设置”绑定一台机器和一个展示托，浏览者不能自由切换 | 使用者确认；一次绑定和异常重置方式属下文工程设计 |
| 公开入口 | 开奖页期号可点击；同一地址可从“设置”复制并外发 | 使用者确认 |
| 观察权限 | 看聊天、快捷、账户；不打开下注键盘，不下注，不发送信息 | 使用者确认 |
| 可见范围 | 展示托账户属于该托；聊天室按机器隔离，同机其他托的真实消息可见 | 已实施；真实双机器数据隔离待专用绑定后人工验收 |
| 合规 | 所有余额、下注、结算、上报均为项目既有虚拟积分及内部模拟能力，不引入现实资金或真实外部上游 | 项目强制边界 |

**公开数据提醒**：开奖页和外发地址都可由未登录的浏览者访问。所绑定机器的可见聊天、展示托的账户/流水及快捷信息将被视为可公开内容。不要把不准备公开的普通玩家、私人聊天或真实凭据放进这台展示机器；如允许普通玩家在该机器参与，其机器内可见消息也可能进入观察页。公开地址的随机标识只能用于区分和轮换入口，不能被当作保密措施。

## 4. 设置页与数据设计

### 4.1 管理界面

在 `/platform-admin/settings` 增加独立区域“开奖页只读入口”，只允许超级管理员配置：

1. **展示机器**：从有效机器账号中选一台；机器必须归属子账号且启用 AU8。
2. **展示账户**：只列出所选机器名下有效的托；指定一个已设为手动/关闭自动的托。绑定成功后显示机器账号和展示托身份，不向浏览者提供选择器。
3. **入口状态**：未配置、已启用、已停用、绑定对象失效。未配置或失效时开奖页保留普通期号文本，不展示可用的跳转链接。
4. **只读地址**：绑定生效后显示“复制链接”；正常轮期不改变地址。另设停用和受控换链/重置操作，用于泄露、机器或托被删除等异常处理；要求原因、确认和审计，不作为日常切换入口。

绑定表建议使用固定单行键和数据库关联约束，持久化 `agent_id`、展示托的 `sys_user_id`、公开地址标识、启停状态、版本、操作人和时间；另写不可覆盖的绑定/换链审计。保存时同事务校验“托属于该机器、BOT、有效且自动关闭”，以版本或行锁避免两个管理员并发覆盖。默认流程是一次绑定后长期使用；如果机器/展示托被停用或物理删除，入口立即失效，不能自动改指向别的账号。删除业务本身仍遵守现有物理删除规则，绑定要先失效并留下不含链接密钥的审计快照。

固定展示托被绑定期间，服务端应阻止把它重新设为自动，或在状态变化时立即停用观察入口并给出明确原因。其他托的自动模式和机器正常运营设置不受绑定影响。

### 4.2 只读观察地址与权限

- 对外地址指向专用观察路由，例如 `/display/observe/{公开标识}`；实际路径以开发时路由约定为准。地址由服务端根据持久化绑定生成，开奖页和“复制链接”读取同一个配置，不在页面文件里写死机器 ID、玩家 ID、密码或现有玩家链接。
- 公开访问时签发与管理员、机器和玩家完整登录隔离的**观察会话**，会话绑定固定机器和展示托。地址是公开入口，所有可读数据必须先按公开范围审核；停用或换链后旧地址和已签发的观察会话失效。
- 观察模式只放行确需的聊天读取、AU8 当前期/赔率读取、展示托自己的账户/流水和快捷配置读取，以及仅用于接收的实时消息。默认拒绝其他路径；聊天室发言、下注、钱包/积分、快捷设置保存、玩家管理、链接管理、机器/上游操作和 WebSocket 上行消息均由服务端拒绝。不能仅依赖前端按钮禁用。
- 现有 `CHAT_ONLY` 权限也允许发送聊天，不能充当本方案只读权限；`PLAYER_FULL` 会赋予完整玩家操作，且自动托的调度依赖它。观察会话不得替换、轮换或撤销托已有的 `PLAYER_FULL` 链接。
- 对观察读取限制机器范围、分页和请求频率；返回账户只包含指定展示托的虚拟积分视图，不返回机器后台配置、其他玩家的钱包、完整访问链接或凭据。浏览器缓存和日志不记录访问凭据。

### 4.3 数据来源与实时性

| 观察页内容 | 事实来源 | 边界 |
| --- | --- | --- |
| 期号、开奖结果、倒计时 | AU8 `game_issue` 及现有开奖服务 | 与普通玩家看到的当前期一致；开奖事实由服务端确认 |
| 机器聊天室 | `chat_message` 的 `PUBLIC` 消息和绑定机器 `agent_id` 对应的 `MACHINE` 消息，沿用历史分页和实时通知 | 不能看到其他机器的私有消息；前台当前历史窗口仍受既有时长/保留规则约束 |
| 托自动活动 | 其他托的行为配置、`test_player_action`、正式 `game_bet` 和实际聊天室消息 | 只展示已执行/已持久化的事实；停机、封盘、托未满足候选条件时可以没有新动作 |
| “账户” | 固定展示托自己的钱包、注单和流水 | 不代表机器积分或同机所有托的汇总；其他托的下注不会进入该账户面板 |
| “快捷” | 该展示托/所属机器的现有赔率与快捷配置读取 | 可打开查看，不可选择并提交下注或保存设置 |

## 5. 使用说明：首次配置与日常使用

以下步骤是该功能的配置方式。当前本机已完成专用账号准备和固定绑定；如果在其他环境初次配置，再按步骤操作。

1. **准备子账号**：超级管理员登录 `/platform-admin`，进入“子账号”，创建专供展示机器归属的子账号。现有机器创建规则要求关联子账号。
2. **创建机器**：进入“机器管理”，创建专用机器并指定上述子账号；按正常业务设置 AU8 彩种、机器状态、有效期、托数量和已有虚拟积分/内部模拟上报参数。机器仍使用现有登录入口和原运营流程。
3. **创建展示托**：使用该机器账号登录 `/console`，通过“创建托”入口创建一个只供公开账户面板显示的托。进入托配置把自动模式改为手动/关闭自动，确认托及其账户状态有效。这个托可以保留正常历史和虚拟积分账本，但不再由自动行为调度新下注。
4. **准备活动内容**：仍在同一机器下按需要创建其他托、玩家；把希望展示自动行为的其他托设为自动，并保持机器开盘、托有效及其完整玩家链接有效。正常下注、结算、报表和内部模拟上报照旧运行。机器内聊天会对观察者可见，新增账号前需判断其内容是否适合公开。
5. **固定绑定**：超级管理员回到 `/platform-admin/settings` 的“开奖页只读入口”，选择专用机器，再从该机器名下选择第 3 步的手动展示托，点击“绑定并启用”。界面显示固定身份和入口状态，普通设置保存不重新选择。紧急重新绑定必须先停用入口，并填写原因。
6. **从开奖页进入**：打开 `/display/mobile`，点快乐8卡片的“快乐8第 xxx 期”。文本随开奖数据更新，进入固定只读观察地址。账户面板始终属于展示托，聊天室始终属于所绑机器；绑定未启用或机器/托失效时，期号仍显示开奖数据但不可点击。
7. **单独外发**：在设置页绑定区点“复制链接”，将只读地址发送给浏览者。对方打开后进入同一实时观察页；无需提供机器密码、托的完整玩家链接，也不必每期重新复制。停用或换链后已外发的旧链接失效。
8. **查看和维护**：浏览者可滚动聊天、查看快捷内容和账户，不能打开下注键盘或发送内容。运营人员继续登录机器 `/console` 维护玩家、托和业务。若要停止公开访问，在超级后台停用入口；异常情况下按受控流程换链，旧链接应失效。

## 6. 失效与提示

| 场景 | 开奖页/观察页预期 |
| --- | --- |
| 尚未绑定或主动停用 | 快乐8仍正常显示开奖；期号不跳转，外发旧地址显示“只读入口暂不可用” |
| 机器停用、过期或被删除 | 观察入口失效；不改指向其他机器，也不使用任何玩家完整链接兜底 |
| 展示托停用、删除、归属变化或被改为自动 | 观察入口失效或配置操作被服务端拒绝；提示后台检查固定绑定 |
| 其他自动托未产生动作 | 聊天显示真实现状，不伪造“托正在下注”；展示托账户仍可正常只读查看 |
| 公开地址被换新 | 开奖页自动指向新地址；复制按钮给出新地址，旧地址和旧观察会话失效 |
| 聊天或账户读取失败 | 各自显示失败/重试状态，禁止降级到别的机器或缓存中的旧账户 |
