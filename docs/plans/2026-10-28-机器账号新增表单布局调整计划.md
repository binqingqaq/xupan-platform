# 机器账号新增表单布局调整

## 目标

将超级管理后台机器账号添加/编辑表单按 BY220 `application/admin/view/rb/form.html` 的逐项单列方式展示，并把彩种、封盘秒数、取消秒数从新建界面移到编辑界面。

## 映射

| BY220 页面/行为 | Xupan 位置/行为 |
| --- | --- |
| `admin.php/rb/form` 逐项单列 | `/platform-admin/machines` 对话框单列布局，标签置于左侧 |
| 新建只配置基础账号信息、托数量、子账号及权限 | 新建表单不展示彩种/封盘/取消；机器自动关联唯一默认彩种 AU8，封盘/取消沿用固定默认值 120/30 秒 |
| 编辑机器的唯一默认彩种 | 移除彩种选择控件；保存时保留既有关联，无关联的旧机器自动回填 AU8 |
| 编辑机器时维护封盘和取消秒数 | 编辑态保留对应字段并提交保存 |

## 实施范围

- 仅调整 `PlatformAdminMachines.vue` 表单布局和新建/编辑字段可见性。
- 新建机器用户名输入显示“请输入用户名”；积分初始为空并显示“请输入初始积分”，留空时后端按 0 入账；托数量默认 3。
- 超级管理员创建机器必须选择所属子账号，页面和创建服务均校验；受子账号数据范围约束的操作者自动归属自己的子账号。
- 新建默认赔率 95、特码赔率 18；限额按截图设置：单码 200、单场总额 5000、角限额 1000、玩家最高 5000、玩家最低 1，其余所示限额 20000。编辑数字统一非负整数，步进 1。
- 不修改 API、数据库结构、默认封盘/取消值或权限行为。
