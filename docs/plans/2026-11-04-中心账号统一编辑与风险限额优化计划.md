# 中心账号统一编辑与风险限额优化计划

> 日期：2026-11-04
> 范围：仅超级后台 `/platform-admin/center` 的中心账号创建、编辑和该页风险限额配置；不改代理报网、订单、结算、对账及其它业务。
> 状态：代码已实施；自动化测试、类型检查、构建、MySQL 和浏览器验收未执行。

## 现状

- 中心账号行把停用/恢复、续期、重置密码、追加额度、机器会话、流水、删除分成多个操作。
- 续期、重置密码和追加额度要求管理员填写原因；风险限额则在“风险”页用另一张表单配置。
- `center_agent.max_single_amount` 与 `max_issue_exposure` 已存在，`CenterAgentService` 有正数及“单期敞口不低于单笔上限”的校验；`NULL` 表示旧全局兜底 100000/500000。
- 创建中心账号当前不写代理级风险上限，因此新账号继承全局值。

## 目标交互

- 中心账号行将“续期、重置密码、追加额度”合并进一个“编辑”按钮；停用/恢复、机器会话、流水、删除继续独立操作。
- 编辑弹窗包含有效期、可选新密码、追加可用额度、单笔上限、单期敞口上限。新密码留空表示不修改；追加额度为 0 表示不追加；有效期必须是未来时间；限额必须为正数，单期敞口不得低于单笔限额。
- 编辑时不要求填写原因。后端仍保留审计；额度追加流水使用固定系统说明并生成服务端幂等键，不删改现有账本规则。
- 删除风险页顶部重复的限额编辑表单；风险汇总、限额展示和命中明细保留。
- 创建账号弹窗加入单笔/单期限额，默认分别为 1000 和 5000；服务端在新账号写入时也固定写入这两个默认值，避免绕开页面后落到旧全局默认。
- 已有账号如限额为 `NULL`，编辑弹窗按当前真实生效的全局兜底 100000/500000 显示；本轮不批量改历史账号。用户保存编辑后，该显示值成为该账号显式限额。

## BY220 与 Xupan 映射

| 页面/操作 | 当前实现 | 本轮落点 |
| --- | --- | --- |
| 中心账号创建/生命周期 | Xupan 扩展，无 BY220 中心承接侧 | `/platform-admin/center` 中心账号表与二级创建/编辑弹窗 |
| 追加额度 | `CenterAgentService.grantAvailable` 追加余额流水 | 编辑弹窗提交追加值；同一事务中按服务生成幂等键写现有追加账本 |
| 单笔/单期风险上限 | 已在中心代理风险字段与接单校验中实现 | 创建默认写 1000/5000；编辑弹窗维护同一字段；“风险”页只读展示 |
| 账号密码/有效期 | 现有专用 PATCH API 要求原因并撤销会话 | 编辑接口集中保存；密码可选；有效期变更或密码变更时撤销关联会话 |

## 后端实施边界

1. 扩展中心账号创建入参，服务端默认值为 1000/5000 并持久化到既有字段；不新增迁移。
2. 中心账号列表/创建响应带上有效限额值。旧 `NULL` 值映射为原接单全局兜底，不伪装为新默认值。
3. 新增中心账号编辑命令和事务服务，统一校验账号存在、有效期、密码策略、限额关系和追加额度整数约束；任一失败全部回滚。
4. 不要求人工填写原因；审计用固定动作说明，额度分录有固定中文原因与服务端幂等键。密码明文不得写日志或审计，只存 BCrypt 哈希。
5. 现有专用管理端 API 可以保留兼容；风险、订单、报网、结算、删除语义不变。

## 验收范围

- 单账号统一编辑覆盖只续期、只改密码、只追加额度、只改限额及组合修改；密码留空不变，额度 0 不产生分录。
- 输入无效密码、过去有效期、非正限额、敞口小于单笔限额或非整数追加额时整体拒绝，账号与账本均不变。
- 新账号默认限额为 1000/5000；旧 `NULL` 账号 UI 显示 100000/500000，未编辑保存前数据库不批量变化。
- 更新密码或有效期会撤销旧机器会话；纯额度/限额编辑不撤销会话。
- 变更只触及中心上游账号管理页面与其 API/服务/仓储/类型和对应测试、项目方案、索引及模块说明。

## 实施与验证记录（2026-11-04）

- 中心账号行现使用“编辑”统一设置有效期、新密码（留空不修改）、追加额度（0 不追加）、单笔和单期敞口上限；停用/恢复、会话、流水和删除保留独立操作。
- 风险页的限额编辑器已移除；风险统计、账号限额只读列和风控命中明细保留。
- 创建弹窗提供单笔/单期限额默认值 1000/5000；服务端同步持久化并校验二者关系。旧 `NULL` 值通过中心账号读取接口映射为其原有全局兜底 100000/500000；未批量改历史账号。
- 新 `PATCH /api/admin/center/accounts/{id}` 在同一事务内更新限额、有效期、可选密码和额度追加。密码或有效期变化会撤销旧机器会话；追加额度走既有中心账本，原因由系统固定并使用服务端 UUID 幂等键；统一审计不记录密码。
- 变更局限于中心账号页面/API/服务/仓储/类型及相关测试与文档；未新增数据库迁移，未改代理报网、中心订单、风险判断公式、结算或对账行为。
- **未执行**：自动化测试、类型检查、前端构建、隔离/本机 MySQL、浏览器及服务器/生产验收。
