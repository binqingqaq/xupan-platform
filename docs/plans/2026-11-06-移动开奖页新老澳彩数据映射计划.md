# 移动开奖页新老澳彩数据映射计划

## 目标

在 `/display/mobile` 保持现有卡片顺序和视觉结构，通过 Xupan 同源 API 更新新澳彩、老澳彩最近已开奖期、七个号码及生肖；下一期倒计时按页面现有展示时刻计算。功能只读展示，不参与下注、开奖事实或结算。

## 实现边界

- 浏览器只请求 Xupan 同源 `/api/display/mobile/macau`；由后端并行获取两个外部静态数据脚本。
- 不执行上游 JavaScript；只提取 Base64 JSON 并校验脚本变量、规则类型、`widgetId`、期号和七球数据。
- 两个卡片独立使用 30 秒内存缓存，并存入现有展示快照表；上游失败时返回最近快照并标记 stale。
- 数据只更新公开展示卡，不进入游戏开奖、下注或结算链路。
