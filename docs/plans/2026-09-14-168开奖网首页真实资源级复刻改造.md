# 168开奖网首页真实资源级复刻改造实施计划

> **给实施者：** 按任务顺序执行本计划。步骤使用复选框（`- [ ]`）语法跟踪进度。本计划只描述资源级视觉复刻，不自动扩展后端业务。

**目标：** 在现有 `/display` 桌面静态首页基础上，使用参考首页中可核对的本地图片、Logo、彩种图标、卡片缩略图和 CSS 尺寸信息，重做资源和视觉层，使页面从“结构相似”提升到“资源和视觉高度接近”。

**架构：** 保留当前 Vue 3 展示路由和静态前端交互，不复制参考站点整套 HTML、JavaScript 或运行时接口。先建立只读资源清单，再将经过允许范围确认的静态资源下载到 `web/public/display/reference/`，最后由 `DisplayHomeStatic.vue` 和页面专用 CSS 通过本地路径引用。所有开奖数字、期号、新闻和倒计时仍是固定展示内容。

**技术栈：** Vue 3、TypeScript、Vite、Vue Router、页面专用 CSS、PowerShell 或 Node.js 一次性资源下载脚本、浏览器截图和静态资源校验。

## 全局约束

- 当前任务只做桌面静态首页资源级复刻，不新增开奖、投注、支付、钱包、用户、权限、聊天、机器人或数据库业务。
- 当前项目技术基线继续使用 `web/` 下的 Vue 3 + TypeScript + Vite，不引入新的 UI 框架。
- `/display` 必须保持未登录可访问；`/` 仍然跳转 `/room`；`/room`、`/admin` 和现有后台接口不因本任务改变。
- 参考站点只作为视觉和静态资源参考，不能把其栏目、请求参数、实时接口字段或外链目标当作当前项目业务契约。
- 不下载或保存 Cookie、Token、登录信息、会话标识、带访问作用的完整 URL、运行时接口响应或第三方投注数据。
- 不在首页运行时引用 `16894913.com`、其 CDN、其 API、其 JavaScript 或其 CSS；页面发布后必须使用本地资源。
- 资源是否能够下载，不等于项目可以永久发布该资源；每项资源必须记录来源、用途、授权状态和处理结论。
- 未获得正式使用许可的资源只允许作为本地评审素材；正式部署前必须替换为用户提供或已获授权的资源，或改用自制等效资源。
- 不删除当前第一阶段占位资源，直到真实资源替换完成并通过截图验收；替换确认后再清理未使用文件。
- 不实现移动端 `m.16894913.com`；本计划只覆盖桌面尺寸 `1366 x 768` 和 `1920 x 1080`。

## 3. 资源授权和下载策略

### 3.1 资源分级

将资源分为三类并在清单中使用固定状态：

| 等级 | 含义 | 处理方式 |
| --- | --- | --- |
| A | 用户提供、明确授权或项目自有资源 | 可以进入 `web/public/display/reference/` 并用于演示和后续部署 |
| B | 公开可访问但版权/商用许可未确认的参考资源 | 可以在本地评审分支临时使用；提交正式部署前必须确认或替换 |
| C | 运行时接口、Cookie、Token、账号相关或第三方投注/支付资源 | 禁止下载、禁止提交、禁止运行时引用 |

本轮资源主要可能落在 A 或 B；任何带有登录、访问控制或业务数据作用的资源直接判为 C，不因为浏览器能够加载就纳入。

### 3.2 下载白名单

只下载首页实际需要的静态文件，初始白名单按以下目录和文件建立：

- 品牌和工具：`img/logo.svg`、`img/icon/APP_download.png`、`img/icon/announce.png`、`img/icon/news.png`、`img/Revision_img/cpdt_white.png`、`img/Revision_img/cpdt_red.png`。
- 极速赛车与首页快速卡片：`img/video_png/jisusc.jpg`、`img/video_png/jsft.jpg`、`img/video_png/xingyft.jpg`、`img/video_png/azxy10.jpg`、`img/video_png/xyssc.jpg`。
- 首屏彩种 Logo：`img/small_logo/jisusc.png`、`img/small_logo/jisuft.png`、`img/small_logo/jisussc.png`、`img/small_logo/sgAirship.png`、`img/small_logo/sg11x5.png`、`img/small_logo/aozxy5.png`、`img/small_logo/aozxy10.png`、`img/small_logo/Kuai3_sg.png`。
- 推荐区：`img/Revision_img/happy28.jpg`、`img/Revision_img/bingo.jpg`、`img/Revision_img/jisu_saiche.png`、`img/Revision_img/ssc_jisu.png`、`img/Revision_img/sport_jsydh.png`、`img/Revision_img/sport_klydh.png`、`img/Revision_img/hksmsixlogo.png`、`img/Revision_img/sgssc.png`、`img/Revision_img/sgAirship.png`、`img/Revision_img/pcdd.png`。
- 专题和侧栏：`img/special_png/pk10.png`、`img/special_png/ssc.png`、`img/special_png/11check5.png`、`img/special_png/k3.png`、`img/special_png/pcdd.png`、`img/banner/foot.png`、`img/myPreferences.png`、`img/pre_p.png`、`img/prev_li.png`、`img/next_li.png`。

执行时必须以 HTML/CSS 中的实际引用为准：如果白名单文件不存在、尺寸不匹配或不属于首屏，就在资源清单中标记为“未使用”，不能用猜测路径继续扩大下载范围。

### 3.3 本地命名和目录规则

- 本地目录按用途分层，不把所有文件平铺到同一个目录。
- 保留原始扩展名和必要的透明通道；SVG、PNG、JPG 不互相强转格式。
- 文件名使用可读中文或稳定英文原名，避免把带查询参数的 URL 直接当文件名。
- 查询参数只用于下载时的缓存校验，不写入前端资源路径。
- 下载后为每个文件记录字节数、MIME、宽度、高度、SHA-256 和资源等级。
- 前端只引用相对本地路径，例如 `/display/reference/lottery/jisusc.png`，禁止保留远程地址。

## 7. 风险和处理方式

| 风险 | 处理方式 |
| --- | --- |
| 资源可以访问但没有明确授权 | 标记 B 类，仅供本地评审，正式发布前替换或取得授权 |
| 资源 URL 返回 HTML/JSON 而非图片 | 用文件头和 MIME 校验阻断，清单标记下载失败 |
| 参考 CSS 使用大量全局选择器 | 只提取尺寸和视觉规则，转换为 `display-` 前缀 CSS |
| 原站图片由接口动态生成 | 只复刻已确认的静态占位/截图效果，不接运行时接口 |
| 资源更新导致截图不稳定 | 记录下载日期和 SHA-256，后续以本地副本为准 |
| 真实图片尺寸与当前卡片不匹配 | 先按原始比例建立固定图片框，再调整卡片布局，不拉伸图片 |
| 误把彩种 Logo 当成用户头像 | 在资源清单中按“彩种 Logo/推荐图/快速开奖图”分类 |
| 资源替换影响现有业务页面 | 所有 CSS 加 `display-` 前缀，并验证 `/room`、`/admin` |
