# 实施计划目录规则

## 当前计划判定

只有 [当前文档入口](../文档索引.md) 的“当前仍在执行或待补的专项计划”中列出的计划，才可以作为当前开发输入。

其他计划文件即使仍保留在目录中，也只用于历史追溯，不能覆盖当前业务模块基线、源码、迁移、测试或最新验收记录。

## 计划结项流程

```text
需求进入模块基线
  -> 创建实施计划
  -> 代码、迁移、测试和运行态验证
  -> 更新模块状态矩阵
  -> 写验收记录并标明证据等级
  -> 从当前入口移除已结项计划
  -> 计划删除或移入明确归档位置
```

计划不应长期承担业务规则的唯一记录职责。规则进入业务模块基线，证据进入验收记录，计划只记录本次实施范围和执行过程。
