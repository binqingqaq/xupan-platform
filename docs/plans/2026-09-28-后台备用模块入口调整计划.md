# 后台备用模块入口调整计划

> **计划状态：** 本机实施完成（2026-09-28）；真实 375px、MySQL、服务器和生产验收未执行。
>
> **目标：** 在“模块预留”下方增加备用模块入口，将后台主界面暂时移出的区域集中保存，便于后续恢复；同时按浏览器批注调整报网控制和左侧辅助栏的位置。

## 1. 调整范围

- 报网控制两行从主控制条移动到主内容后段，保持静态展示和原有事件语义不变。
- 左侧辅助栏上移到与右侧主内容同一行顶部。
- 从主界面移除“当前运行状态”四格，放入新的 `/console/stash` 备用模块页面。
- 在“模块预留”下方增加“备用模块”入口链接。
- 保持后台路由权限 `USER_MANAGE`、现有 API、玩家、积分、下注、机器人和数据库逻辑不变。

## 2. 验收

- 新增路由和入口可访问。
- 主界面不再渲染原状态四格，备用页仍显示相同只读状态。
- 报网控制和左侧辅助栏位置调整生效。
- 前端测试、类型检查和生产构建通过。
- 真实 375px、MySQL、服务器和生产环境仍未验证。

## 3. 实施结果

- `/console` 的左侧辅助栏已上移，与右侧内容同一行顶部对齐。
- 报网控制的报网类型和报网状态两行已移动到上下分/最近记录之后、玩家工作台之前。
- 原主界面的“当前运行状态”四格已移除，放入 `/console/stash`。
- “模块预留”下方新增“备用模块 / 查看备用模块”入口。
- 新增 `/admin/stash` 到 `/console/stash` 的兼容重定向。
- 前端 Vitest：`20` 个文件、`106` 个测试通过；`typecheck` 和生产构建通过。
- 真实管理员页面已验证主界面新布局、备用入口和备用页可访问。
## 4. 补充优化结果

- 积分颜色统一为增加/上分为红色，减少/下分为绿色，覆盖上下分确认、最近上下分记录、玩家积分操作、积分汇总和旧运营页余额流水。
- 根因定位：后台多个顶层面板和内层玩家列表使用 `overflow` 滚动容器，鼠标滚轮到这些区域时只尝试滚动内部容器，页面级滚动被拦截。
- 修复：后台面板改为 `overflow: clip`；玩家列表和详情取消内部滚动，改为页面整体滚动；后台根容器增加显式滚轮转发处理。
- 真实浏览器验证：在后台主界面滚动后 `window.scrollY` 从 `0` 变为 `209`，页面级滚轮恢复。
