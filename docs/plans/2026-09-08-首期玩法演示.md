# 首期玩法演示实施计划

> 历史计划：本计划对应 2026-09-08 的首期手动开奖演示。当前期号和轮期规则以 `docs/需求基线/2026-09-10-自动轮期与随机开奖.md` 和 `docs/项目记忆.md` 为准。

> **给实施者：** 按任务顺序执行本计划。步骤使用复选框（`- [ ]`）语法跟踪进度。已完成步骤保留验证依据。

**目标：** 在当前 Spring Boot 服务中交付一个可浏览器演示的 8 球玩法页面，并用可配置赔率完成可重复验证的结算闭环。

**架构：** 使用单体 Spring Boot 服务承载 REST API 和静态页面，先用领域服务完成纯 Java 结算，再通过 Flyway 建立 MySQL 8.4 LTS 兼容表结构。首期使用后台演示接口录入开奖，页面通过轮询刷新，不引入实时通信和微服务。

**技术栈：** Java 21、Spring Boot 4.0.8、Spring MVC、Bean Validation、Flyway、MySQL 8.4 LTS、测试 H2、原生 HTML/CSS/JavaScript。

## 全局约束

- 生产数据库固定为 MySQL `8.4 LTS`，数据库结构使用 Flyway。
- 测试可以使用 H2，但必须单独标识，不能宣称已完成 MySQL 运行验证。
- 金额使用 `BigDecimal`，不使用 `double`。
- 所有下注保存赔率快照，不能按结算时的最新赔率回算。
- 页面首期为移动端优先的密集信息界面，交互目标尺寸不小于 44px，不使用横向滚动。
- 玩法规则以 `docs/项目方案.md` 和 `docs/参考资料/汇博盈-业务参考.md` 为准；未知口径用配置或明确错误返回处理。
- 新文档使用中文或中英结合文件名，不创建纯英文文档文件名。
