# 机器人开奖消息图像化展示开发计划

## 1. 目标

完成第二阶段展示改造：让机器人开奖后的摘要、历史、获胜名单三段消息表现为不可选中文本的图片式内容，并在聊天室窗口缩放时保持比例和可读性。

## 2. 事实与边界

- 已确认：后端已通过 `payloadJson` 提供三种结构化开奖消息，内容来自真实开奖历史和结算数据。
- 本阶段：前端生成内联 SVG 数据图像，图像不依赖网络资源、不创建可复制的正文文本节点，并通过 `img` 响应式缩放。
- 本阶段：图像内部的用户标识、玩法、金额和时间全部来自已校验 payload；动态文字先做 XML 转义。
- 未纳入：对象存储、图片上传、图片附件下载、服务端图片渲染和生产字体版权确认。

## 3. 实现任务

1. 新增三种开奖 payload 的 SVG 图像渲染器，统一输出 data URL、原始尺寸和辅助说明。
2. 替换机器人消息组件为无文本图像容器，禁止选中、拖拽和点击交互。
3. 调整机器人气泡宽度，使桌面和窄窗口按容器宽度缩放且不产生横向溢出。
4. 增加图像内容安全、无外链、转义和三种 payload 渲染测试。

## 4. 验证标准

- 三种机器人消息均渲染为 `img`，图像源为 `data:image/svg+xml`，不包含外链图片节点。
- 图像容器没有可复制正文文本，禁止拖拽和指针交互，同时存在 `role="img"` 和辅助说明。
- 486px 左右窄窗口下图像不超出视口，桌面宽度使用同一比例模型。
- 前端 Vitest、类型检查和生产构建通过；开奖接口和后端既有测试不回归。
