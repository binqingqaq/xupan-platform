# Xupan 玩家账户流水面板复用 HBY019 源码实施计划

## 计划状态

- 状态：本机账户面板范围实现与专项验收完成；字体最终观感由使用者在本机浏览器确认。服务器、生产和跨浏览器验证不属于本机结项范围。
- 确认日期：2026-10-19。
- 实施记录：2026-10-19。

## 1. 目标

玩家在 Xupan 前台点击右上角三杠时，显示 HBY019 原账户流水面板的 DOM 结构与 CSS 样式，并由 Xupan 当前登录会话和 API 提供真实账户数据。面板仅在打开时显示，不重做或替换玩家主界面。

本次目标是复用来源页面代码，不再用 Vue 模板重新画面板，也不通过反复追加近似 CSS 来追赶截图。

## 2. 实施前实现与问题

- HBY019 面板来源位于 `web/public/hby019-demo/source/player-ui1.html`，面板 DOM、作用域属性、弹出层结构及样式均在该来源页面中。
- 当前 Xupan 在 `web/src/components/Hby019AccountPanel.vue` 重新构建了 Vue 模板与样式；账户数据由 `web/src/views/UserRoom.vue` 调用 `api.getMyBetSummary()` 读取 `/api/demo/game/bets/summary`。
- 现有 Vue 组件没有逐字保留原始 DOM 和 CSS 选择器所需属性，已出现页签选择器未命中等可见差异。仅在现有 Vue 重建结构上继续补 CSS，不能作为本计划的实现方式。

## 3. 已确认方案

1. 从 HBY019 来源页面提取账户流水面板所需的原始 HTML 结构和相关 CSS，放入独立、同源的面板文档。保留来源中的 DOM 层级、类名、`data-v-30d8da26` 属性、尺寸规则、字体规则、颜色、滚动区域和弹层位置。
2. 由 Xupan 玩家页面提供全屏透明 iframe 宿主；iframe 文档只渲染账户流水面板及其遮罩，不加载第二份玩家主界面。面板关闭时卸载或隐藏 iframe；打开时沿用 HBY019 的遮罩和右侧面板表现。
3. Xupan 父页面继续持有认证态并调用现有 API。通过校验来源窗口和 origin 的 `postMessage` 协议向 iframe 发送账户数据、加载状态和错误状态，不向 iframe 传递 access token 或其他凭据。
4. iframe 将关闭、切换未结算/已结算、字体大小、加粗、注单展开等 UI 操作通过消息返回父页面。父页面继续负责 API 调用、状态管理和现有本地字体偏好存储。
5. 只替换 Xupan 玩家前台的账户流水弹层实现，不改主聊天室、键盘、下注业务、后端接口、数据库、代理后台或 HBY019 演示路由。

## 4. 来源与 Xupan 行为映射

| HBY019 来源行为/结构 | Xupan 接入方式 | 数据或状态来源 |
| --- | --- | --- |
| `uni-popup right`、遮罩、`popup-content` | 在全屏 iframe 文档中保留原始弹层 DOM/CSS；父页面三杠控制开关 | Xupan `menuOpen` |
| 用户头像与身份 | 保留来源头像/身份节点和布局 | 当前登录用户及头像 API |
| 今日流水、今日总盈亏 | 保留来源汇总节点及格式 | `/api/demo/game/bets/summary` |
| 未结算、已结算页签 | 保留原始 `btnClass` 与 `btnClassActive` 结构和属性 | Xupan `pending` / `settled` 状态 |
| 注单列表、结果、展开 | 保留来源列结构、行布局及字号/加粗 CSS | API 摘要中的 `pending` / `settled` 注单 |
| 字号、加粗控件 | 保留来源控件外观及布局；只绑定操作状态 | Xupan 当前字体偏好 |
| 关闭面板 | 来源面板发出关闭消息，由父页面关闭 | Xupan overlay 状态 |

## 5. 分阶段实施

### 阶段一：来源面板隔离（已完成）

- 对照 `player-ui1.html` 确认账户面板 DOM、依赖样式、字体和图片资源的完整边界。
- 生成独立面板文档，保留原始结构、属性和样式；移除与面板无关的主页面节点、脚本和外部请求。
- 以静态演示数据打开 iframe，先验证面板能独立显示、关闭、滚动，主界面不受 CSS 污染。

### 阶段二：消息桥接和真实数据（已完成）

- 定义并校验父页面与 iframe 的消息类型、数据结构、来源窗口和 origin。
- 父页面打开面板时调用现有账户摘要 API，并向 iframe 发送用户信息、汇总、两个状态的注单和加载/错误状态。
- 完成页签切换、字号、加粗、行展开、刷新数据和关闭操作的双向映射。
- 不复制认证凭据到 iframe；不增加后端 API 或数据库改动。

### 阶段三：视觉与交互验收（本机面板范围完成）

- 在相同浏览器、视口、缩放比例、用户数据、字号、加粗状态和页签下，同时比较 HBY019 来源面板与 Xupan 嵌入面板。
- 检查面板边界、遮罩、头像/身份、汇总区、页签、表头、行高、列宽、字体、颜色、滚动条及移动视口。
- 验证两个页签、所有字号、加粗、展开长注单、空数据、加载失败、重新打开和关闭后状态恢复。
- 本机确认面板层级、遮罩与左侧聊天可见关系；像素级等同性不作为本轮专项自动化验收项。
- 来源字体 CSS 已完整保留并由专项测试校验；使用者反馈的字形观感仍需在当前浏览器刷新后确认。

## 6. 安全与工程边界

- iframe 文档与父页面应同源部署；开发和打包时确保面板资源路径不指向外部站点。
- 消息处理只接受预期 iframe 的 `contentWindow` 和允许的 origin；校验消息类型和字段，避免任意窗口伪造数据或操作。
- token、cookie、随机访问标识和敏感凭据不得写入 iframe URL、消息载荷、源码或日志。
- Xupan API 是数据事实源；HBY019 页面仅提供展示结构和交互外观，不调用 HBY019 后端或演示 bridge。
- 不修改 `web/public/hby019-demo/source/player-ui1.html` 的来源内容来适配正式 Xupan。若需抽取或本地化，使用独立面板资源并记录与来源的差异。

## 7. 验收标准

- 点击 Xupan 三杠出现来源结构的账户面板，关闭后回到原玩家页面；聊天室和键盘不因面板样式发生变化。
- 在相同视口及相同 UI 状态下，面板布局、颜色、字号、页签和滚动行为与 HBY019 来源一致；所有可见差异有记录和解释。
- 汇总、身份和注单来自 Xupan 当前用户 API；未结算与已结算切换显示各自真实数据。
- 字号、加粗、注单展开、关闭、加载和错误状态正常；刷新和重复开关不遗留重复 iframe、监听器或遮罩。
- `postMessage` 来源验证通过；浏览器网络记录确认面板不访问 HBY019 服务端、外网或演示 API。
- 前端类型检查、相关自动化测试和构建通过；最终报告明确区分静态检查、浏览器交互和视觉对照证据。

## 8. 本机实施结果

- HBY019 UI1 的账户流水面板已抽取为独立同源文档 `web/public/hby019-demo/source/account-panel.html`，使用来源 DOM 结构和样式，不再由 Vue 重新绘制面板。动态记录行模板已对照 UI1 runtime 源码映射，桥接只用 Xupan 数据填充。
- Xupan 玩家页现使用 `Hby019AccountPanelFrame.vue` 承载面板；双向消息桥接位于 `account-panel-bridge.js`，只传递界面状态和操作，不传递 access token。生产静态资源由 `build-hby019-account-panel.mjs` 生成到 Spring Boot 静态目录。
- 弹层 iframe 层级按 HBY019 原页的层级安排为 999，Xupan 顶部工具栏为 1001；iframe 根画布透明，保留来源 40% 遮罩，因此顶栏在面板上方，遮罩下左侧聊天室内容可见。
- HBY019 来源样式表（含字体规则）完整保留；专项测试逐项比较来源与抽取文档的 `<style>` 节点，未增加替代字体定义。
- `SecurityConfig` 仅对精确账户面板文档路径设置 `X-Frame-Options: SAMEORIGIN`，其余页面继续使用 `DENY`；增加对应后端测试。
- 旧 Vue 重画组件已删除；自动化测试验证抽取后的面板节点与 UI1 来源节点 `outerHTML` 相同，并覆盖数据渲染、交互消息及无效消息拒绝。
- 浏览器验收记录：本机 8080 实际加载了 Xupan 汇总和注单数据；页签、字号、加粗、展开、遮罩关闭和再次打开均已操作验证。该证据为本机浏览器交互检查，不代表服务器或生产验收。

## 9. 验收边界与遗留项

- 本机专项验收确认来源 DOM 与样式（包括字体规则）保留，iframe 层级和透明画布已修正；使用者刷新后仍可反馈实际字体观感。源码样式一致不等同于不同浏览器、系统字体渲染下像素完全一致。
- 曾观察到的周期性 `TypeError: Failed to fetch` 尚未定位，且不是本次账户面板范围的验收门槛；不能据此判定为本改动导致或已解决。
- 服务器发布、生产验证、跨浏览器验证和长期稳定性检查未执行，不属于本机账户面板专项结项范围。

## 10. 范围外事项

- 无关模块全量测试中的历史失败不作为账户面板专项验收门槛；本轮仅执行面板相关测试、类型检查、构建和后端安全头定向测试。
- 头像失效/缓存场景、生产环境静态资源和跨浏览器行为未验收；真实浏览器数据检查仅覆盖本机当前账号。
