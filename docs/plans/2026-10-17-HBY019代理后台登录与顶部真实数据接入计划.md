# HBY019 代理后台登录与顶部真实数据接入计划

## 目标

沿用 `web/public/hby019-demo/source` 中的 HBY019 登录页和代理后台 HTML/CSS/布局。机器账号通过 Xupan 的 `CONSOLE` 认证登录后进入 `/hby019-demo/console`。顶部机器数据及普/托列表与删除已接入；2026-10-18 新阶段接入选中玩家后的操作，供使用者人工核对。

## 实现边界

- iframe 与 Vue 宿主通过同源 `postMessage` 传递登录请求、退出请求和顶部显示数据；只接受当前 iframe 的消息，不向 iframe 暴露 access token。
- 机器身份、登录校验、授权和机器隔离由 Xupan 后端执行；底栏只读写当前机器配置，不放宽管理员接口权限、不把本地演示桥接为后端代理。V85 仅新增 `agent.countdown_visible`，默认开启以保持既有玩家端显示。
- 详情桥接不得向 iframe 暴露访问令牌；宿主只接受当前 iframe、当前 origin 发来的白名单操作请求。
- 上下分审批需复用 Xupan 的机器范围、审批状态和虚拟积分账本；不得前端直接改余额。成功反馈用申请编号作为幂等键，避免重试生成重复聊天室消息。
- 提示音偏好与正式 Xupan 审批面板共用 `xupan.admin.point-request-sound`；音频播放仍受浏览器自动播放限制。
- `/hby019-demo/login` 使用 HBY019 登录页面外观，但账号密码必须交由父级 Vue 应用调用 Xupan 登录 API；不验证或保存本地模拟账号。
- 顶栏数据请求失败时不得继续显示 HTML 固定示例值；显示占位/失败状态，避免误认为是真实数据。
- 本阶段不接入积分记录页面、托积分记录页面、重置密码和无对应 Xupan 能力的托配置；当前期下注榜与上下分申请/审批使用 Xupan 真实接口。上期注单没有可用的 Xupan 读取接口，保持空列表。

## 人工验收

使用者自行输入真实机器账号密码登录并核对：登录成功落在 `/hby019-demo/console`；欢迎栏账号等于实际登录名；托数量上限、过期时间、剩余积分等于 Xupan 机器管理中的该机器数据；普/托数量、对应列表、会员 ID、昵称、积分和筛选后总积分与 Xupan 玩家数据一致；底栏封盘、取消、返水、流水显示口径和倒计时保存后重新进入仍保持设置；玩家链接登录后，机器关闭倒计时应隐藏期号栏，重新开启后应恢复；“移上/移下”和提示音分别只影响当前浏览器布局及声音。用可删除的测试玩家核对删除、上下分等既有流程；平台账号不能从机器端登录；退出后回到机器账号登录页。其余区域保持演示数据，不能当作已接入真实业务数据。
