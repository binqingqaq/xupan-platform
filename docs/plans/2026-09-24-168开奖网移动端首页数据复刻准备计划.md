# 168开奖网移动端首页数据复刻准备计划

> 状态：本机实现和验证完成。用户已明确确认外部接口合法合规并允许请求。

**目标：** 为移动端首页后续复刻准备可追溯的接口清单、字段映射和本地 UI 静态资源，同时保持外部接口与当前项目生产事实源隔离。

**范围：**

- 仅分析移动端首页 `home.html`。
- 只记录匿名可观察的 GET 接口结构和字段。
- 只下载首页同域 UI 静态资源。
- 不进入登录、投注、后台、新闻和其他子页面。
- 不下载广告轮播、统计脚本、Cookie、Token、接口响应或第三方品牌素材。
- 不实现登录、投注、新闻、彩票大厅或其他子页面。
