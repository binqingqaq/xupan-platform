# 机器开盘与代理配置权限收敛

> 状态：机器开盘与代理配置控制已实现；`robot_manage` 已按 BY220 `xiugai` 接入前端。2026-10-28 本机重启时 Flyway 已将数据库从 V97 迁移至 V98，后端健康检查 UP、前端 HTTP 200；测试未运行。

## 用户确认范围

1. 机器账号不再有独立“开盘”开关；机器名下下注按彩种状态、期号和封盘时间等正常规则判断，不受机器级开盘标记控制。
2. 机器账号不再有“代理配置修改”授权开关；机器账号始终可以在自身权限/数据范围内修改赔率、返水、封盘秒数、限额等机器配置。
3. 保留“机器人权限”和“开通追”。`robot_manage` 对齐 BY220 `xiugai` 的前端行为；保存 API 不增加权限校验。“开通追”不与其合并。

## BY220 核查项

- `application/admin/view/rb/form.html:78-82` 的 `xiugai` 是机器“机器人权限”开关，新建默认开启；`application/admin/controller/Rb.php:74,189` 保存它并在列表显示为“修改权限”。
- `application/rbt/view/index/admin_list.html:1795-1801` 在 `xiugai=0` 时将赔率、返水、封盘、取消输入设只读并隐藏修改入口；打开时解除只读并显示入口。
- 已核对 `UpdatePeiLv`、`UpdatePeiLv2`、`UpdateFanShui`、`UpdateFanShui2`、`UpdateFengpan`、`UpdateCancel`、`ChangeLimit`：这些接口没有服务端 `xiugai` 校验；`xiugai` 只在 `admin_list.html` 控制配置字段只读及限额入口显示。
- BY220 `setzhui()` 单独检查机器记录的 `zhui`，控制代理对托使用“追”设置的操作；它不等同于 `xiugai`。
- Xupan `robot_manage` 映射 BY220 `xiugai`；“开通追”仍是独立能力，不映射 BY220 另一个机器字段 `zhui`。

## 本机实现结果

- `PlatformAdminMachines.vue` 移除机器“开盘”和“代理配置修改”开关及开盘列；保留“机器人权限”和“开通追”。

- 代理配置读模型返回 `robotManage`；Vue 与 HBY019 前台都用它控制配置字段只读和限额入口显隐，保存接口不检查该值。
- 新建机器的“机器人权限”默认开启，缺省 API 请求也按开启处理；已有机器值不回填修改。
