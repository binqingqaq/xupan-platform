# 快捷入口与账户流水面板实施计划

## 1. 目标

- 将聊天室右上角旧菜单中的玩法说明、展开键盘、历史记录和设置迁移到“快捷”。
- 将菜单按钮改为打开当前登录用户的账户流水面板。
- 面板展示当前头像、余额、今日流水、今日总盈亏，以及未结算和已结算注单。

## 2. 已确认口径

- 所有金额、注单状态和盈亏以数据库和服务端结算结果为准。
- 今日按 `Asia/Shanghai` 自然日计算。
- 未结算为 `PENDING`；已结算为 `WIN`、`DRAW` 或 `LOSE`。
- 账户面板只读取当前登录用户的记录，不展示其他用户注单。
- 查询接口使用固定上限，避免把全部历史数据一次性塞入页面。
- 不修改开奖、下注球位、玩法解析和结算规则。

## 3. 实施范围

1. 后端在游戏数据仓储增加按账户查询注单和当日统计的只读查询。
2. 增加认证用户注单摘要接口，返回今日流水、今日净盈亏、未结算注单和已结算注单。
3. 前端新增账户面板状态、加载和错误反馈；面板按响应式抽屉布局实现。
4. 快捷菜单承载旧菜单功能；界面切换按钮保持原有界面 1/界面 2 行为。
5. 增加 Controller 查询回归测试，并执行前端类型检查、单元测试和生产构建。

## 4. 不在本次范围

- 分页、导出、筛选和后台统计报表。
- 修改赔率、玩法、下注金额或结算算法。
- 将钱包流水全部替换为注单列表；两者仍按各自业务职责保留。

## 5. 验收边界

- 静态验证：接口权限、数据字段、上海时区日界线和空数据状态有测试覆盖。
- 本机运行验证：登录后打开菜单，能够看到真实头像、今日统计和两个注单状态页签。
- 未执行生产服务器发布和多实例验证；上线前仍需按正式环境配置和数据备份流程验收。
