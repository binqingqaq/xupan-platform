# 用户与机器人真实头像上传实现计划

## 目标

打通用户和聊天室机器人的真实头像上传链路：文件上传、服务端本地存储、数据库头像键更新、聊天历史和 WebSocket 消息返回头像键，以及前台和管理后台的图片预览。

## 已确认边界

- 现有 `sys_user.avatar_key` 和 `chat_robot.avatar_key` 字段已存在，本阶段不新增业务表。
- 上传接口需要登录；当前用户只能修改自己的头像，管理员可通过现有用户/机器人管理权限修改目标头像。
- 图片通过公开只读 URL 展示，上传接口仍使用 Bearer 认证；文件名不采用客户端原始文件名。
- 默认使用本机运行目录下的 `var/uploads/avatars`，可通过环境变量替换为部署目录；本阶段不接入对象存储。

## 实现范围

1. 后端头像存储、类型/大小校验、路径安全和图片读取接口。
2. 当前用户、管理员用户、管理员机器人的 multipart 上传接口。
3. 聊天历史、REST 发送响应和 WebSocket 广播增加头像键。
4. 用户聊天室设置、用户管理详情、机器人管理表单增加选择文件和预览。
5. 前端类型检查、构建，后端测试和本地接口级验收。

## 验收标准

- 合法图片可上传并能通过公开头像 URL读取。
- 非图片、超限文件、未登录上传被拒绝。
- 用户和机器人数据库头像键更新后，聊天室历史和实时消息使用对应头像。
- 前台和管理后台均能看到当前头像并在上传后刷新预览。
- 不影响现有登录、聊天室消息、机器人管理和权限路由。
