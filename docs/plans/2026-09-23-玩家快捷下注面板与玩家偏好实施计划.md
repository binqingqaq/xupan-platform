# 玩家快捷下注面板与玩家偏好实施计划

## 1. 计划状态

- 状态：本机实现和验证完成；服务器与生产现场待验收。
- 日期：2026-09-23
- 所属模块：[展示端与玩家前台](../业务模块/07-展示端与玩家前台.md)、[期号玩法下注与结算](../业务模块/03-期号玩法下注与结算.md)
- 关联模块：身份与玩家管理、虚拟积分与钱包、运营后台与报表。
- 目标：将玩家页右上角“快捷”改为参考站的完整赔率与快捷下注面板，并让五个快捷金额按玩家保存。

## 2. 用户已确认规则

- 旧“快捷”下拉内容完全从页面移除，但旧代码保留，供后续复用。
- 点击“快捷”后展示完整赔率区和底部快捷下注栏，两者一起使用。
- 赔率项支持多选和再次点击取消。
- 金额输入框支持数字追加，底部 `X` 删除最后一位，快捷金额按钮直接替换输入值。
- `重置`只清空赔率选择，不清空金额。
- `设置`修改五个快捷金额，并按玩家保存；同一玩家的不同链接读取同一偏好。
- 点击“快速下注”后，把已选项目按参考顺序拼成一条逗号分隔消息，并发送到聊天区。
- 批量下注保持当前事务语义：任一注单失败，整批不生效。
- `1车`表示车覆盖另外三个番值，例如 `1车` 等于 `2/3/4` 车。
- `2无3`表示 `2` 中、`3` 输、其余番值和。
- `快捷`支持再次点击收起赔率面板。
- `界面`选择框需要在快捷赔率面板上方显示；`账户流水`入口会关闭赔率面板并打开账户流水。
- 刷新统一回到普通下注首页；快捷面板收起再打开保留上次滚动位置。
- `界面`菜单对当前选中的界面显示勾选。
- 设置弹窗只保留五个快捷金额输入和保存按钮，不再显示头像或金额提示文字。
- 设置弹窗保存按钮旁增加`默认`，点击后把五个输入恢复默认值，仍需点击`保存`才会持久化。
- 账户流水的`今日`口径下，已结算列表只显示当天结算，昨天及更早记录不出现在该列表。
- 账户流水按钮悬停时不显示浏览器原生`账户流水`提示。
- 机器人文本消息气泡宽度跟随正文长度，不再固定为等宽气泡。

- 管理员撤单和上期榜单。

## 4. 数据与接口

新增 Flyway V28：

```text
player_quick_bet_preference
  user_id
  amount_1 ... amount_5
  updated_at
```

接口：

```text
GET /api/me/quick-bet-preferences
PUT /api/me/quick-bet-preferences
```

规则：

- 偏好以 `sys_user.id` 为唯一键，同一玩家的所有链接共享。
- 只允许非 `CHAT_ONLY` 会话读写。
- 必须提供 5 个大于 0、最多两位小数的金额。
- 未保存过偏好时返回 `50、100、200、500、1000`。
- 偏好只表示界面快捷金额，不是钱包余额或资金事实。

## 5. 下注格式扩展

- `1车`到`4车`解析为覆盖另外三个番值的 `CAR` 参数。
- `2无3`等短格式解析为两个 `NONE` 参数：第一个为赢号，第二个为输号。
- 原有 `12无3`三位格式继续支持。
- 原有番、角、严/念、加、正、通、单双、大小、特格式继续支持。
- 组合下注继续使用逗号分隔，由聊天室服务在同一事务中逐笔创建注单。
