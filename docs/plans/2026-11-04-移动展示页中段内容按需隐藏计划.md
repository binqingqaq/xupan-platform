# 移动展示页中段内容按需隐藏计划

## 目标

`/display/mobile` 默认隐藏页面中段约四分之三可见文字内容，保留统一的展开/收起按钮。展开时按需请求本地 HTML 片段；收起时从 DOM 移除该片段，缓存内容供再次展开，不永久删除页面数据。

## 内容范围与映射

| BY220/现有页面内容 | 当前区块范围 | Xupan 行为 |
| --- | --- | --- |
| 移动展示页中段连续模块 | `widgetBox40236` 至 `widgetBox40605`，共 105 个顶层模块 | 初始不随首页 HTML 返回；点击按钮后载入，支持再次收起 |
| 中段前后的首页模块 | 其余 `widgetBox` | 保持原顺序和内容 |

选区按当前 HTML 可见文字长度累计，覆盖 37,233 字符中的 28,102 字符，约 75.5%；片段源码 621,823 字节。页面模块顺序和内容保持原样，仅延后中段请求与渲染。

## 实现约束

- 页面默认收起，按钮标注展开/收起状态并可键盘操作。
- 片段只通过同源静态路径加载；首次成功后在页面内缓存，隐藏时移除节点，再展开时复用缓存。
- Web 源文件与 Spring Boot 静态副本保持一致。
- 本功能不读写业务事实，不涉及数据库或迁移。
