## 1. 状态定义

| 状态 | 含义 |
| --- | --- |
| 待确认 | 业务规则、范围或口径尚未由用户确认 |
| 已规划 | 已有方案或计划，但尚未形成可验收实现 |
| 开发中 | 当前工作区或分支正在实现 |
| 代码完成未验证 | 代码存在，但缺少对应自动化或运行态证据 |
| H2 已验证 | 测试数据库迁移、单元或集成测试通过 |
| 本机 MySQL 已验证 | 本机 MySQL 8.4 LTS 迁移或接口链路通过 |
| 服务器已验证 | 已在目标服务器现场验证 |
| 生产已验证 | 已在正式生产环境验证 |
| 暂不纳入 | 当前阶段明确不做，不代表需求已完成 |
