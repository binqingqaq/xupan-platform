## 1. 当前结论

项目已经从“首期玩法和聊天室基础能力建设”进入“玩家身份、玩家工作台和运营联动能力完善”阶段。

当前可以确认：

- Spring Boot 后端、Vue 前端、Flyway 数据库迁移和 MySQL 8.4 LTS 技术基线已经建立。
- 管理员、普通玩家、TEST 玩家、BOT 和服务端机器人已经形成不同身份边界。
- 玩家链接登录、软删除、虚拟积分、下注结算、聊天室、WebSocket、机器人和玩家工作台已经形成多个可联动的业务切片。
- 最近提交包含玩家会员编号、头像、链接生命周期、积分记录和业务日对账等增强能力。
- 当前仍是单服务器、单 Spring Boot 实例方案；不能把本机验证写成服务器或生产验收。

当前不应再采用“想到一个页面就直接修改一个接口”的方式。任何新功能都要先确认它属于哪个模块、影响哪些主流程、产生哪些持久化事实，以及如何验收。

## 2. 产品边界

### 2.1 已确认边界

- 产品定位为合法合规的虚拟积分娱乐产品。
- 余额、下注额、返还、盈亏、积分流水和结算全部表示虚拟积分。
- 不接入充值、支付、提现、转账、代理分成或现实资金结算。
- TEST 玩家和 BOT 必须有可见、可查询、可审计的身份标记，不能伪装成普通真实用户。
- 数据库是业务事实源；前端计算、浏览器状态、内存状态和临时文件不能作为唯一事实。
- 关键操作必须考虑权限、事务、幂等、审计、失败恢复和重复执行。

### 2.2 当前范围

- 一个单体 Spring Boot 服务。
- 一个单服务器、单实例运行基线。
- 一个当前游戏和期号流，已有期号、玩法、下注、开奖、结算和虚拟积分链路。
- 管理员后台、玩家工作台、普通玩家链接前台、聊天室和展示端页面。
- 服务端常驻机器人和 TEST/BOT 自动行为。

### 2.3 当前不纳入或尚未确认

- 现实资金能力和可兑换资产。
- Redis、多实例协调、分布式调度锁和跨节点 WebSocket 广播。
- 第三方开奖接口或未经确认的生产开奖源。
- 抽水、飞单、代理分成和现实资金语义。
- 总结果聚合、特玩法金额口径、和局返还等仍需确认的业务规则。

## 3. 技术与部署基线

```text
Vue/Vite 前端
    -> REST API / WebSocket
Spring Boot 单体服务
    -> 领域服务、权限、调度、消息和审计
    -> JDBC Repository
MySQL 8.4 LTS（正式事实源）
    -> Flyway 迁移
```

- Java：21。
- 后端：Spring Boot，静态资源可由同一服务托管。
- 前端：Vue 3、TypeScript、Vite。
- 数据库：正式基线为 MySQL 8.4 LTS，测试可使用 H2，但 H2 结果不能替代 MySQL、服务器或生产证据。
- 当前运行决策：单服务器、单实例；扩容、Redis 和分布式能力必须以真实容量或故障证据为依据另行评估。

## 5. 模块依赖关系

```text
平台基础
  -> 身份与权限
       -> 玩家工作台
       -> 普通玩家前台
       -> TEST/BOT 自动行为
  -> 虚拟积分
       -> 下注与结算
       -> 积分报表
  -> 游戏核心
       -> 聊天反馈
       -> 服务端机器人
       -> TEST/BOT 自动行为
  -> 聊天与实时通信
       -> 玩家前台和机器人消息
```

关键原则：

- 钱包余额和流水由服务端交易链路产生，不能由页面直接计算或写入。
- 下注必须依赖当前期号、玩家身份、玩法校验和钱包余额；不能把下注做成单独页面假数据。
- 机器人消息是聊天事实或系统事件反馈，不能替代注单、钱包、结算等业务事实。
- 报表只能读取已有业务事实，不能再建一套与钱包、注单相冲突的统计事实源。
- 删除玩家不删除业务历史；必须撤销会话、链接和后续行为，并保留可审计关联。

## 6. 当前开发阶段

### 已完成的阶段性基础

- 首期游戏、期号、玩法、下注、随机开奖和结算基础。
- 虚拟积分钱包、管理员分配、下注扣分、结算和流水。
- 聊天 REST 持久化、WebSocket、断线补偿和单实例实时消息。
- 服务端机器人、开奖消息、模板、重试和审计基础。
- 统一管理后台和玩家工作台。
- TEST 玩家、BOT 分类和自动/手动行为闭环。
- 玩家身份字段、链接登录、链接刷新、过期/撤销、软删除和历史保留。
- 玩家积分记录弹窗和按 `Asia/Shanghai` 每天 06:00 切换的业务日统计。
- 聊天室上下分申请、后台确认、两种提示音、玩家/托最近记录和手动上下分联动已在本机形成闭环。
- `/console` 左侧下注榜已支持当前期普/托聚合、当前期明细、空白上期、18 期开奖和倒计时，`×` 保留但禁用。
- 玩家页“快捷”已替换为参考式完整赔率与快捷下注面板，支持 74 项多选、组合下注文本和玩家级快捷金额。
- 管理员和玩家链接使用独立刷新 Cookie，同一浏览器的管理员标签页与玩家标签页可同时保持会话。

### 当前阶段定位

当前处于：**下注榜、快捷下注和上下分审批本机闭环完成，准备处理服务器现场、真实全量下注、并发多管理员、撤单专项和生产发布收口。**

这不是正式生产上线状态。仍需单独完成或持续补充：

- 服务器现场部署、迁移、重启、回滚和备份恢复演练。
- 生产数据库、HTTPS、监控告警和正式运维链路。
- 托完整开奖周期、多人聊天室和关键页面的现场复验。
- 链接元数据保留期限和定期清理策略。
- 尚未确认的游戏规则和后续运营模块。
