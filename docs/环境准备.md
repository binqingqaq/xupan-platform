## 当前本机数据库情况

本机检测到 Windows 服务 `mysqlzt` 正在运行，但它来自 ZenTao：

- 实际数据库：MariaDB `10.4.14`。
- 服务目录：ZenTao 自带 `D:\Users\tbq\Downloads\ZenTao\bin\mysql`。
- 监听端口：`3306`。
- 用途：ZenTao 自带数据库，不作为 `xupan-platform` 的生产数据库基线。

不要为了本项目升级、覆盖或停止这个服务。项目应另外安装 MySQL `8.4 LTS`，建议：

- 服务名：`MySQL84`。
- 端口：`3307`，与 ZenTao 的 `3306` 并存。
- 数据库名：`xupan_platform`。
- 项目账号：单独创建，不使用 root 运行应用。
- root 密码和项目账号密码只保存在本机密码管理器或环境变量中，不能提交到 Git。

MySQL 官方 Windows 文档建议使用 MSI 和 MySQL Configurator；官方也支持 ZIP 安装。安装完成后，将 MySQL `bin` 目录加入 PATH，便于执行 `mysql`、`mysqldump` 等命令。

## 不需要现在安装的环境

- Node.js/npm：本机已有 Node.js `v24.14.0`、npm `11.9.0`；当前首期使用 Spring Boot 提供原生静态页面，不依赖 Node 构建。
- Docker：本机未检测到，首期不依赖 Docker。
- Redis：若依只作为参考，首期不引入 Redis。
- Quartz：确认需要自动开奖或定时结算后再引入。
- 独立 Maven：项目已有 Maven Wrapper，不需要另装 Maven。

## 推荐安装顺序

1. 安装 JDK 21，配置 `JAVA_HOME` 和 PATH。
2. 重新打开终端，确认 `java -version` 输出 21。
3. 安装 MySQL Community Server `8.4 LTS`，端口使用 3307，服务名使用 `MySQL84`。
4. 创建 `xupan_platform` 数据库和独立应用账号。
5. 配置本机环境变量，不把密码写入 `application.yaml`。
6. 运行 `cd server\xupan-server; .\mvnw.cmd test`。
7. 再进行 Flyway/MySQL 连接测试和首期页面验收。
