## 当前本机数据库情况

本机检测到 Windows 服务 `mysqlzt` 正在运行，但它来自 ZenTao：

- 实际数据库：MariaDB `10.4.14`。
- 服务目录：ZenTao 自带 `D:\Users\tbq\Downloads\ZenTao\bin\mysql`。
- 监听端口：`3306`。
- 用途：ZenTao 自带数据库，不作为 `xupan-platform` 的生产数据库基线。

不要为了本项目升级、覆盖或停止这个服务。项目使用独立的 MySQL `8.4 LTS` 实例，当前配置如下：

- 服务名：`MySQL84`。
- 端口：`3307`，与 ZenTao 的 `3306` 并存。
- 数据库名：`xupan_platform`。
- 项目账号：单独创建，不使用 root 运行应用。
- 安装目录：`D:\\MySQL\\MySQL Server 8.4`。
- 数据目录：`D:\\MySQL\\data`。
- 错误日志：`D:\\MySQL\\logs\\mysql84.err`。
- JDBC URL：`jdbc:mysql://127.0.0.1:3307/xupan_platform?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai`。
- 项目账号：`xupan_app`，数据库：`xupan_platform`。
- root 密码和项目账号密码只保存在本机用户环境变量 `XUPAN_MYSQL_ROOT_PASSWORD`、`XUPAN_DB_PASSWORD` 中，不能提交到 Git。

MySQL 官方 Windows 文档建议使用 MSI 和 MySQL Configurator；官方也支持 ZIP 安装。安装完成后，已将 MySQL `bin` 目录加入用户 PATH，并设置 `MYSQL84_HOME`，便于执行 `mysql`、`mysqldump` 等命令。已通过应用账号和 root 账号分别验证 TCP 登录。

腾讯云 Ubuntu 服务器已安装并验证 JDK 21：

- JDK 路径：`/www/server/java/jdk-21.0.2`。
- 登录终端环境文件：`/etc/profile.d/xupan-java21.sh`。

不要在服务器上通过系统提示另行安装 OpenJDK，避免形成多套 Java 环境。新建或更新项目 systemd 服务时，应固定使用已验证的 JDK 21 路径。

## 推荐安装顺序

1. 已确认 JDK 21、Git 和 Maven Wrapper 可用。
2. 已安装 MySQL Community Server `8.4.11`，端口 `3307`，服务名 `MySQL84`。
3. 已创建 `xupan_platform` 数据库和独立应用账号 `xupan_app`。
4. 已配置本机环境变量，不把密码写入 `application.yaml`。
5. 运行 `cd server\xupan-server; .\mvnw.cmd test`。
6. 完成 Flyway/MySQL 连接测试和首期页面验收。
