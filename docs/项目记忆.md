### A.2 当前关键约束

- 全站只用虚拟积分，不接入充值、支付、提现、转账、代理分成，不形成真实资金流水（合规边界（使用者确认 2026-09-19）；完整原文见 [项目方案](项目方案.md) B 节 §1.2）。
- 入口级独立会话：`auth_session.entry` 取 `PLATFORM` 或 `CONSOLE`，三个刷新 Cookie 分离，跨入口刷新 401 且只清本入口 Cookie；显式 `CONSOLE` 头登录要求账号含 `AGENT` 角色，否则 403 且不签发 Cookie（工程基线）。
- 上下分：机器账号在 `/console` 给玩家上下分时扣/回自己那台机器的积分池，托不联动（BY220: application/rbt/controller/Index.php:623；BY220: application/rbt/controller/Index.php:610）。
- 积分与金额统一为 2 位小数、超精度一律 400；这是对 BY220 六位小数的收窄，属使用者确认的有意偏离（BY220: local/schema-base.sql:397；BY220: local/schema-base.sql:534）。
- 报网、盘口、线路域名只做内部持久化与本地模拟，不发起真实外部请求、不保存真实凭据、不形成现实资金语义（合规边界（使用者确认 2026-10-02））。
- 线路域名字段已落库；接口与玩家端呈现属阶段 5、**未执行**（未对齐核对）。
- 迁移：本机 MySQL 实测 Flyway `V76`；`V76` 撤销 `ADMIN` / `SUB_ACCOUNT` 的 `AGENT_CONSOLE_READ`；服务器尚未迁移到该版本，本机数字不代表服务器状态（工程基线；不代表服务器）。
- 已知待清理（未执行）：`sys_user.user_type` 与 `demo_user_account.identity_type = 'TEST'` 的「玩家身份维度」是本项目自造，BY220 没有这一维度——BY220 的托只是玩家行上的 `isrobot`（BY220: application/rbt/controller/Index.php:622；BY220: application/rbt/controller/Index.php:651），本项目对应 `player_kind`；清理计划见 [移除玩家身份维度 REAL-TEST 与托标记收敛计划](plans/2026-10-08-移除玩家身份维度REAL-TEST与托标记收敛计划.md)。
