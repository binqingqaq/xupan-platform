## 2026-09-10 自动轮期与随机开奖

- 用户已确认：8 个球号分别在 01～20 内随机生成，允许重复，不做去重；首期期号从 `3000000` 开始。
- 每期固定 300 秒：前 180 秒为 `BETTING`，到时自动封盘并进入 `DRAWING`；后 120 秒开奖中，期满生成最终号码、结算待结注单并自动创建下一期。
- 服务端使用 Spring `@Scheduled(fixedDelay = 1000)` 推进状态，前台通过 `/api/demo/game/current` 每秒轮询；服务端返回阶段、服务端时间、两个阶段截止时间和轮期事件。
- 随机开奖使用 `SecureRandom` 生成最终 8 个号码；开奖中的滚动预览使用按期号和秒数稳定的伪随机值，避免同一秒不同客户端显示不同结果。
- Flyway 新增 V3 轮期字段和 V4 轮期事件表；自动轮期状态转换、最终开奖和事件写入均有幂等条件。
- 已验证：`自动轮期服务Test` 能从 `3000000` 推进到开奖中，期满将旧期置为 `SETTLED` 并创建 `3000001`；前端 `npm run typecheck`、`npm run build` 已通过。
